## Purpose

Finalise the compiler ↔ runtime split. The Zig runtime executes
compile-time metaprogramming (macros, scratch variables,
generative pipeline) against Clause IR; the Rust compiler defines
+ validates the C ABI by which those two sides communicate.

Output of this round: a stable type surface + runtime ABI
skeleton that later rounds fill in. Not shipped this round:
actual Zig source code, the LLVM bindings the runtime may use,
or the rustc wrapper that bundles the runtime dylib with the
compiler distribution.

## Decisions

### 1. Four new crates (three Rust, one Zig).

| Crate | Kind | Role |
|---|---|---|
| `clause-runtime-abi` | Rust, `cdylib` | Defines the C ABI in `#[repr(C)]` Rust types. Exports `extern "C"` entry points callable by the Zig runtime. No runtime logic — contract surface only. |
| `clause-runtime-driver` | Rust, library | Compiler-side driver: invokes the Zig runtime through dlopen/dlsym against the shipped runtime dylib. Consumes `clause-schedule`'s pass-DAG hand-off. |
| `clause-runtime-tests` | Rust, library | Runtime-ABI soundness tests. Validates every `#[repr(C)]` type has stable size / align / offsets across toolchains. Runs under `cargo test`; no Zig requirement. |
| `clause-runtime-zig` | Zig | The runtime proper. Consumes the C ABI; implements macro interpretation, scratch lowering, generative expansion. Delivered as a dylib bundled with the compiler binary. |

Rationale: splitting the Rust-side ABI definition (`clause-runtime-abi`)
from the driver (`clause-runtime-driver`) keeps the ABI pure —
downstream tooling (IDE helpers, Clause-in-Clause REPL) can depend
on the ABI crate without pulling the dlopen plumbing. The Zig
runtime is its own build unit with its own `build.zig`.

### 2. C ABI shape: `#[repr(C)]` + `extern "C"`.

Everything across the boundary uses:
- `#[repr(C)]` structs / enums / unions.
- `extern "C" fn` entry points.
- Owned memory passed via explicit `const T*` / `T*` + length
  pairs (Rust-side allocator stays on Rust side; Zig uses its
  own allocator for Zig-owned buffers; handoffs are by-pointer
  with documented lifetimes).

Strict rules:
- **No `Option`, `Vec`, `String`, `Box`** in ABI types.
- **No enum discriminants > u64** — Zig must encode them the
  same way.
- **Versioning:** every ABI struct carries a `abi_version: u32`
  as its first field. Mismatch aborts at the driver boundary with
  a diagnostic.
- **Endian:** little-endian fixed. Big-endian targets compile but
  refuse to load the runtime dylib.

### 3. Core ABI types (skeleton this round).

```rust
#[repr(C)]
pub struct AbiSpan {
    file_id: u32,
    start: u32,
    end: u32,
}

#[repr(C)]
pub struct AbiToken {
    kind: u16,     // maps to clause-ir::TokenKind discriminants
    trivia: u16,   // packed flags
    span: AbiSpan,
}

#[repr(C)]
pub struct AbiNode {
    kind: u16,     // maps to clause-ir::AstNodeKind discriminants
    pad: u16,
    span: AbiSpan,
    first_child: u32,  // NodeId.0
    next_sibling: u32,
}

#[repr(C)]
pub struct AbiDiagnostic {
    severity: u8,
    pad: [u8; 3],
    span: AbiSpan,
    message_ptr: *const u8,
    message_len: u32,
}
```

Every type mirrors a `clause-ir` type. The ABI crate provides
`From` impls in both directions that prove the `#[repr(C)]` shape
preserves the logical contract.

### 4. Entry points (skeleton this round).

```rust
extern "C" {
    /// Initialise runtime state. Called once per compile session.
    fn clause_runtime_init(arena_bytes: u32) -> *mut RuntimeHandle;

    /// Tear down runtime state.
    fn clause_runtime_shutdown(handle: *mut RuntimeHandle);

    /// Interpret a Clause IR node (macro body) against a provided
    /// call-site context. Returns a TokenStream pointer + length.
    fn clause_runtime_invoke_macro(
        handle: *mut RuntimeHandle,
        macro_body: *const AbiNode,
        macro_body_len: u32,
        call_site_args: *const AbiNode,
        call_site_args_len: u32,
        out_tokens_ptr: *mut *const AbiToken,
        out_tokens_len: *mut u32,
    ) -> i32;

    /// Evaluate a scratch-variable expression to its compile-time
    /// value. Returns a byte blob the compiler folds into the AST.
    fn clause_runtime_eval_scratch(
        handle: *mut RuntimeHandle,
        expr: *const AbiNode,
        out_bytes_ptr: *mut *const u8,
        out_bytes_len: *mut u32,
    ) -> i32;

    /// Expand a generative subgraph against compile-time inputs.
    fn clause_runtime_expand_generative(
        handle: *mut RuntimeHandle,
        generator: *const AbiNode,
        inputs: *const AbiNode,
        inputs_len: u32,
        out_nodes_ptr: *mut *const AbiNode,
        out_nodes_len: *mut u32,
    ) -> i32;
}
```

Return convention: `i32` = `0` success, negative = error code
(mapped to `AbiDiagnostic` via a follow-up `extern fn
clause_runtime_last_error(handle) -> AbiDiagnostic`).

### 5. Zig-side contract.

Zig runtime implements the inverse: it declares `extern fn`
prototypes matching the above. Zig's `extern "C"` is bit-compatible
with Rust's on the targets we care about (Linux glibc x86_64 /
aarch64, macOS aarch64, Windows x86_64).

`clause-runtime-zig` has a `build.zig` + `src/runtime.zig` with:
- Arena allocator.
- IR interpreter loop.
- TokenStream emitter.

Final shape + per-function impls in Phase 6 (Task #39).

### 6. Build integration.

- `clause-runtime-zig` builds to `libclause_runtime.{so|dylib|dll}`.
- `clause` binary at distribution time:
  1. Builds the Rust compiler.
  2. Builds the Zig runtime via `build.zig`.
  3. Bundles both into a single distribution tarball + a
     `manifest.toml` declaring the runtime dylib's abi_version.
- At run time: `clause-runtime-driver` dlopens the bundled dylib,
  validates `abi_version`, dispatches.

The bundling / distribution mechanics ship with a dedicated
round once the cargo-xtask pattern is authored.

### 7. Testing strategy.

- `clause-runtime-tests` runs `size_of` + `align_of` + `offset_of`
  assertions against every ABI type. If any shape drifts between
  rustc versions or targets, tests fail loudly.
- `clause-runtime-tests` also exercises the ABI via a minimal
  Zig stub — the test harness builds a tiny Zig dylib implementing
  the same ABI surface, dlopens it, and round-trips token / node
  / diagnostic buffers. This proves the Rust ↔ Zig handshake
  without needing the real runtime.
- Real runtime tests land in Phase 6.
