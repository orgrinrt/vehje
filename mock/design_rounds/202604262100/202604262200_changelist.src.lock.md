## Impl-time decisions (pre-committed)

1. **`clause-runtime-abi` crate-type = `["rlib", "cdylib"]`** —
   rlib so downstream Rust crates depend on the types; cdylib so
   the `extern "C"` symbols are callable from Zig at link time.
2. **Zig runtime in `mock/runtime-zig/`, not in `mock/crates/`** —
   it's not a Cargo member; lives alongside as a separate build
   system tree.
3. **No libloading dep in the R2 scaffold** — clause-runtime-driver
   declares it in DESIGN but adds the dep in its impl round.
4. **All nuked markers** — no real items anywhere until impl rounds.
