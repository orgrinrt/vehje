## Deliverables

### clause-resolve (new src)

1. `src/symbol.rs` — symbol surface. Roughly 60–90 lines.

   - `pub enum SymbolKind { Type, Value, Module, Import,
     Function, Const }`. `Copy + Clone + Eq + PartialEq + Hash +
     Debug`. `Default` → `Value`.
   - `pub struct Symbol { name: String, scope: ScopeId, node:
     NodeId, kind: SymbolKind }`. `Clone + Eq + PartialEq + Hash
     + Debug`.
   - Constructor: `Symbol::new(name: impl Into<String>, scope:
     ScopeId, node: NodeId, kind: SymbolKind) -> Self`.
   - Accessors: `name(&self) -> &str`, `scope(&self) -> ScopeId`,
     `node(&self) -> NodeId`, `kind(&self) -> SymbolKind`.

2. `src/scope.rs` — scope tree. Roughly 90–130 lines.

   - `pub struct Scope { parent: Option<ScopeId>, symbols:
     HashMap<String, Symbol> }`. `Clone + Debug + Default`.
   - Methods: `new(parent: Option<ScopeId>) -> Self`, `parent()
     -> Option<ScopeId>`, `insert(&mut self, name: String,
     symbol: Symbol) -> Option<Symbol>` (returns previous
     occupant if any), `lookup(&self, name: &str) -> Option<&Symbol>`.
   - `pub struct ScopeTree { scopes: Vec<Scope> }`. `Clone +
     Debug + Default` (default constructs a single root scope).
   - Methods: `new() -> Self` (allocates the root scope at index
     0 with `parent == None`), `root() -> ScopeId` (returns
     `ScopeId(0)`), `len() -> usize`, `get(id: ScopeId) ->
     Option<&Scope>`, `get_mut(id: ScopeId) -> Option<&mut
     Scope>`, `push(&mut self, parent: Option<ScopeId>) ->
     ScopeId` (appends a new scope, returns its id).

3. `src/resolved.rs` — resolved bundle. Roughly 50–80 lines.

   - `pub struct Resolved { ast: Ast, scopes: ScopeTree,
     resolution: Vec<Option<Symbol>> }`. `Clone + Debug +
     Default`.
   - Methods: `empty() -> Self` (empty AST + default ScopeTree +
     empty resolution vec), `new(ast: Ast, scopes: ScopeTree,
     resolution: Vec<Option<Symbol>>) -> Self`, `ast() -> &Ast`,
     `scopes() -> &ScopeTree`, `resolution() -> &[Option<Symbol>]`,
     `is_empty() -> bool` (true iff all three are empty /
     default-sized).

4. `src/manifest.rs` — manifest parser stub. Roughly 60–90 lines.

   - `pub struct Manifest { crate_name: String, version: String,
     dependencies: Vec<String> }`. `Clone + Debug + Default`.
   - Accessors: `crate_name() -> &str`, `version() -> &str`,
     `dependencies() -> &[String]`.
   - `pub fn parse_manifest(bytes: &[u8]) -> Result<Manifest,
     ManifestError>`:
     - Empty input → `Ok(Manifest::default())`.
     - Otherwise → `Err(ManifestError::NotImplemented)`.

5. `src/error.rs` — error carriers. Roughly 70–110 lines.

   - `pub enum ResolveError { UnresolvedIdentifier { name:
     String, span: Span }, DuplicateDefinition { name: String,
     span: Span, prev_span: Span } }`. `Clone + Eq + PartialEq +
     Hash + Debug`.
   - `impl From<ResolveError> for Diagnostic` — emits
     `Severity::Error` with a static placeholder message per
     variant (`"unresolved identifier"`,
     `"duplicate definition"`); follow-up rounds refine messages.
   - `pub enum ManifestError { Parse { message: &'static str },
     NotImplemented }`. `Copy + Clone + Eq + PartialEq + Hash +
     Debug`.

6. `src/resolver.rs` — resolver driver. Roughly 60–90 lines.

   - `pub struct Resolver { scopes: ScopeTree, current: ScopeId }`.
     `Clone + Debug`.
   - Methods: `new() -> Self` (fresh `ScopeTree`, cursor at
     root), `scopes() -> &ScopeTree`, `current_scope() -> ScopeId`.
   - `pub fn resolve(mut self, ast: &Ast) -> Result<Resolved,
     ResolveError>` — skeleton stub:
     - Does not walk the AST this round.
     - Returns `Ok(Resolved::new(*ast, self.scopes, vec![None;
       ast.len()]))`.

7. `src/lib.rs` — top-level entry. Roughly 40–60 lines.

   - Crate-level doc comment (no `#![no_std]` — this crate is

   - `#![deny(unused, unreachable_code, unused_must_use,
     unused_imports, dead_code)]` matching sibling crates.
   - `pub mod symbol;`, `pub mod scope;`, `pub mod resolved;`,
     `pub mod manifest;`, `pub mod error;`, `pub mod resolver;`.
   - Re-exports: `Symbol`, `SymbolKind` from `symbol`; `Scope`,

     `Manifest`, `parse_manifest` from `manifest`;

   - Re-exports: `NodeId`, `ScopeId`, `Span`, `Diagnostic` from

## Impl-time decisions (pre-committed)

1. **`std` is used, not `no_std`.** Resolve is a host-side
   compiler phase; `HashMap` / `Vec` / `String` are fine.
   Embedded / `no_std` discipline stays on `clause-ir`,
   `clause-lex`, `clause-syntax`.
2. **`Symbol::name` is owned `String`.** Interning is BACKLOG.
   This keeps the skeleton obvious; once interning lands,
   `Symbol` becomes `Copy`.
3. **`ScopeTree` uses a `Vec<Scope>` keyed by `ScopeId(u32)`.**
   No arena abstraction yet; the existing `ScopeId` from
   `clause-ir` plays the role directly.
4. **`ScopeTree::new()` pre-allocates a root scope at index 0.**
   Caller always has a valid `root()` to start from; no
   "unrooted tree" state.
5. **`Resolver::resolve` does NOT walk the AST.** Returns a
   `Resolved` with a `None`-filled `resolution` vec of length
   `ast.len()`. Each deferred resolution rule flips a subset of
   those to `Some(Symbol)` in its own follow-up round.
6. **`parse_manifest` is a two-arm stub.** Empty → default;
   non-empty → `NotImplemented`. No attempt at partial parsing.
7. **`From<ResolveError> for Diagnostic`** emits
   `Severity::Error` with a `&'static str` placeholder per
   variant; full message rendering lands alongside the resolution
   rule that produces the error.
