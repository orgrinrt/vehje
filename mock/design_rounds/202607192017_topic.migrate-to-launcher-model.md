**Date:** 2026-07-19
**Phase:** TOPIC
**Scope:** Repo-wide build/tooling. Migrate vehje from the dissolved mockspace proxy + `build.rs` bootstrap to the launcher + pin model.

# Current state

vehje adopts mockspace through the old model: each crate carries a `build.rs`
that calls `mockspace::bootstrap::bootstrap_from_buildscript()`, `mock/Cargo.toml`
declares a `mockspace` build-dependency, `.cargo/config.toml` holds a `cargo mock`
alias pointing at `target/mockspace-proxy`, and the config lives at
`mock/mockspace.toml`. The engine is resolved and built as a proxy crate under
`target/`.

# Changes proposed

Move to the launcher + pin model that mockspace now ships:

- The config relocates to a single repo-root `mockspace.toml` carrying
  `mock_dir = "mock"` and a `mockspace_branch = "dev"` pin. The standalone
  `cargo-mock` launcher (installed once, globally) reads the pin, builds the
  pinned engine into its shared cache, and runs it. A repo has exactly one
  mockspace.toml.
- The old plumbing is deleted, not kept alongside: the 11 `build.rs` bootstrap
  files, the `mockspace` build-dependency, the `.cargo` alias, and the
  `target/mockspace-proxy` artifact all go.
- The `[lint-crates]` stack-lints pack pins to `branch = "dev"` so its
  lint-rules matches the dev-pinned engine.

No design docs or source logic change; this is a build/tooling migration. The
source-side changelist enumerates the file removals and edits.
