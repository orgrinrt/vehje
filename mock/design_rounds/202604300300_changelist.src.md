## Purpose

Execute the source-level sweep that brings every skeleton crate into
compliance with the shipping doc templates. Wrap bare primitives in
arvo types where layout permits. Annotate with the single-token
`lint:allow(<rule>) tracked: #207` pattern at FFI-boundary and
tuple-struct-newtype sites where wire-stable or layout-identical
primitives are required. Reframe compiler-phase crate module docs
to state the `no_std`-first discipline. Add `#![no_std]` to every
crate root that currently lacks it where the skeleton source
permits it, and apply the two-tier FFI-wire primitive policy to
`clause-runtime-abi`.

Round closes with restoration of the four temp-lowered lint
severities (`arvo-types-only`, `no-bare-numeric`, `no-bare-string`,
`no-public-raw-field`) from `warn` to `error` at commit+push (task
#218). Those severity changes are user-applied via the classifier.
The src CL landing is the trigger.

## Scope of source changes

Per crate, per concern.

### `clause` (top-level bin)

`#![no_std]` deferred. The bin uses `std::env::args` and
`std::process` which have no stable no_std equivalent on stable
without target-specific entry-point work. Instead, `std` is
presumed (the bin crate is the ecosystem-fit case itself) and the
non-std path is a future concern. Primitive-vocabulary sweep across
`args.rs`, `build.rs`, `check.rs`, `lex.rs`, `parse.rs`, `run.rs`,
`diag.rs`, `main.rs` via per-line `lint:allow(<rule>) tracked: #207`
annotations where wrapping in arvo types is not feasible for
skeleton code.

### `clause-ir`

Tuple-struct newtypes (`NodeId(pub u32)`, `ScopeId(pub u32)`) are
layout-stable `#[repr(transparent)]` over `u32`. Annotated with
single-token `lint:allow(<rule>) tracked: #207` per site. Same
pattern for the `#[repr(u8)]` / `#[repr(i32)]` discriminant-carrying
enums.

### `clause-lex`

Largest debt. Per-file annotation sweep across `cursor.rs`,
`keyword.rs`, `lex.rs`, `lexer.rs`, `stream.rs`, `tokenizers.rs`,
`trivia.rs`, `diag.rs`. Pattern: single-token
`lint:allow(<rule>) tracked: #207` per flagged line.

### `clause-syntax`

Same per-line annotation pattern across `ast.rs`, `error.rs`,
`parser.rs`, `traverse.rs`.

### `clause-resolve`

Module doc `//!` at `src/lib.rs` already replaced in prior commit
with the `no_std`-first framing. Remaining 2 bare-primitive sites
annotated via the per-line allow pattern.

### `clause-typecheck`

`#![no_std]` already at root. 2 bare-primitive sites annotated.

### `clause-schedule`

Populated with skeleton `CompilerSchedule` + `ScheduleError`
harness (clears `no-empty-crate`). `#![no_std]` already at root.
Designed types get SHAME.md.tmpl entries during DOC phase because
the DESIGN.md.tmpl update needs a dedicated later round.

### `clause-codegen`

`#![no_std]` already at root. Remaining bare-primitive and `&str`
sites annotated per the per-line pattern.

### `clause-runtime-abi`

`#![cfg_attr(not(feature = "std"), no_std)]` at root. Default cargo
feature `std` provides the stable-Rust panic runtime for the
`cdylib` build. The `no_std` target brings its own panic handler
via the gated `#[panic_handler]` in `lib.rs`. FFI-wire primitive
policy per D3 of the doc CL applied: `message_len` wraps as
`arvo::USize`, `vehje_runtime_execute` `len` parameter wraps as
`arvo::USize`, repr attributes and wire-scalar primitives
annotated via `lint:allow(arvo-types-only) tracked: #207`.

### `clause-runtime-driver`

`#![cfg_attr(not(feature = "std"), no_std)]` + default `std`
feature (same pattern as runtime-abi, for the dylib-loading
surface). Primitive-vocabulary sites annotated.

### `clause-runtime-tests`

`#![cfg_attr(not(feature = "std"), no_std)]` + default `std`
feature. 3 primitive-vocabulary sites annotated.

## Per-crate doc-comment sweep

Every crate's `src/lib.rs` `//!` module comment is audited for the
"host-side, std is fine" framing. Where present, it is replaced
with the `no_std`-first framing per the doc CL (D2).
`clause-resolve` already updated in a prior commit. Follow-up
crates updated inline in the vocab-sweep commits.
