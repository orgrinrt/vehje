## CHANGE: enable `feature(const_trait_impl)` in str_const-using tests

Files: `crates/vehje-resolve/tests/{resolve_errors,symbol_types}.rs`
Verification: `grep -c "#!\[feature(const_trait_impl)\]" mock/crates/vehje-resolve/tests/{resolve_errors,symbol_types}.rs` returns 1 each. ## CHANGE: USize-wrap bare integer literals at FFI boundaries

Files: `crates/vehje-runtime-abi/tests/{exports,abi_types}.rs`
Verification: `grep -n "arvo::USize" mock/crates/vehje-runtime-abi/tests/{exports,abi_types}.rs` shows three matches (1 in exports.rs at line 23, 2 in abi_types.rs at lines 34 and 41).

Before:
- `vehje_runtime_execute(_, _, 0)` (exports.rs:23)
- `message_len: message.len()` (abi_types.rs:34)
- `assert_eq!(diag.message_len, message.len())` (abi_types.rs:41)

## CHANGE: replace `Some/None` with `Maybe::Is/Isnt`

Files: `crates/vehje-syntax/tests/ast_types.rs`, `crates/vehje-lex/tests/{cursor,mixed,operators,whitespace}.rs`
Verification: `! grep -nE "(Some|None)\(" mock/crates/vehje-syntax/tests/ast_types.rs` returns no match (or matches only inside string literals); same check across the four lex test files. Each file gains `use notko::Maybe;` if not already present.

The lex `whitespace.rs` test consumed `lx.next().is_none()`; migrated to `lx.next().isnt()` per notko's pinned-API predicate name.

## CHANGE: migrate parse() callers to take a sink

Files: `crates/vehje-syntax/tests/{empty_input,single_literal,unexpected_token}.rs`
Verification: All three files compile under `cargo check --test {name}`. Each file defines a small inline `ErrSink` struct that impls `hilavitkutin_api::{Push, Len}` over `SyntaxError`. The `empty_input` and `single_literal` use a counter-only sink; `unexpected_token` uses a bounded `ErrSink<4>` with `MaybeUninit` storage so tests can read back error kinds.

The new shape:
```rust
let mut errs = ErrSink::default();
let ast = parse(&tokens, &mut errs).expect("...");
```
