# Topic: rehab vehje engine + runtime tests past arvo Round D + Maybe surface drift

## Scope

Test-side mechanical migration after the library-side adoption in
round 202605110100 (#411). The library compiles green; tests reveal
several sibling drifts beyond the must_use Maybe pattern:

1. **`Maybe` replaces `Option` everywhere across substrate-public APIs.**
   Tests that destructured `Some(x) / None` against a `Maybe<T>`
   return need migration to `Maybe::Is(x) / Maybe::Isnt`.
2. **`Outcome` replaces `Result` for the substrate's load-bearing
   error carriers.** Tests that wrote `Err(LoaderError::...)` against
   an `Outcome<T, E>` return need `Outcome::Err(...)`.
3. **`USize` replaces bare `usize` at FFI boundaries.** Tests that
   constructed `VehjeDiagnostic { message_len: message.len(), ... }`
   need `arvo::USize(message.len())` because the field is now `USize`.
   Same for `vehje_runtime_execute(_, _, 0)` whose `len: USize`
   parameter rejects a bare `0`.
4. **`#![feature(const_trait_impl)]`** at the top of test files that
   expand `str_const!()` macros into `static` blocks. The macro's
   expansion calls `Bits::<28>::from_narrowed` which is `[const]`
   (conditionally const), and conditionally-const calls in static
   contexts require the unstable feature gate.
5. **`Cursor::bump_byte()` is `must_use`** because `notko::Maybe<u8>`
   is `must_use`. Test discard sites need explicit `let _ = ...`.

The work mirrors hilavitkutin's #399 round 202605110000 in shape and
discipline.

## Decisions

1. **Bounded `ErrSink<N>` helper inside each parser test file.**
   `vehje-syntax::parse(tokens, &mut dyn DiagnosticSink<SyntaxError>)`
   takes a sink. Tests need a small sink that counts pushes (for the
   tests that just check `errs.len()`) plus optionally records the
   error kind (the `unexpected_token` test). Inline definition keeps
   each file self-contained without a shared test-helper crate.

2. **`arvo` as a `[dev-dependencies]` entry on vehje-syntax and
   vehje-runtime-tests.** Both crates need `arvo::USize` only at
   test time; the published surface stays unchanged. Cleaner than
   adding a workspace-wide bare-numeric helper.

3. **`#![feature(const_trait_impl)]` at the per-test crate root**
   instead of editing the consumer crate's `lib.rs`. Per-test scope
   matches how hilavitkutin's str-using tests (and the analogous
   round 202605110000) handle the same problem.
