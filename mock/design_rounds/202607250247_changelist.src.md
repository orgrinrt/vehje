# Source changelist: grade-region must_use soundness fix

**Round:** 202607250247
**Phase:** IMPL
**Scope:** vehje-ir (GradeTable::set), vehje-typecheck (check propagation + CheckError variant + red test).

## vehje-ir

### CHANGE: `GradeTable::set` gains `#[must_use]`
File: `mock/crates/vehje-ir/src/grade.rs`
Add `#[must_use = "a false result means the grade region was too small and the write did not land"]` to `set`. Its `Bool` return can no longer be silently discarded under `deny(unused_must_use)`.
Verification: `grep -q 'must_use' mock/crates/vehje-ir/src/grade.rs`.

## vehje-typecheck

### CHANGE: `CheckError` gains `GradeRegionFull`
File: `mock/crates/vehje-typecheck/src/lib.rs`
Add `GradeRegionFull { at: NodeRef }` to `CheckError`: the grade region is smaller than the node arena, so a node's grade could not be recorded.
Verification: `grep -q 'GradeRegionFull' mock/crates/vehje-typecheck/src/lib.rs`.

### CHANGE: `check` propagates a grade-region set failure
File: `mock/crates/vehje-typecheck/src/lib.rs`
The `grades.set(at.index(), grade)` at the fold tail returns `Err(CheckError::GradeRegionFull { at })` when the write does not land, instead of discarding the result.
Verification: `grep -q 'GradeRegionFull { at }' mock/crates/vehje-typecheck/src/lib.rs && cargo test -p vehje-typecheck`.

### CHANGE: red test for a too-small grade region CREATE
File: `mock/crates/vehje-typecheck/src/lib.rs`
A `check` run over a program with a grade region smaller than the node count asserts `Err(CheckError::GradeRegionFull { .. })`, not `Ok`. Fail-first: it fails until the propagation lands.
Verification: `cargo test -p vehje-typecheck`.
