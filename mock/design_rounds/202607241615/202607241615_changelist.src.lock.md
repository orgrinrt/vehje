## CHANGE: `vehje-ir/src/hash.rs` module header names the manifest as a word-fold consumer

File: `mock/crates/vehje-ir/src/hash.rs` (lines 3 to 7, the `//!` header).

The header states "One definition, two consumers: hash-consing in `vehje-lower` and the manifest in `vehje-runtime-gen`." This is the stale claim the audit flagged (Leroy finding 9, SPJ F8): the manifest in `vehje-runtime-gen` does not consume this word-fold, it keys cross-artifact identity on a byte-image hash (`arvo_hash::xxhash3_64` over the serialized slice bytes), which the same file's body states correctly at lines 12 to 14. The header contradicts its own body in the direction that conflates within-stage structural identity with cross-artifact identity, which is unsound.

Correction: rewrite the header so this word-fold's only consumer is within-stage hash-consing in `vehje-lower`, and both the manifest in `vehje-runtime-gen` and `vehje-fixpoint`'s incremental dedup key on the byte-image hash for cross-artifact identity. Doc-comment only; no code, no signatures, no types change.

Verification: `grep -n "two consumers" mock/crates/vehje-ir/src/hash.rs` returns no match after the change; `grep -n "within-stage consumer" mock/crates/vehje-ir/src/hash.rs` returns one match; the body's byte-image statement (lines 12 to 14) is unchanged.

## CHANGE: mark the unconstructed CFG-residual surface with a greppable `// FIXME:`

File: `mock/crates/vehje-runtime-abi/src/wire/residual.rs` (at the `BlockTable` definition, near line 122).

The `Block`, `Function`, and `BlockTable` types are the designed residual control-flow-graph shape, but no producer constructs them yet (the lowering from `vehje_ir::Node` into blocks is unbuilt, downstream of `vehje-lower`'s `Anf` which names the join points). The audit noted the gap carries no `// FIXME`, so a FIXME-enumeration pass is blind to it. Add a greppable `// FIXME:` comment at the `BlockTable` definition naming the owed producer, per the mark-placeholders-fixme discipline. Comment only; the types, their fields, and their impls are unchanged (they are the designed shape, not dead code to remove).

Verification: `grep -n "FIXME" mock/crates/vehje-runtime-abi/src/wire/residual.rs` returns at least one match naming the owed `Node`-into-blocks lowering.
