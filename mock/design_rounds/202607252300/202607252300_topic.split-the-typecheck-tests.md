# Topic: split the typecheck tests to clear the file-size gate

**Date:** 2026-07-25
**Phase:** TOPIC
**Scope:** `vehje-typecheck` file organisation only. No behaviour changes.

The Perform round added three tests to `vehje-typecheck`: the two that prove the effect scope chain (a handled
operation never reaches the mask, an unhandled one does) and the one that proves the escape refusal. They are
the right tests and they put the file at 448 non-blank non-comment lines against a 400-line push gate.

The gate is correct and the fix is the one the rule names: split. The seam is the obvious one, tests to a
sibling module, which is the same move `vehje-lower` and `vehje-runtime-driver` already took for the same
reason. The handler machinery was already split into its own module during the Perform round, so this is the
second and last cut the crate needs.

Nothing about the design changes, which is why this round exists separately rather than riding inside a larger
one: a round whose whole content is "move lines between files" should be legible as exactly that.
