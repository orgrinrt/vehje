## Purpose

Ship the skeleton scaffolding for the four Phase 6 runtime units:

1. `clause-runtime-abi` — the C-ABI shim crate. `cdylib + rlib`.
   Exposes `#[repr(C)]` types and `extern "C"` entry points that
   the Zig runtime (and any other runtime backend) implements.
2. `clause-runtime-driver` — compiler-side orchestrator. Locates
   the runtime dylib via a `RuntimeLoader`, returns a boxed
   `RuntimeHandle` trait object, and drives `execute(input)`
   calls through that handle.
3. `clause-runtime-tests` — integration-test harness crate.
   Skeleton round: a single round-trip test that asserts the
   driver returns `DriverError::NotImplemented` because no
   runtime is loaded yet.
4. `mock/runtime-zig/` — the Zig tree. Separate from the Rust
   workspace; has its own `build.zig`, `src/main.zig`,
   `README.md`, and `.gitignore`. Ships stubbed `export fn`
   entrypoints matching the `extern "C"` signatures on the
   Rust side. Mockspace does not build this tree — it ships
   source but cargo / mockspace lints ignore the `.zig` files.

Without this round, the three `clause-runtime-*` crates are
nuked stubs (literally `//! nuked. Rewrite from design docs.`)
and the Zig tree has a bare two-function stub with no build
integration story. With it, every deferred runtime feature
(real dlopen integration, real interpreter, diagnostic mapping,
panic catching at FFI boundary, Zig test suite, …) lands on top
of a stable harness as its own follow-up round.

This is the exact skeleton-pattern established by
clause-resolve / clause-typecheck / clause-codegen: one round
for the harness, one round per deferred real body.

## Scope adjustment vs R2

R2 (2026-04-26) finalised the runtime-split architecture:

- 3 Rust crates with the names shipped here.
- Zig sibling tree at `mock/runtime-zig/`.
- Boundary: `#[repr(C)]` + `extern "C"` + dlopen dispatch.
- `abi_version: u32` first field on every struct crossing the
  boundary.
- `AbiSpan`, `AbiToken`, `AbiNode`, `AbiDiagnostic` as the
  ABI-mirror type surface (mirrors of `clause-ir` types).
- `extern "C"` entry points: init / shutdown / invoke_macro /
  eval_scratch / expand_generative / last_error.

This skeleton round ships a narrower surface that still
satisfies the R2 invariants:

- `clause-runtime-abi` exports three stable `extern "C"`
  entries (`clause_runtime_new`, `clause_runtime_free`,
  `clause_runtime_execute`) plus the `#[repr(C)]` type surface
  for opaque handle + result code + diagnostic.
- Full `AbiSpan` / `AbiToken` / `AbiNode` / `AbiDiagnostic`
  mirror types are deferred BACKLOG; this round ships the
  minimal `ClauseDiagnostic` shape (span, message pointer,
  kind) and leaves the richer mirrors for the round that
  wires the real interpreter.
- `clause-runtime-driver` ships the `RuntimeLoader` +
  `RuntimeHandle` trait + `DriverError` / `LoaderError` enums;
  real `dlopen` / `libloading` integration is BACKLOG.
- `clause-runtime-tests` ships a single-file smoke harness;
  real dlopen-against-stub-dylib integration is BACKLOG.
- Zig tree ships three `export fn` stubs matching the Rust
  side's `extern "C"` entries; real interpreter body is
  BACKLOG.

Exactly the same pattern used by clause-resolve /
clause-typecheck / clause-codegen skeleton rounds: one round
for the harness, one round per deferred real body.

## Deliverables this round

### clause-runtime-abi — C ABI surface

- `src/lib.rs` — `#![no_std]` crate root. Re-exports types from
  submodules. No heap, no std. Crate doc comment explaining the
  C ABI shim stance + the deferred R2 retrofit (full
  `AbiSpan` / `AbiToken` / `AbiNode` mirrors).
- `src/result.rs` — `ClauseResult` `#[repr(i32)]` enum. Variants:
  `Ok = 0`, `Err = -1`, `NullHandle = -2`, `InvalidInput = -3`.
  Derives `Copy + Clone + Eq + PartialEq + Debug`.
- `src/handle.rs` — `ClauseRuntime` opaque handle. Declared as
  `#[repr(C)] pub struct ClauseRuntime { _private: [u8; 0] }`
  — the standard opaque-handle idiom for C ABI. Consumers never
  construct or inspect; only operate through `*mut ClauseRuntime`.
- `src/diagnostic.rs` — `ClauseDiagnostic` `#[repr(C)]` carrier:
  `span: AbiSpan`, `message: *const u8`, `message_len: usize`,
  `kind: ClauseDiagnosticKind`. `ClauseDiagnosticKind` is
  `#[repr(i32)]` with `Error = 0`, `Warning = 1`, `Info = 2`.
  `AbiSpan` is a flat `#[repr(C)] struct { file: u32, start: u32, end: u32 }`
  (minimal R2-mirror; full `FileId` wrapping is BACKLOG).
- `src/exports.rs` — three `extern "C"` functions:
  - `pub extern "C" fn clause_runtime_new() -> *mut ClauseRuntime`
    — stub: returns `core::ptr::null_mut()`.
  - `pub extern "C" fn clause_runtime_free(rt: *mut ClauseRuntime)`
    — stub: no-op. Caller expected to drop a null / valid
    pointer; the free function accepts null safely.
  - `pub extern "C" fn clause_runtime_execute(rt: *mut ClauseRuntime, input: *const u8, len: usize) -> ClauseResult`
    — stub: returns `ClauseResult::Err`.

### clause-runtime-driver — orchestrator

- `src/lib.rs` — crate root. Re-exports. Crate doc comment on
  the orchestrator role + `dlopen` plan (BACKLOG).
- `src/error.rs` — two enums.
  - `LoaderError { NotImplemented, SymbolNotFound, LoadFailed }`.
  - `DriverError { NotImplemented, HandleNull, ExecuteFailed { code: i32 } }`.
  - Both derive `Clone + Eq + PartialEq + Debug`. `DriverError`
    is not `Copy` because `ExecuteFailed` carries data the
    caller may want to consume via pattern-match.
- `src/handle.rs` — `RuntimeHandle` trait.
  - `pub trait RuntimeHandle: Send + Sync { fn execute(&self, input: &[u8]) -> Result<Vec<u8>, DriverError>; }`.
  - No stub impls shipped; concrete `DlopenHandle` lands in
    follow-up round.
- `src/loader.rs` — `RuntimeLoader` + `load` entry.
  - `pub struct RuntimeLoader;` (ZST).
  - `impl RuntimeLoader { pub fn load(path: &std::path::Path) -> Result<Box<dyn RuntimeHandle>, LoaderError> { Err(LoaderError::NotImplemented) } }`.
- `src/driver.rs` — `RuntimeDriver` placeholder struct.
  - `pub struct RuntimeDriver { _private: () }`.
  - `impl RuntimeDriver { pub fn new() -> Self { Self { _private: () } } }`.
  - Doc comment: the driver is currently a placeholder shell;
    real state (handle, per-session arena, cached diagnostics)
    lands with the dlopen-integration round.

### clause-runtime-tests — integration harness

- `src/lib.rs` — crate root. Re-exports from
  `clause-runtime-abi` + `clause-runtime-driver` for
  convenience. Crate doc comment explaining the harness scope.
- Single `test_runtime_roundtrip` fn in the crate that attempts
  to load a runtime via `RuntimeLoader::load` and verifies the
  returned error is `LoaderError::NotImplemented`. Exposed as a
  `pub fn` so both unit tests and integration tests can share.

### Zig runtime (`mock/runtime-zig/`)

- `build.zig` — already exists. Expand to declare a named
  dylib target (`clause_runtime`) with the R2 output-path
  convention and both target + optimise options.
- `src/main.zig` — new file replacing `src/runtime.zig`. Three
  `export fn` stubs matching the Rust ABI:
  - `export fn clause_runtime_new() ?*anyopaque` returns null.
  - `export fn clause_runtime_free(rt: ?*anyopaque) void` no-op.
  - `export fn clause_runtime_execute(rt: ?*anyopaque, input: [*]const u8, len: usize) ClauseResult` returns `.{ .code = -1 }`.
  - Defines `pub const ClauseResult = extern struct { code: i32 };`
    matching the Rust `ClauseResult` layout.
- `src/runtime.zig` is retired by `src/main.zig`; the existing
  stub is superseded by the new entries.
- `README.md` — new file (promoted from `README.md.tmpl`
  expansion) explaining the tree: what it is, how to build via
  `zig build`, where the dylib lands (`zig-out/lib/libclause_runtime.*`),
  and how the Rust side locates it (env var
  `CLAUSE_RUNTIME_PATH` or conventional path, both BACKLOG).
- `.gitignore` — new file: `zig-out/`, `zig-cache/`.
- `BACKLOG.md` — new file (not `.tmpl`; the Zig tree is outside
  mockspace's tmpl-expansion scope).

### Tests

`mock/crates/clause-runtime-abi/tests/`:

- `tests/abi_types.rs` — 4 tests:
  - `clause_result_ok_is_zero` — `ClauseResult::Ok as i32 == 0`.
  - `clause_result_err_is_negative` — `ClauseResult::Err as i32 == -1`.
  - `clause_result_variants_distinct` — each pair of variants
    compares unequal.
  - `clause_diagnostic_construction` — build a
    `ClauseDiagnostic` from raw parts; `kind` round-trips.
- `tests/exports.rs` — 3 tests:
  - `new_returns_null_in_skeleton` — `clause_runtime_new()`
    returns `null_mut()`.
  - `free_null_does_not_crash` — `clause_runtime_free(null_mut())`
    runs without panic.
  - `execute_null_returns_err` — `clause_runtime_execute(null_mut(), ptr, 0)`
    returns `ClauseResult::Err`.

`mock/crates/clause-runtime-driver/tests/`:

- `tests/loader.rs` — 2 tests:
  - `load_nonexistent_returns_not_implemented` —
    `RuntimeLoader::load(Path::new("/nonexistent"))` returns
    `Err(LoaderError::NotImplemented)` (not `LoadFailed`, since
    the skeleton never attempts a real load).
  - `load_bogus_returns_not_implemented` — same for a path
    string that would be a bogus lib name.
- `tests/error_types.rs` — 4 tests:
  - `loader_error_variants_distinct` — each pair of
    `LoaderError` variants compares unequal.
  - `driver_error_variants_distinct` — same for `DriverError`.
  - `driver_error_execute_failed_carries_code` — construct
    `DriverError::ExecuteFailed { code: -7 }`; extract via
    pattern match.
  - `loader_error_construction` — construct each variant;
    pattern match is exhaustive.

`mock/crates/clause-runtime-tests/tests/`:

- `tests/smoke.rs` — 2 tests:
  - `test_runtime_roundtrip_returns_not_implemented` — calls
    the harness `test_runtime_roundtrip()` fn; asserts the
    error is `LoaderError::NotImplemented`.
  - `types_are_accessible` — verifies that `ClauseResult`,
    `ClauseDiagnostic`, `RuntimeDriver`, `RuntimeLoader`
    symbols can all be named from the crate's public surface.

Total: 15 tests.

## Deferred (BACKLOG, one follow-up round per entry)

### clause-runtime-abi BACKLOG

- Full `ClauseRuntime` state struct body (currently opaque).
- Full `AbiSpan`/`AbiToken`/`AbiNode` mirrors of `clause-ir`
  types (R2 entry-point payload shapes).
- Real `clause_runtime_execute` wiring (hand off to loaded
  runtime).
- Error code → `ClauseDiagnostic` translation layer.
- Panic handling at FFI boundary (`catch_unwind`).
- Thread safety document + Send/Sync guarantees on ABI types.
- Little-endian guard (R2 invariant — refuse big-endian load).

### clause-runtime-driver BACKLOG

- `dlopen` / `libloading` integration (real dynamic library
  loading behind the `RuntimeLoader::load` API).
- Environment-variable convention (`CLAUSE_RUNTIME_PATH`).
- Fallback to embedded runtime when env var unset.
- Runtime-handle lifecycle (multi-runtime; per-session
  isolation).
- Windows / Linux / macOS dylib naming conventions
  (`libclause_runtime.{so,dylib,dll}`).
- `AbiDiagnostic` → `clause_ir::Diagnostic` mapping.
- Integration with clause-schedule pass DAG (macro-expansion
  pass, generative-expansion pass).

### clause-runtime-tests BACKLOG

- Minimal Zig stub-dylib built into `tests/zig_stub/` for real
  dlopen round-trip tests.
- Struct-shape assertions (`size_of`, `align_of`, `offset_of`)
  on every `#[repr(C)]` type in `clause-runtime-abi`.
- Enum-discriminant stability tests (assert every public enum's
  discriminant values).
- ABI-version monotonic-increase guard.
- Fuzz harness over the ABI surface.
- Regression tests for crash-recovery semantics.

### Zig runtime BACKLOG

- Real execution engine (IR interpreter; later JIT).
- Arena allocator (per-session state, no global allocator).
- Diagnostic emission mirroring Rust `ClauseDiagnostic`.
- Zig test suite (`zig build test`).
- Cross-compilation support (`zig build -Dtarget=...`).
- TokenStream emitter — macro return path.
- Scratch-var evaluator — compile-time expression folding.
- Generative-expansion body (R2 generative-pipeline research).
