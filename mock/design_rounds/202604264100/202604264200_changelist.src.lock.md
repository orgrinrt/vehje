## Impl-time decisions (pre-committed)

1. **`clause-runtime-abi` is `no_std`, no alloc.** FFI shim stays
   bare-types. Re-exports are by module path.
2. **`ClauseRuntime` is `#[repr(C)] struct { _private: [u8; 0] }`.**
   Standard opaque-handle idiom. Consumers never construct or
   inspect.
3. **`ClauseResult` is `#[repr(i32)]` with `Ok = 0, Err = -1,
   NullHandle = -2, InvalidInput = -3`.** Zero / negative
   convention matches POSIX errno idiom; Zig side mirrors the
   same shape via `ClauseResult = extern struct { code: i32 }`.
4. **`ClauseDiagnostic` cannot derive `Eq + PartialEq + Hash`.**
   Raw pointer field forbids cheap derives; manual comparator
   (compare slices pointed to) is BACKLOG.
5. **`extern "C"` entries use `#[unsafe(no_mangle)]`
   (2024-edition syntax).** Workspace pins `edition = "2024"`.
6. **`clause-runtime-driver` keeps declared `clause-schedule`
   dep even though unused this round.** Follow-up round wires
   the runtime-pass into the schedule DAG; churning the dep in
   and out of Cargo.toml costs more than leaving it.
7. **`clause-runtime-tests` declares both `clause-runtime-abi`
   and `clause-runtime-driver`.** Re-exports from both for the
   harness fn + smoke test. Add `clause-runtime-driver` to the
   Cargo.toml.
8. **Zig tree keeps `src/runtime.zig` as the entry source file.**
   The R2 baseline `build.zig` points at `src/runtime.zig`;
   rewriting its body (instead of renaming to `src/main.zig`)
   is the minimum-churn path.
9. **`lint:allow(bare_collection)` on `Vec<u8>` returns.** The
   `RuntimeHandle::execute` return is `Result<Vec<u8>,
   DriverError>`; the `test_runtime_roundtrip` harness returns
   `Result<Vec<u8>, LoaderError>`. Both carry the ≥21-word
   justification matching the clause-typecheck /
   clause-codegen precedent.
