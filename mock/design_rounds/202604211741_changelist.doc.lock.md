# Doc Changelist: clause fallibility sweep

**Date:** 2026-04-21
**Phase:** DOC
**Scope:** `clause-codegen`, `clause-resolve`, `clause-runtime-driver`,
`clause-syntax` — doc templates only.

**Source topics:**
- 202604211741_topic.fallibility-sweep.md

## Purpose

Update the shipping-contract templates for the four clause phase
crates that name `Option` or `Result` in type signatures, so the
doc state matches the `Maybe` / `Outcome` substitution the source
CL will carry out. The `no-bare-option` / `no-bare-result`
principles were already documented in `mock/PRINCIPLES.md.tmpl`,
`mock/agent/rules/type-surface.md.tmpl`, and the type-surface-review
skill — no change to rules or principles.

Five template files in total. Every change swaps the outer shell
of a return type or field; every inner error-type name stays as
declared.
