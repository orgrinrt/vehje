## Impl-time decisions (pre-committed)

1. **`std` is used.** Typecheck is host-side (compiler phase);
   `Vec`, `String`, heap allocation all fair game. The `no_std`
   discipline stays on `clause-ir` / `clause-lex` /
   `clause-syntax`.
2. **`Validator` is instance-method, not associated-const.**
   Trait has `fn name(&self) -> &'static str` and `fn
   validate(&self, ctx: &ValidatorCtx) -> Vec<Diagnostic>`.
   Object-safe; works in `&dyn Validator`. The R4
   associated-const shape is deferred BACKLOG.
3. **`ValidatorCtx` carries only `resolved: &Resolved`.** Sink,
   workspace, config are BACKLOG.
4. **`ValidatorRegistry` is a ZST with associated const
   `VALIDATORS` + associated `run_all`.** No state. No
   constructor. Registry-expansion API (`register`) is BACKLOG.
5. **`VALIDATORS` ordering is fixed: `Strict1..Strict7`,
   `Coherence`, `OrphanRule`, `BindTargetShape`.** Consumers
   should not depend on ordering, but the test suite asserts it
   for this round to catch accidental reorders.
6. **Each validator body is `Vec::new()`, not `todo!()`.**
   Skeleton: `run_all` must not panic; tests must pass without
   stubbing unreachable arms.
7. **No arvo / arvo-bitmask use this round.** The Cargo.toml
   declares the deps (kept for the follow-up rounds that surface
   real access sets), but no code imports them. If this trips a
   `no-unused-deps` lint, move them to a future round; the
   skeleton stands on its own.
