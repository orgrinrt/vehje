`vehje-lower`'s `Anf::apply` is an unconditional no-op (`vehje-lower/src/lib.rs:387-393`). It is the one node-creating rewrite: A-normal form names every non-atomic intermediate in a fresh `Let`, and creating a `Let` is creating a node, which the redirecting `Rewrite` cannot do. This round turns it into the real node-creating catamorphism per the v1 design memo, with one deviation the memo predates: the fresh-binder mechanism is `hilavitkutin_sym::Generator<BinderDomain>` (shipped in the Sym binder flip), not the memo's Section 6 synthetic-`Str` reserved-flag-bit gensym. A minted binder carries kind `0b001`; a source name carries `0b000`; the two are never equal, so capture is structurally impossible and macro hygiene follows for free.

## The algorithm: flat ANF, no closures, no alloc

ANF is the standard two-function normalization (Flanagan, Sabry, Duba, Felleisen, PLDI 1993). The classic form expresses the evaluation context as a continuation closure; in `no_std` with no alloc and an append-only arena, the continuation is realized by building inner-to-outer against the arena and remembering the hoisted bindings in a bounded stack scratch. The output is **flat** ANF (a let-binding's value is never itself a let), not nested-let, which is what the memo's `normalize_term`/`atomize` pair produces.

Three functions read the input tree (indices `[0, k)`, through `rw.resolve` so the folded/shared view is honoured) and append fresh nodes (indices `[k, ..)`):

- `normalize_term(e) -> Maybe<NodeRef>`. ANF-normalizes a whole term that is its own evaluation context (the program root, a branch, a lambda/iter body, a match arm, a handle clause). It flattens `e` into a bounded list of hoist-bindings plus a tail expression, then wraps the bindings around the tail in reverse (the leftmost/first-evaluated binding becomes the outermost `Let`), and returns the wrapped root.
- `flatten(e, binds) -> Maybe<NodeRef>`. Appends `e`'s hoist-bindings to the shared `binds` accumulator and returns `e`'s tail: an atom, or a compound whose operands are all atoms. A `Let(x, v, body)` flattens by recording `(x, flatten-tail-of-v)` then flattening `body` (so let-chains flatten into one binding list). A compound (`Apply`, `Project`, `If`, `Iter`, `Match`, `Interp`, `Handle`, `Raw`) atomizes each operand and rebuilds the form over the atoms.
- `atomize(e, binds) -> Maybe<NodeRef>`. Returns an atom for `e`: if `e`'s tail is already an atom (`Var`/`Lit`), returns it unchanged (atoms are not hoisted, and an input atom node is reused by its `NodeRef`, no rebuild); otherwise mints a fresh binder `t` via `gen.mint()`, records `(t, tail)` in `binds`, and returns `Var(t)`.

Evaluation-context boundaries get a fresh `normalize_term` (their own binding list): the two `If` branches, a `Lambda` body, an `Iter` body, each `Match` arm, each `Handle` clause. Operand positions that are pure subexpressions (an `Apply` callee and args, a `Project` base, an `If`/`Iter`/`Match`/`Interp`/`Handle` scrutinee-or-value) are atomized into the current binding list.

### Why a `Var(t)` may be built before its `Let(t, ..)`

Building inner-to-outer means the innermost body (the atomized compound) is built first, then wrapped. A `Var(t)` for a hoisted operand is built during atomization, before the `Let(t, v, ..)` that binds it is built during the reverse wrap. This is sound because name resolution runs after ANF and matches a `Var` to its binder by `Sym` identity, not by construction order; the fresh `t` is the same `Sym` in both nodes.

## The no-alloc scratch: the operand-binding buffer

The hoist-bindings `(Sym, NodeRef)` for one `normalize_term` call, and the atom `NodeRef`s for one compound's operand list, need bounded contiguous storage with no allocation. `Builder::apply`/`match_`/`alloc_list` take a `&[NodeRef]` slice, so a compound's atoms must be contiguous before the form is built.

First landing: fixed stack buffers, `binds: [(Sym, NodeRef); BIND_CAP]` per `normalize_term` and `atoms: [NodeRef; ARG_CAP]` per compound, both with an exhaustion return of `Maybe::Isnt` when the cap is exceeded (the same no-alloc exhaustion contract as an arena-full `push`). `BIND_CAP` bounds the number of hoists per evaluation context and `ARG_CAP` bounds one form's arity; both are generous constants, bench-tunable, and their overflow is a loud `Isnt`, never a silent truncation. The memo's pool-resident scratch (an incremental `list_begin`/`list_push`/`list_end` arena primitive that writes the operand list directly into the caller-lent pool `[p, ..)`) is the follow-up that removes the arity cap; it is a vehje-ir arena addition and is noted as the refinement, not required for the first landing.

## The `Lower::lower` signature change

`Anf::apply` becomes:

```rust
pub fn apply(
    &self,
    builder: &mut Builder<'_>,          // node-creating access, not &Arena
    root: NodeRef,                       // input root, indexes [0, k)
    rw: &Rewrite<'_>,                    // read the folded/shared view
    gen: &mut Generator<BinderDomain>,   // fresh binder source
) -> Maybe<NodeRef>                      // the ANF root, Isnt on arena-full or generator-exhaustion
```

`Lower::lower` correspondingly takes a `&mut Builder` (it already runs the redirecting passes first, which only need `&Arena`, reachable via `builder.arena()`) plus a `&mut Generator<BinderDomain>`, and returns `Anf`'s fresh root as the program root instead of `rw.resolve(root)`. The ordering (macro-expand, fold, share, then ANF last) is already correct; only the final step changes from a discarded no-op to the returned root. One generator threads through `MacroExpand` and `Anf` so their fresh-name spaces cannot collide. Callers (`vehje/src/lib.rs`, the vehje-lower tests) provision a node arena and child pool sized for the linear ANF growth (memo Section 5: `>= 4*N` nodes and `>= 3*P` pool as a safe default; exact constant bench-tunable) and pass a fresh `Generator<BinderDomain>::new()`.

## The minted-binder wire encoding

The residual encoder currently resolves every binder to its interner text (`vehje-runtime-abi/src/encode.rs`, the FIXME added in the Sym flip). A minted binder (kind `0b001`) has no backing string, so `Interner::resolve` returns `Isnt`. This round resolves the FIXME: the wire format encodes a binder by its 32-bit `Sym` bits when it is not a string-domain handle (a minted binder), and by its resolved text when it is a source name, so a residual carrying minted binders round-trips.

## Termination and hygiene

Termination is structural: `flatten`/`atomize` recurse only into strictly-smaller input subterms, and `normalize_term` on a branch recurses into a strictly-smaller subterm. There is no fixpoint iteration; the fresh-binder counter is monotonic and never read as a loop bound. Against a finite caller-lent arena or an exhausted generator the pass stops early with `Maybe::Isnt`, the correct no-alloc exhaustion behaviour.

Hygiene is structural on the domain tag: a minted binder's `Sym` (kind `0b001`) is never equal to any source name's `Sym` (kind `0b000`), whatever their ids, so a hoisted `Let` can never capture a source variable and a source variable can never resolve to a hoisted binder. This is the generative-freshness conviction realized; ANF is its first client.

## Strict tests (fail-first)

Per the memo's test list, adapted to the `Sym` mechanism:

1. `anf_leaves_atoms_untouched`: normalizing `x` or a literal returns the input node and appends nothing.
2. `anf_hoists_a_compound_apply_arg`: `f(g(x))` normalizes to `let t = g(x) in f(t)`, with `t` a minted `BinderDomain` `Sym`.
3. `anf_flattens_nested_compounds`: a doubly-nested application flattens to a straight-line let-sequence, no let-bound value is itself a let.
4. `anf_flattens_let_chains`: an input `let a = .. in let b = .. in ..` stays a flat chain, not a nested-let.
5. `anf_branches_are_separate_contexts`: hoists inside an `If` branch stay inside that branch, not lifted above the `If`.
6. `anf_minted_binder_cannot_capture`: a hoisted binder's `Sym` has kind `0b001` and is unequal to a source name's `0b000`, asserted directly.
7. `anf_returns_isnt_on_arena_full`: too-small an arena returns `Isnt`, no panic, no corruption of the input region.
8. `anf_returns_isnt_on_scratch_overflow`: a form exceeding `ARG_CAP`/`BIND_CAP` returns `Isnt`, no truncation.

## Decision

Implement the flat ANF catamorphism above in `vehje-lower` with fixed-cap stack scratch (the pool-resident incremental-list primitive is the noted follow-up), change `Lower::lower` to `&mut Builder` + a `Generator<BinderDomain>`, resolve the encoder's minted-binder FIXME, and write the eight tests fail-first. No nested-let ANF, no closure, no alloc, no interner in the pass.
