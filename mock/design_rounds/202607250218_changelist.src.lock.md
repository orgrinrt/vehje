## vehje-runtime-abi

### CHANGE: keep the minted-binder encoder FIXME (safe graceful failure; full wire encoding is a tracked follow-up)
File: `mock/crates/vehje-runtime-abi/src/encode.rs`
A minted binder reaching the encoder already fails GRACEFULLY, not unsafely: `Interner::resolve` returns `Isnt` for a non-string-domain `Sym` (kind != `0b000`), so `serialize` returns `Isnt`, never corrupting the buffer. The Round-A FIXME (encode.rs:145-155) stays as the greppable marker; the full minted-binder wire encoding + decoder is the tracked follow-up. No source change this round.
