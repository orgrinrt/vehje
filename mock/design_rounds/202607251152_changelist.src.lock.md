# Source changelist: strings are values

**Round:** 202607251152
**Phase:** IMPL
**Scope:** the Zig runtime gains string values, a bytes-carrying operand, and a real session handle; the driver mirrors the operand record and the handle. No family is defined.

## The Zig runtime

### CHANGE: `Value` gains `str`
File: `mock/runtime-zig/src/runtime.zig`
A `str: []const u8` variant. The slice points into the residual image for a literal, or into the session scratch for a handler's result; both outlive the evaluation.
Verification: `grep -q 'str: \[\]const u8' mock/runtime-zig/src/runtime.zig`.

### CHANGE: `Image` reads the blob, and `LIT_STR` evaluates
File: `mock/runtime-zig/src/runtime.zig`
`Image` computes the blob base and length from the header and section sizes. `LIT_STR` reads the literal's offset and length, bounds-checks the span against the blob, and yields the slice. A span past the blob is `Corrupt`.
Verification: `grep -q 'LIT_STR =>' mock/runtime-zig/src/runtime.zig`.

### CHANGE: `VehjeScalar` becomes `VehjeOperand`, gaining `bytes`
File: `mock/runtime-zig/src/runtime.zig`
The record carries `tag`, `payload`, and `bytes`. For a scalar `bytes` is null and `payload` is the value; for a string `bytes` is the pointer and `payload` is the length. Renamed because it is no longer only scalars. Per the pre-1.0 rule the old name is deleted, not aliased.
Verification: `grep -q 'pub const VehjeOperand' mock/runtime-zig/src/runtime.zig && ! grep -q VehjeScalar mock/runtime-zig/src/runtime.zig`.

### CHANGE: struct `Session` CREATE, and the handle becomes real
File: `mock/runtime-zig/src/runtime.zig`
`Session` holds the caller-lent scratch and how much is used. `vehje_runtime_new(scratch, len)` returns a handle over it; `vehje_runtime_execute` takes the handle and uses its scratch; `vehje_runtime_free` releases nothing. A null handle means no scratch.
Verification: `grep -q 'pub const Session' mock/runtime-zig/src/runtime.zig`.

### CHANGE: a handler may return a string
File: `mock/runtime-zig/src/runtime.zig`
When the returned operand carries bytes, the runtime copies them into the session scratch and yields a slice of the copy. No scratch is `NoScratch`; too little is `ScratchFull`.
Verification: `grep -q 'ScratchFull' mock/runtime-zig/src/runtime.zig`.

### CHANGE: `marshal` writes a string value
File: `mock/runtime-zig/src/runtime.zig`
A string marshals with the `Str` tag and its bytes in the image blob, through the existing writer.
Verification: the round-trip test below.

## The driver

### CHANGE: `Scalar` becomes `Operand` with a bytes pointer; `new` takes scratch
File: `mock/crates/vehje-runtime-driver/src/runtime.rs`
The Rust mirror gains the bytes pointer and the rename. `NewFn` takes the scratch pointer and length. `Runtime::execute` and `execute_with_host` create the handle with a caller-lent scratch slice and free it after.
Verification: `grep -q 'pub struct Operand' mock/crates/vehje-runtime-driver/src/runtime.rs`.

## Tests (fail-first, strict)

Zig, in `mock/runtime-zig/src/runtime_test.zig`:

- A string literal evaluates to its bytes, read from the residual blob.
- A string literal whose span runs past the blob is `Corrupt`, not a read past the end.
- A string operand reaches a handler with its bytes intact, which is what a string standard library needs.
- A handler returns a string and the value survives the call, proving the scratch copy.
- Returning a string with no scratch is `NoScratch`, and with too little is `ScratchFull`.
- A string value marshals into a value image carrying the `Str` tag and the bytes.

Rust, in `mock/crates/vehje-runtime-driver/src/runtime/tests.rs`:

- The existing stand-in tests keep passing against the new operand shape and handle.
- An ignored end-to-end test: a program whose value is a string literal runs against the real artifact and the string comes back in the value image's blob.

Verification: `zig build test` and `cargo test -p vehje-runtime-driver --features dynamic` pass.
