## CHANGE: struct `Runtime` CREATE
File: `mock/crates/vehje-runtime-driver/src/runtime.rs` (new module)
`pub struct Runtime<'lib>` holding the loaded `Library` and the three resolved entry symbols, so a resolved symbol cannot outlive its library and a later call cannot fail on a missing one.

- `Runtime::open(path: &[u8]) -> Outcome<Library, DriverError>` loads the artifact. Loading and resolving are two steps because the resolved symbols borrow the library, so the caller owns the `Library` and binds the `Runtime` to it.
- `Runtime::bind(lib: &'lib Library) -> Outcome<Self, DriverError>` resolves `vehje_runtime_new`, `vehje_runtime_free`, and `vehje_runtime_execute` once, reporting `SymbolMissing` when any is absent.
- `Runtime::execute(&self, residual: &[u8], out: &mut [u8]) -> Outcome<USize, DriverError>` creates the runtime handle, calls the entry with a sink over `out`, frees the handle, and returns the committed byte count. A non-`Ok` result code is `ExecuteFailed`.

Verification: `grep -q 'pub struct Runtime' mock/crates/vehje-runtime-driver/src/runtime.rs`.

## CHANGE: the driver's transfer sink CREATE
File: `mock/crates/vehje-runtime-driver/src/runtime.rs`
A `#[repr(C)]` `SinkCtx` holding the lent buffer pointer, its capacity, and the committed length, plus the two `extern "C"` callbacks. `reserve` returns the buffer when the hint fits and null otherwise, which the runtime reads as backpressure; `commit` records what was written. The sink is assembled per call and never retained.
Verification: `grep -q 'extern "C" fn driver_reserve' mock/crates/vehje-runtime-driver/src/runtime.rs`.
