### Change S2 — src/main.rs

Single entry point. Parses `argv[1]` as the subcommand name and
dispatches. Unknown or missing subcommand prints the subcommand
list to stderr and exits `2`.

```rust
fn main() {
    let args: Vec<String> = std::env::args().collect();
    let code = match args.get(1).map(String::as_str) {
        Some("lex")   => clause::lex::run(&args[2..]),
        Some("parse") => clause::parse::run(&args[2..]),
        Some("check") => clause::check::run(&args[2..]),
        Some("build") => clause::build::run(&args[2..]),
        Some("run")   => clause::run::run(&args[2..]),
        Some(other)   => { eprintln!("clause: unknown subcommand: {other}"); print_usage(); 2 }
        None          => { print_usage(); 2 }
    };
    std::process::exit(code);
}
```

`Vec<String>` in `fn main` is tolerated under the lint-allow
envelope: `std::env::args` returns an iterator of `String`, and
the binary is host-side `std`. Collecting to a `Vec` and slicing
is the idiomatic shape. Add trailing
`// lint:allow(bare_collection) lint:allow(bare_string)
tracked: #73` on the `args` line.

### Change S4 — src/args.rs

Hand-rolled parser. Round-one surface is minimal:

```rust
/// Parse the remaining argv after the subcommand. Expects
/// exactly one positional: the input file path. Returns the
/// path or `Maybe::Isnt` if the positional is missing.
pub fn single_file_arg(rest: &[String]) -> notko::Maybe<&str> {
    match rest.first() {
        Some(path) => notko::Maybe::Is(path.as_str()),
        None => notko::Maybe::Isnt,
    }
}
```

Output the crate holds is a tiny helper; flag parsing comes
later per BACKLOG.

### Change S5 — src/lex.rs

The real body. Reads the file, builds a `Lexer`, pumps tokens,
prints them per the DESIGN format.

```rust
use clause_ir::{Diagnostic, FileId, TokenKind};
use clause_lex::{Lexer, Token};
use notko::Maybe;

pub fn run(args: &[String]) -> i32 {
    let path = match crate::args::single_file_arg(args) {
        Maybe::Is(p) => p,
        Maybe::Isnt => { eprintln!("clause lex: missing <file>"); return 2; }
    };
    let src = match std::fs::read_to_string(path) {
        Ok(s) => s,
        Err(e) => { eprintln!("clause lex: {path}: {e}"); return 2; }
    };
    let file = FileId::new(1);  // round-one: single-file input
    let mut lexer = Lexer::from_str(&src, file);
    let mut had_diag = false;
    let mut sink = |d: Diagnostic| {
        crate::diag::print(&src, &d);
        had_diag = true;
    };
    loop {
        match lexer.next_with_diag(&mut sink) {
            Maybe::Is(tok) => print_token(&src, &tok),
            Maybe::Isnt => break,
        }
    }
    if had_diag { 1 } else { 0 }
}

fn print_token(src: &str, tok: &Token) {
    let start = tok.span.start.0 as usize;
    let end = tok.span.end.0 as usize;
    let lit = &src.as_bytes()[start..end];
    let lit_s = core::str::from_utf8(lit).unwrap_or("<non-utf8>");
    let show_lit = matches!(
        tok.kind,
        TokenKind::Ident | TokenKind::IntLiteral | TokenKind::Keyword
    ) || is_operator_or_punct(tok.kind);
    if show_lit && !lit_s.is_empty() {
        println!("{start}..{end}  {:?}  {lit_s}", tok.kind);
    } else {
        println!("{start}..{end}  {:?}", tok.kind);
    }
}

fn is_operator_or_punct(k: TokenKind) -> bool { /* ... */ }
```

Exact `TokenKind` enum variants match whatever `clause-ir`
currently exports. If additional variants have landed, extend
the `show_lit` predicate to include them.

### Change S7 — src/diag.rs

Diagnostic printer. Computes line:col from the byte offset by
counting newlines in `src` up to the offset, then prints
`file:line:col: <phase>: <message>`. Round-one output targets
stderr.

```rust
pub fn print(src: &str, diag: &clause_ir::Diagnostic) {
    let off = diag.span.start.0 as usize;
    let (line, col) = line_col(src, off);
    eprintln!("<file>:{line}:{col}: {:?}: {}", diag.phase, diag.message);
}

fn line_col(src: &str, off: usize) -> (u32, u32) { /* ... */ }
```

`file` is a placeholder this round; the binary only handles
single-file input and does not yet track filename through the
pipeline as a `Str`. Future work (ties to #73.3).
