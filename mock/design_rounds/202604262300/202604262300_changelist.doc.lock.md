## Purpose

Finalise the extension-point contract by which game-specific
codegen targets (`clause-jomini` for Clausewitz, future
`clause-w3`, `clause-ts4`, `clause-lua`, etc.) plug into the base
language. Blocks clause-codegen's impl round (Task #38) and
establishes the surface for later extension repos.

## Decisions

### 1. Extension point = trait, not trait object.

Extensions implement a `CodegenTarget` trait. The trait is
**object-safe only at its base-shape level**; generic methods use
monomorphised dispatch. Rationale: matches the no-dyn discipline
used across arvo / hilavitkutin; keeps codegen compile-time
dispatchable.

### 2. Trait shape.

```rust
pub trait CodegenTarget: Send + Sync + 'static {
    /// Canonical name used in manifest declarations.
    const NAME: &'static str;

    /// Stable fingerprint distinguishing target revisions.
    /// Changes invalidate cached artefacts.
    const VERSION: u32;

    /// Declare which AST node kinds this target accepts.
    fn accepts(&self, kind: AstNodeKind) -> bool;

    /// Declare which pass-DAG stages this target participates in.
    fn stages(&self) -> &'static [Stage];

    /// Compile a typed IR unit to target output.
    /// Output is an opaque byte blob + a manifest fragment
    /// describing what got produced.
    fn compile(
        &self,
        unit: &TypedUnit,
        ctx: &mut CodegenCtx<'_>,
    ) -> Result<CodegenOutput, Diagnostic>;

    /// Target-specific diagnostics lowered to clause-ir::Diagnostic.
    fn render_diagnostic(&self, err: &TargetError) -> Diagnostic;
}
```

### 3. Target registry.

```rust
pub struct TargetRegistry {
    targets: [Option<&'static dyn CodegenTarget>; MAX_TARGETS],
    count: usize,
}

impl TargetRegistry {
    pub const fn new() -> Self;

    /// Register at compile time. All built-in + plugin targets
    /// register before `compile_all` runs.
    pub fn register<T: CodegenTarget>(&mut self, target: &'static T);

    pub fn get(&self, name: &str) -> Option<&dyn CodegenTarget>;

    pub fn iter(&self) -> impl Iterator<Item = &dyn CodegenTarget>;
}
```

Note the `&'static dyn CodegenTarget`: this is the ONE place
clause uses a `dyn` trait object — confined to the registry,
static-lifetime, and const-sized. Acceptable exception documented
in DESIGN since it's the only dispatch point the extension-point
mechanism really needs, and it stays type-erased only at the
outer iteration level; the inner compile calls monomorphise via
the impl bound.

### 4. Target selection.

Targets are selected in priority order:

1. **Explicit `clause build --target <name>` CLI flag** — wins
   always.
2. **Per-package `[targets]` in Clause.toml** — targets
   declared by the package.
3. **Workspace-wide `[workspace.targets]` in root Clause.toml** —
   default for all packages.
4. **Built-in fallback** — the `clause-builtin` target emits
   target-agnostic IR that other tooling consumes.

### 5. Stage participation.

```rust
pub enum Stage {
    /// Target wants to see the IR before type checking runs.
    /// Used by targets that emit pre-typecheck diagnostics (rare).
    PreTypecheck,
    /// Target wants to see the typed IR. Default.
    PostTypecheck,
    /// Target wants to emit additional passes before codegen.
    CodegenPre,
    /// Main codegen — target produces output.
    Codegen,
    /// Post-codegen hook for linking / bundling / container output.
    Link,
}
```

Targets opt into stages via the `stages()` method. The schedule
crate respects target-declared stages when building the pass DAG.

### 6. `CodegenCtx`.

```rust
pub struct CodegenCtx<'a> {
    diagnostic_sink: &'a mut DiagnosticSink,
    artefact_cache: &'a mut ArtefactCache,
    workspace: &'a Workspace,
}
```

Context passed to every `compile` call. Lets the target emit
diagnostics, query cached artefacts, and walk the workspace
graph for cross-package references.

### 7. Target output.

```rust
pub struct CodegenOutput {
    /// The emitted payload (opaque to clause core).
    pub bytes: Vec<u8>,
    /// Manifest fragment: file path, bundle routing, integrity
    /// hash.
    pub manifest: ManifestFragment,
    /// Cross-target references (resolved at link stage).
    pub references: &'static [SymbolRef],
}
```

`ManifestFragment` describes where the bytes land (which file
path / which Clausewitz subdir / etc.). Consumers wire the
fragment into their distribution format.

### 8. Built-in targets this round.

- `clause-builtin` — identity codegen. Emits the typed IR as the
  output, useful for debuggers + IDE tooling.

Real Clausewitz / W3 / Lua targets ship in their own sibling
repos (`clause-jomini`, future `clause-w3`, future `clause-lua`).
