## Impl-time decisions (pre-committed)

1. **Sanctioned `&'static dyn CodegenTarget`** — the TargetRegistry
   iteration surface uses trait objects; documented explicitly in
   DESIGN as the single exception to the no-dyn discipline,
   confined to static-lifetime registry walks.
2. **Stage enum is fixed this round** — reordering / graph-based
   stages deferred.
3. **`clause-builtin` as the fallback target** — it emits typed IR
   verbatim. Real targets (clause-jomini etc.) ship in sibling
   repos.
4. **`CodegenOutput::bytes` is `Vec<u8>`** — the one place codegen
   uses heap allocation, since targets emit variably-sized
   payloads. Confined to this one output type; the rest of the
   crate stays alloc-minimal.
