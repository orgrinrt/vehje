# Topic: grade-region set-failure is a must_use soundness fix

**Date:** 2026-07-25
**Phase:** TOPIC
**Scope:** vehje-ir (GradeTable::set), vehje-typecheck (check + CheckError)
**Source topics:** the canon PE3 mandate (Torvalds audit finding), no-alloc axiom with mandated mitigations.

## Current state

`GradeTable::set` returns `Bool(false)` when the arena index is past the
caller-lent grade region (the write did not land), but `check` discards
that return (`vehje-typecheck/src/lib.rs:314`: `grades.set(at.index(), grade);`).
A grade region smaller than the node arena therefore drops a node's grade
silently, and `check` still returns `Ok`: an unsound state passes as checked.

## Decision

Make the illegal state unbuildable-by-omission: mark `GradeTable::set`
`#[must_use]` so discarding its result is a compile error under the crate's
`deny(unused_must_use)`, and have `check` propagate a set-failure as a new
`CheckError::GradeRegionFull { at }`. A red test drives it first: a check run
with a grade region smaller than the node count must return
`GradeRegionFull`, not `Ok`.
