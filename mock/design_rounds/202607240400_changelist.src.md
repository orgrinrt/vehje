Shape: `pub trait TargetSets { type Supports: AccessSet; type Permits: AccessSet; }`. The carrier trait

parameters, living below both check and codegen to avoid a dependency cycle.

## CHANGE: `mint_checked` signature FROM free `Supports, Permits, Families, Effects` TO `T: TargetSets` deriving the sets, consuming `Graded`
File: `mock/crates/vehje-typecheck/src/lib.rs`
New: `mint_checked<'a, T, Families, Effects>(graded: Graded<'a>, _incl: PhantomData<(Families, Effects)>) -> Checked<'a, T> where T: TargetSets, T::Supports: ContainsAll<Families>, T::Permits: ContainsAll<Effects>`.
Ties the support and permit sets to the target (closing the untied-target forge half) and requires the
`Graded` evidence (closing the mint-without-check path). The caller-supplied `Families`/`Effects` remaining
the program's claimed sets (rather than program-derived) stays the FIXME'd inclusion frontier.
Verification: `grep -n "T::Supports: ContainsAll" mock/crates/vehje-typecheck/src/lib.rs` returns one match;
`! grep -n "Supports: ContainsAll<Families>," mock/crates/vehje-typecheck/src/lib.rs | grep -v "T::"` (no free-Supports bound remains).

## CHANGE: `check_for` FROM `(arena, root)` minting directly TO consuming a `Graded`, in `vehje-codegen`
File: `mock/crates/vehje-codegen/src/lib.rs`
New: `check_for<'a, T, Families, Effects>(graded: Graded<'a>) -> Checked<'a, T> where T: Target, T::Supports: ContainsAll<Families>, T::Permits: ContainsAll<Effects>`, delegating to `mint_checked`. The caller runs
`check` to obtain the `Graded`, then `check_for` mints. This unifies static inclusion with the runtime
evidence-of-check.
Verification: `grep -n "graded: Graded" mock/crates/vehje-codegen/src/lib.rs` returns one match.

## CHANGE: `hash_of` folds leaf content in `vehje-ir`
File: `mock/crates/vehje-ir/src/hash.rs`
`Var` folds the interned name (`Str::to_bits`), `Lit` folds the scalar value (bool bit, 64-bit int raw,
interned string word) alongside the type tag, `Project` folds the key, `Raw` folds its payload children.
Structurally distinct subtrees then hash distinct.
Verification: a new unit test asserts `hash_of(Var(x)) != hash_of(Var(y))` and `hash_of(Int(1)) != hash_of(Int(2))`; `cargo test -p vehje-ir` passes.

## CHANGE: recursive `Let` binds its name for the bound value in `vehje-resolve`
File: `mock/crates/vehje-resolve/src/lib.rs`
In `walk` and `walk_record`, when `Node::Let { rec, .. }` has `rec` set, push the binder frame before
walking the value so the value can reference the binding; the non-recursive path is unchanged.
Verification: a new unit test builds `let rec f = f in f` and asserts `resolve` returns `Ok`; `cargo test -p vehje-resolve` passes.

## CHANGE: `Arena::list` bounded by the child-index pool length in `vehje-ir`

The returned slice is clamped to the live pool region, so a malformed `NodeList` cannot read past the
pool's filled length.
Verification: `grep -n "pool" mock/crates/vehje-ir/src/arena.rs` shows the clamp in `list`.

## CHANGE: tests for the landed fixes; frontier gaps stay FIXME-marked
File: the relevant crates' test modules.
Green tests cover every fix landed here: `hash_of` distinguishes `Var(x)`/`Var(y)`, `Int(1)`/`Int(2)`, and
`Bool(true)`/`Bool(false)` while equal subtrees still hash equal (`vehje-ir/src/hash.rs`); recursive `Let`
resolves and non-recursive `Let` does not bind its value (`vehje-resolve`); a dangling root is refused by
`check` so no `Graded` is minted over a corrupt IR (`vehje-typecheck`).
The two frontier gaps are NOT catalogued as `#[ignore]` tests this round, honestly, because neither is
expressible yet: effect gating needs the unbuilt effect-classification scaffolding (no node contributes an
effect at M-level, so a permitted/forbidden program cannot be distinguished), and the program-derived
inclusion half (rejecting a caller-claimed `Families = Empty` for a program that uses a family) is a
compile-fail property that needs a trybuild-style harness this workspace does not set up. Both remain
FIXME-marked at their sites (`vehje-typecheck` infer Raw arm and the `mint_checked`/`Graded` FIXMEs) and
tracked #29; a hollow ignored test asserting nothing would misrepresent coverage.
Verification: `cargo test --workspace` passes with the new green tests; the frontier FIXMEs are greppable
(`grep -rn "FIXME.*#29\|FIXME.*runtime-bitmask\|FIXME.*family-check" mock/crates`).
