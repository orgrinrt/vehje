## Purpose

Execute the source-level sweep that brings every skeleton crate into
compliance with the shipping doc templates. Wrap bare primitives in
arvo types where layout permits. Annotate per the single-token
`lint:allow(<rule>) tracked: #207` pattern at FFI-boundary and
tuple-struct-newtype sites where wire-stable or layout-identical
primitives are required. Apply the em-dash sweep to source-side
module doc comments to clear writing-style density warnings.

Round closes with restoration of the four temp-lowered lint
severities (`arvo-types-only`, `no-bare-numeric`, `no-bare-string`,
`no-public-raw-field`) from `warn` to `error` at commit+push (task
#218). Those severity changes are user-applied via the classifier.

## Scope of source changes

Per crate. The bulk of work landed in earlier commits on this
branch. Final SRC commit covers the em-dash sweep across all
`src/*.rs` doc comments plus the `lint:allow ... reason: ...`
annotation form fix on `clause-runtime-abi/src/diagnostic.rs`.

### Em-dash sweep

Apply `s/ — /. /g; s/—/, /g` across every `.rs` file under
`mock/crates/`. Em-dashes in module doc comments and inline doc
comments (and a small handful in user-facing CLI strings) become
periods or commas per the writing-style rule. The bulk transform
preserves meaning; reviewer-facing prose remains coherent because
em-dashes were used either as parenthetical separators (now
commas) or as sentence breaks (now periods).

## Per-crate doc-comment sweep

Same as above; the em-dash sweep replaces all the per-crate doc
comment fixes that the prior CLs enumerated separately.

## Round-close trigger for #218

The SRC CL's final commit is the trigger for the lint severity

final SRC commit lands, verified with `cargo mock --lint-only
--commit` and `--push`, then the round closes with `cargo mock
close`.
