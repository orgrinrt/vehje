# Source changelist: wire binders by Sym bits

**Round:** 202607251019
**Phase:** IMPL
**Scope:** vehje-runtime-abi (ResidualEncoder trait + FlatArenaEncoder impl + the encode walk + serialize tests).

## CHANGE: `ResidualEncoder` gains a `binder` primitive
File: `mock/crates/vehje-runtime-abi/src/encode.rs`
Add `fn binder(&mut self, sym: Sym) -> Maybe<()>` to the `ResidualEncoder` trait: one wire word carrying `Sym::to_bits`, the stable 32-bit binder identity. Add `use hilavitkutin_sym::Sym;`.
Verification: `grep -q 'fn binder' mock/crates/vehje-runtime-abi/src/encode.rs`.

## CHANGE: the encode walk writes binders via `binder`, not `text`
File: `mock/crates/vehje-runtime-abi/src/encode.rs`
`Node::Var`, `Node::Let.name`, and `Node::Lambda.param` call `encoder.binder(sym)` instead of `encoder.text(Interner::resolve(sym)?)`. `Project.key` and `Literal::Str` keep `text`. Remove the minted-binder FIXME (resolved: a minted binder encodes its bits like any other).
Verification: `grep -q 'encoder.binder' mock/crates/vehje-runtime-abi/src/encode.rs && ! grep -q 'MINTED binder' mock/crates/vehje-runtime-abi/src/encode.rs`.

## CHANGE: `FlatArenaEncoder` implements `binder`
File: `mock/crates/vehje-runtime-abi/src/wire/serialize.rs`
`fn binder(&mut self, sym: Sym)` takes one word slot and writes `sym.to_bits().to_raw()`. Update the module doc's per-node layout note (a binder is one word, not a text pair).
Verification: `cargo test -p vehje-runtime-abi`.

## CHANGE: serialize tests adapt to the one-word binder slot
File: `mock/crates/vehje-runtime-abi/src/wire/serialize.rs`
The `Var` / `Let` / `Lambda` byte-offset assertions shift: a binder is one word where it was a two-word text pair. Assert the binder word equals the source `Sym`'s bits.
Verification: `cargo test -p vehje-runtime-abi`.
