# Doc changelist: strings are values

**Round:** 202607251152 (topic: `202607251152_topic.strings-are-values.md`)
**Phase:** DOC
**Scope:** `runtime-zig/DESIGN.md.tmpl` only. Strings join the evaluated set, the operand record grows a bytes pointer, and the runtime handle becomes the per-session scratch it was always intended to be.

## `mock/runtime-zig/DESIGN.md.tmpl`

- The evaluated set: add string literals. State why they cost nothing to produce: the residual ends in a self-contained byte blob and a string literal is an offset and a length into it, so a string value is a slice of bytes the runtime already holds, with no copy and no allocation. State that the span is bounds-checked against the blob because the image is untrusted.
- The evaluated set: state that a string value is a byte slice regardless of where the bytes live, a literal's pointing into the residual image and a handler's result pointing into the session scratch, both outliving the evaluation and neither distinguishable to what reads them.
- The family-operation section: the operand record carries a bytes pointer alongside its tag and payload. For a scalar the pointer is null and the payload is the value; for a string the pointer is the bytes and the payload is their length. One record for both, so the common case is unchanged in size and cost. Rename it in the prose to an operand rather than a scalar, since it is no longer only scalars.
- The family-operation section: a handler returns a string the same way it receives one, writing a pointer and a length into the out-slot; the runtime copies those bytes into the session scratch so the value stays valid after the handler returns and the host keeps no obligation once the call ends. Scratch exhaustion is a named refusal.
- The C ABI surface: `vehje_runtime_new` takes the scratch region the host lends and returns a handle over it; `vehje_runtime_execute` takes that handle and uses its scratch; `vehje_runtime_free` releases nothing, because the memory was never the runtime's. A null handle means no scratch, under which a handler returning a string is a named refusal rather than a crash.
- The produced-value section: a string marshals with the `Str` tag and its bytes in the image blob.
- Intended, not shipped: remove per-session arena state, which now ships as the handle's scratch. Narrow the strings-sequences-records bullet to sequences and records, and say they need a value arena rather than a byte scratch because their elements are values rather than bytes. Keep the rest unchanged.

## Not in this changelist

No other document changes. Sequences, records, `Project`, and the pattern representation are named as owed and land in their own rounds.
