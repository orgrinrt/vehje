# Topic: encode residual binders by Sym bits, not resolved text

**Date:** 2026-07-25
**Phase:** TOPIC
**Scope:** vehje-runtime-abi (the residual encoder + wire format)
**Source topics:** the Round B minted-binder FIXME (encode.rs:145-155), the Zig-runtime path (op 2026-07-25), the residual's role as the runtime's executable image.

## Current state

The residual encoder writes a binder (`Var`, `Let.name`, `Lambda.param`) as
its RESOLVED TEXT: `encoder.text(Interner::resolve(sym))` emits a
`(blob-offset, len)` pair (encode.rs:152-166). Two problems make this wrong for
execution: (1) the blob is not dedup-guaranteed, so the same source name bound
at a `Let` and referenced at a `Var` can land at different blob offsets, and a
runtime that matches a variable to its binder by wire identity cannot rely on
the offset; and (2) a MINTED binder (BinderDomain, kind 0b001) has no backing
string, so `Interner::resolve` returns Isnt and serialization fails outright
(the Round B FIXME). A tree-walk runtime needs a stable binder identity to bind
and look up variables.

## Decision

Encode every binder by its `Sym` bits, a single wire word (`Sym::to_bits`, the
32-bit handle), not by resolved text. Add a `binder(sym)` primitive to
`ResidualEncoder` (one word) beside `text` (two words); `Var`, `Let.name`, and
`Lambda.param` use it. `Project.key` and `Literal::Str` stay `text` (they are
genuine strings, not binders). This gives the runtime a stable integer binder
identity that a `Var`'s bits equal its `Let`'s bits exactly (integer equality on
the whole Sym, kind included), resolves the Round B minted-binder FIXME (a minted
binder encodes its bits like any other), and shrinks each binder slot from two
words to one. The resolved text, where a debugger wants a name, is a later
optional debug section keyed by the Sym, not the execution encoding.
