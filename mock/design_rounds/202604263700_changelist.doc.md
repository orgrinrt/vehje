## Purpose

Ship the typecheck crate scaffolding for Clause: the `Validator`
trait, the `ValidatorRegistry` with the R4-sanctioned
`&'static dyn Validator` exception, ten concrete validator ZST
stubs (STRICT1-7 + Coherence + OrphanRule + BindTargetShape), a
`ValidatorCtx` carrier, and a top-level `typecheck` entry that
walks the registry over an empty/skeleton `Resolved` and returns
an empty diagnostic vec.

This is the skeleton pattern: each validator's `validate` body
returns `Vec::new()` (not `todo!()`, so `run_all` does not panic
in tests). Every concrete check — overlap detection for
coherence, the shadow check for STRICT1, etc. — lands as its own
follow-up micro-round on top of this stable harness.

Without this round, clause-typecheck is a nuked stub; with it,
downstream phases (clause-schedule, clause-codegen) have a
concrete validator surface to route work through, and each
deferred validator body ships in isolation.

## Scope adjustment vs R4

R4 finalised a richer trait shape (associated consts `NAME` /
`CATEGORY`, `accepts(kind)` node routing, `&mut DiagnosticSink`
emission). This skeleton round lands a narrower instance-method
trait that still satisfies the R4 invariants at the registry
surface:

- `name(&self) -> &'static str` — the NAME access point.
- `validate(&self, &ValidatorCtx) -> Vec<Diagnostic>` — the
  check entry.

`Category`, `accepts`, and the `DiagnosticSink` API are deferred
to the follow-up rounds that land real validator bodies. The
instance-method form works in a `&dyn Validator` registry
directly; associated-const variants require `const-in-trait` or
an object-safe shim and can be retrofitted without touching
consumers once the registry walks real diagnostics.

## Deliverables this round

### clause-typecheck — trait + registry

- `Validator` trait (`src/validator.rs`):
  ```rust
  pub trait Validator: Sync {
      fn name(&self) -> &'static str;
      fn validate(&self, ctx: &ValidatorCtx) -> Vec<Diagnostic>;
  }
  ```
- `ValidatorCtx<'a>` carrier (`src/ctx.rs`) — holds
  `resolved: &'a Resolved` only this round. Future fields
  (diagnostic sink, workspace info, per-validator config) are
  BACKLOG.
- `ValidatorRegistry` (`src/registry.rs`) — hosts
  `pub const VALIDATORS: &[&'static dyn Validator] = &[...]` with
  ten entries plus `run_all(ctx: &ValidatorCtx) -> Vec<Diagnostic>`
  that iterates and extends.

### clause-typecheck — ten validator stubs

Each is a ZST struct with `Validator` implemented; body returns
`Vec::new()`. Names match R4 (section 4):

- `src/strict1.rs` — `Strict1` — `no-shadow`.
- `src/strict2.rs` — `Strict2` — `unused`.
- `src/strict3.rs` — `Strict3` — `assign-to-immut`.
- `src/strict4.rs` — `Strict4` — `int-overflow`.
- `src/strict5.rs` — `Strict5` — `use-after-move`.
- `src/strict6.rs` — `Strict6` — `ambiguous-imports`.
- `src/strict7.rs` — `Strict7` — `clippy-batch`.
- `src/coherence.rs` — `Coherence` — `coherence`.
- `src/orphan_rule.rs` — `OrphanRule` — `orphan-rule`.
- `src/bind_target_shape.rs` — `BindTargetShape` —
  `bind-target-shape`.

### clause-typecheck — entry point

- `typecheck(resolved: &Resolved) -> Vec<Diagnostic>` in
  `src/lib.rs`. Builds a `ValidatorCtx`, calls
  `ValidatorRegistry::run_all(&ctx)`, returns the collected vec.

### Tests (`clause-typecheck/tests/`)

- `tests/validator_trait.rs` — 4 tests covering each STRICT ZST:
  - `strict1_name_matches` — `Strict1.name() == "no-shadow"`.
  - `strict1_validate_empty` — empty resolved → empty vec.
  - `strict_names_cover_all_seven` — collect the seven STRICT
    names, assert each expected string present.
  - `strict_validate_all_empty` — all seven return empty vec.
- `tests/registry.rs` — 4 tests:
  - `registry_has_ten` — `VALIDATORS.len() == 10`.
  - `registry_run_all_empty_resolved` — `run_all` returns empty
    vec on an empty `Resolved`.
  - `registry_contains_expected_names` — the ten names appear in
    the registry in the documented order.
  - `registry_names_unique` — no name appears twice.
- `tests/coherence_orphan_bind.rs` — 3 tests:
  - `coherence_name_and_empty` — `Coherence.name() ==
    "coherence"`; validate returns empty vec.
  - `orphan_rule_name_and_empty` — `OrphanRule.name() ==
    "orphan-rule"`; empty vec.
  - `bind_target_shape_name_and_empty` — `BindTargetShape.name()
    == "bind-target-shape"`; empty vec.
- `tests/end_to_end.rs` — 2 tests:
  - `typecheck_empty_resolved_returns_empty` — top-level
    `typecheck` on a default `Resolved` returns empty vec.
  - `typecheck_empty_then_runnable_twice` — idempotent.

Target ~12 tests total (13 in practice).
