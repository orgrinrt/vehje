# Src changelist: the family-extension dispatch seam

Source execution for round `202607241030`, against the locked doc CL `202607241100_changelist.doc.lock.md`.
Makes the three Core passes descend into a `Raw` node's payload and adds the family-dispatch hook the passes
are generic over, so the implementation matches the DESIGNs' "generic over the family set, with
family-extension hooks" and a consumer with a payload-bearing family can attach. Each change carries a test.

## CHANGE: `fold_core` descends into `Raw.payload` in `vehje-codegen`
File: `mock/crates/vehje-codegen/src/lib.rs`
The `Raw` arm of `fold_core` iterates `payload` and recurses into each child (after `visit`), so a target's
`visit` closure sees the family node's Core children. `Raw` is no longer a leaf in the fold.
Verification: a test folds a program with a `Raw` node over Core children and asserts the children are visited;
`cargo test -p vehje-codegen` passes.

## CHANGE: resolve descends into `Raw.payload` and gains the `FamilyResolve` hook in `vehje-resolve`
File: `mock/crates/vehje-resolve/src/lib.rs`
`walk` and `walk_record` descend into a `Raw` node's payload, resolving each child against the current scope
(a `Var` inside a family node resolves). Add `FamilyResolve` (a hook trait with a no-op-defaulted `resolve_raw`
called at each `Raw`), `CoreFamilies` (the no-op default), and `resolve_with` / `resolve_into_with` (generic
over the hook). `resolve` / `resolve_into` stay the Core-only entries and call the generic form with
`CoreFamilies`, so existing callers are unchanged.
Verification: a test builds `Raw` over a bound `Var` and asserts `resolve` returns `Ok` (the inner `Var`
resolves); a test builds `Raw` over an unbound `Var` and asserts `Unresolved`; `cargo test -p vehje-resolve`
passes.

## CHANGE: check descends into `Raw.payload` and gains the `FamilyCheck` hook in `vehje-typecheck`
File: `mock/crates/vehje-typecheck/src/lib.rs`
`infer`'s `Raw` arm descends into the payload, joining each child's grade, and joins the family operation's
declared effect from a `FamilyCheck` hook (`effect_of_raw`, defaulting to the empty effect). Add `FamilyCheck`,
thread the hook through `check`/`infer` (the Core-only `check` uses a default hook), and add `check_with` for a
consumer hook.
Verification: a test grades a `Raw` over Core children and asserts the children's grades are recorded; a test
with a hook returning a non-empty effect asserts the `Raw` node's grade carries it; `cargo test -p vehje-typecheck` passes.

## CHANGE: FIXME markers updated
Files: the `Raw`-arm FIXMEs in the three passes are replaced by the implemented descent plus the hook; a

## CHANGE: add `Builder::alloc_list` in `vehje-ir`
File: `mock/crates/vehje-ir/src/builder.rs`
A `pub fn alloc_list(&mut self, refs: &[NodeRef]) -> Maybe<NodeList>` delegating to `Arena::alloc_list`, so a
consumer (or a test) can build the `NodeList` a `Raw` payload or a `Handle` clause list needs. Without it a
`Raw` node could not be constructed through the builder, a small consumer-readiness gap surfaced while testing
the seam.
Verification: `grep -n "pub fn alloc_list" mock/crates/vehje-ir/src/builder.rs` returns one match; the seam
tests build `Raw` payloads through it.
