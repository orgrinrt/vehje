# Doc changelist: a family operation reaches its handler

**Round:** 202607251140 (topic: `202607251140_topic.family-operations-reach-their-handler.md`)
**Phase:** DOC
**Scope:** `runtime-zig/DESIGN.md.tmpl` gains the host-call dispatch as shipped and loses it from the intended list. `vehje-runtime-driver/DESIGN.md.tmpl` gains the host surface it passes through.

## `mock/runtime-zig/DESIGN.md.tmpl`

- New section, after the produced-value section: the family-operation dispatch, marked shipped. State the framing first: an effect is an operation, a handler is what services it, and a host-call is a runtime-effect operation the host handles, so the runtime's job is not to know what a family means but to evaluate its operands and hand them over. State that this is what keeps the framework family-free while making every family executable.
- Describe the mechanism: `Raw` carries a family id and a payload list; the runtime evaluates each payload child left to right, because a host call may have effects and operand order is part of what a program means; it collects the results into a fixed-capacity operand buffer, over which it refuses by name; and it calls the host with the family id and that buffer, taking one value back.
- Describe the operand record: a kind tag and a payload word covering unit, boolean, and integer, the runtime's whole value set. Say that the tag values are the value image's scalar tags, so one vocabulary describes a scalar wherever it appears. Say plainly that a compound operand has no representation yet and will arrive through the value image when compound values exist.
- Describe the failure modes: a null host makes any `Raw` a named refusal rather than a crash, and a non-zero host result code propagates as an evaluation error, so a host that refuses is distinguishable from a host that produced a value.
- The C ABI surface section: record that `vehje_runtime_execute` takes a host pointer alongside the sink.
- Intended-not-shipped list: remove the family-operations-and-host-calls bullet. Add, in its place, the two things this round does not do: compound operands, and the compile-stage counterpart where a handler services a macro operation at its binding time. Keep every other intended item unchanged.

## `mock/crates/vehje-runtime-driver/DESIGN.md.tmpl`

- Scope: add the host surface the driver passes through, alongside the sink it already supplies. The driver does not implement any family; it carries the host record from whoever embeds it to the runtime, which is the same posture it takes with the sink.
- Scope, `Runtime`: note that execution comes in two shapes, one without a host for programs that need none and one with, and that the hostless shape is not a lesser path but the honest default.

## Not in this changelist

No family is defined anywhere. The first-party language consumer, which will define arithmetic, is a later round.
