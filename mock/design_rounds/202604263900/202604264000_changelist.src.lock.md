7. `src/registry.rs` — `TargetRegistry`. Roughly 60–100 lines.

   - `pub struct TargetRegistry;`.
   - ```rust
     pub const TARGETS: &[&'static dyn CodegenTarget] = &[
         &NativeTarget,
         &JominiTarget,
     ];
     ```
   - `impl TargetRegistry` with:
     - `pub fn lookup(name: &str) -> Option<&'static dyn
       CodegenTarget>` — linear scan over `TARGETS` matching
       `name`.
     - `pub fn emit_for(name: &str, ctx: &CodegenCtx) ->
       Result<CodegenArtifact, CodegenError>` — uses `lookup`,
       returns `Err(CodegenError::TargetNotFound { name:
       <static_name> })` if missing. NOTE: the `name` field is
       `&'static str`; the lookup-miss returns a static "literal"
       by matching against the known target names in a fallthrough
       and using the input name only if it matches one of those.
       Since we cannot coerce arbitrary `&str` to `&'static str`
       safely, the `emit_for` miss path returns `TargetNotFound {
       name: "unknown" }` — the doc comment notes that a
       follow-up round will migrate this to an owned `String`
       or a `&'static [&'static str]` lookup table. Simpler
       alternative: change `TargetNotFound` to carry no
       payload and let the caller retain the input name. Use
       the latter to keep the error a plain enum.

   - **Decision:** To keep `CodegenError: Copy`, `TargetNotFound`
     MUST carry a `&'static str`. The registry passes the
     static target-name slice if a target matches (never on
     miss). On miss, return `TargetNotFound { name: "" }` — the
     caller owns the input string and can re-report it. Doc
     comments note the empty-name sentinel + the follow-up
     round that will retrofit a richer error carrier.

## Impl-time decisions (pre-committed)

1. **`std` is used.** Codegen is host-side (compiler phase);
   `Vec`, `String`, heap allocation all fair game. The `no_std`
   discipline stays on `clause-ir` / `clause-lex` /
   `clause-syntax`.
2. **`CodegenTarget` is instance-method, not associated-const.**
   Trait has `fn name(&self) -> &'static str` and `fn emit(&self,
   ctx: &CodegenCtx) -> Result<CodegenArtifact, CodegenError>`.
   Object-safe; works in `&dyn CodegenTarget`. The R3
   associated-const / `CodegenOutput` shape is deferred BACKLOG.
3. **`CodegenCtx` carries only `resolved: &Resolved`.** Sink,
   artefact cache, workspace, config are BACKLOG.
4. **`TargetRegistry` is a ZST with associated const `TARGETS` +
   associated `lookup` + `emit_for`.** No state. No constructor.
   Dynamic registration is BACKLOG.
5. **`TARGETS` ordering is fixed: `NativeTarget`,
   `JominiTarget`.** Consumers should not depend on ordering,
   but the test suite asserts length + membership.
6. **Each target's `emit` body returns `Ok(CodegenArtifact::empty(kind))`.**
   Skeleton: registry walks must not panic; tests pass without
   stubbing unreachable arms. `CodegenError::NotImplemented` is
   reserved for future partial-implementation returns; skeleton
   does not use it.
7. **`CodegenError` is `Copy`; `TargetNotFound` carries a
   `&'static str` that is `""` on miss.** Caller owns the
   input-string context and re-reports if needed. A follow-up
   round migrates to a richer error carrier if the empty-name
   sentinel surfaces as painful in practice.
8. **`CodegenArtifact` fields `bytes: Vec<u8>` and
   `diagnostics: Vec<Diagnostic>` carry the
   `lint:allow(bare_collection)` escape hatch with a ≥21-word
   justification (see clause-typecheck/src/lib.rs for the
   pattern).**
