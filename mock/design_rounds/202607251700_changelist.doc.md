# Doc changelist: compound values across the host boundary

**Date:** 2026-07-25
**Phase:** DOC
**Topic:** `202607251700_topic.compound-values-across-the-host-boundary.md`

Three documents describe the seam this round changes. The operand contract is stated in the ABI crate, the
value model and its arena in the runtime, and the mirrored host surface in the driver. Each edit below names
the section and what it says after the edit.

## `mock/crates/vehje-runtime-abi/DESIGN.md.tmpl`

**Section: the operand record.** State that the record serves three shapes rather than two. A scalar carries
its value in `payload` with a null `bytes`; a string carries its bytes in `bytes` and its length in `payload`;
a compound carries a value image in `bytes` and that image's byte length in `payload`. Say plainly that the
record's shape does not change to gain the third, because the string convention already generalises, and that
the tag values remain the value image's tags so one vocabulary describes a value wherever it appears.

**Section: the value image.** Add that the image is the marshalling format for the host boundary in both
directions, not only for the produced value crossing back. Name the consequence: a compound arriving from a
handler is validated by the same bounds-checking decoder that validates a value crossing to the host, so the
boundary has one decoder rather than two specifications trusted to agree. Note that a value image carries a
root, which is what lets it describe a subtree rather than only a whole result.

**Section: refusals.** Add that a malformed returned image is a named refusal distinct from a handler
reporting failure.

State-labelled `intended` until the source lands in the src CL.

## `mock/runtime-zig/DESIGN.md.tmpl`

**Section: the value model.** Add the compound case to the union alongside unit, boolean, integer, string, and
closure. Say where it lives: a caller-lent value arena in the same shape as the environment arena, host-lent,
bump-allocated, owned by the runtime for no longer than the call. Say that a record is a node with its fields
in a child pool, which is the shape the value image already describes, so materialising a returned image is a
walk rather than a translation.

**Section: the value arena's record shape.** State that operands are inline rather than reached through a pool
indirection, and cite the measurement that decides it (`value-arena-throughput`: 10.7 ns per node
pool-indirected against 4.4 ns inline, the difference attributed to the indirection rather than to transport).

**Section: what the arena does not do.** State that values are stored plainly, with no interning and no
deduplication, and cite the two cells that refused both for this domain (`string-interning`, 2.2x to 3.1x
slower across three regimes; `dedup-vs-reuse`, record deduplication 9x to 19x slower than reuse and 6x to 7x
slower than plain). This is a positive design statement, not an omission, so it belongs in the document rather
than only in the bench findings.

**Section: the update path and the reuse bit.** State that the update path is written so a per-site uniqueness
bit selects in-place mutation against copy, that copy is the behaviour until the bit exists, and why that
direction is the safe one: ignoring the bit means copying, which is always sound, while reusing without a
verdict has nothing to read. Note the exclusion the measurement established, that a deduplication table is
itself a referrer, so interning a value forfeits reuse on it permanently and the two cannot both be defaults.

**Section: the evaluated set.** Move compound operands and compound returns from intended to shipped when the
src CL lands. Keep the closure refusal as written, with its reason.

**Section: refusals.** Add the undersized value arena and the malformed returned image as named refusals.

## `mock/crates/vehje-runtime-driver/DESIGN.md.tmpl`

**Section: the host surface the driver passes through.** State that the operand the driver carries now has a
compound form, and that the driver continues to interpret none of it: it moves the contract, it does not read
the family's values. Keep the existing posture sentence about the sink and extend it to cover compounds.

**Section: the lent buffers.** State that a host servicing a family operation that returns a compound writes
into the same session scratch already lent for returning strings, so the round adds no new lending channel.

## Not in this round

`Project` evaluation, though it becomes possible with this round. Its strategy is already settled by
measurement and it is a well-specified follow-on; keeping it out keeps this round's boundary claim auditable
alone.

The pattern representation and `Handle`'s clause representation, both deferred with their own rounds owed.

The reuse analysis itself, which needs the emit-time uniqueness verdict whose derivation from the lease masks
is still only intended.
