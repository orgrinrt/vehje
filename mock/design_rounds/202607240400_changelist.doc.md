# Doc changelist: readiness-review soundness fixes

Per-file doc-template edits for round `202607240330`. The source topic is
`202607240330_topic.readiness-review-soundness-fixes.md`. This changelist documents the new public
surface the fixes introduce (`TargetSets`, `Graded`), records the sealed-mint and check-evidence
contract, corrects the `compile_language` doc/source mismatch, and clears three standing
`undocumented-type` build-blockers (`BufSink`, `Reader`, `SliceKind`) owed from the prior round.

## vehje-ir/DESIGN.md.tmpl

- Add `TargetSets` to the documented surface: the carrier trait naming `Supports: AccessSet` and
  `Permits: AccessSet`, the type-level sets a target declares. It lives in `vehje-ir` so both
  `vehje-typecheck` (the mint) and `vehje-codegen` (the `Target`) can name it without a dependency
  cycle.
- Add `Graded` to the documented surface: the zero-size witness `check` returns on a clean graded
  fold, required by the mint. Names the evidence-of-check the DESIGN's "check mints the witness"
  contract depends on.
- In the structural-hash section, state that `hash_of` folds leaf content (the interned name of a
  `Var`, the scalar value of a `Lit`, the key of a `Project`, the payload of a `Raw`) so that
  structurally distinct subtrees hash distinct, the invariant the incremental layer's cache-hit
  soundness depends on.

## vehje-typecheck/DESIGN.md.tmpl

- State that `check` returns a `Graded` witness on success and that the mint (`mint_checked`,
  `check_for`) requires it, so a witness cannot be minted without a clean check having run.
- State that the mint derives the target's `Supports`/`Permits` from `T: TargetSets` rather than from
  free parameters, so a caller cannot claim a support or permit set the target does not declare. Note
  that deriving the program's used family and effect sets from the program itself (rather than
  trusting caller-supplied sets) is the remaining inclusion step, carried by the runtime-bitmask path.

## vehje-codegen/DESIGN.md.tmpl

- State that `Target` extends `TargetSets` (its `Supports` and `Permits` associated sets are the
  carrier trait's), and that `check_for` derives the inclusion bounds from the target through it.

## vehje-resolve/DESIGN.md.tmpl

- State that a `Let` with `rec` set binds its name in scope for the bound value (a recursive binding),
  and a non-recursive `Let` does not, in both `resolve` and `resolve_into`.

## vehje-runtime-driver/DESIGN.md.tmpl

- Document `Reader`: the safe reader over a residual's value arena that the driver hands a consumer,
  bounds-checking each value-node access.

## vehje-runtime-gen/DESIGN.md.tmpl

- Document `SliceKind`: the kind tag on a `Slice` of a generated `Package` (which validated-data
  section the slice carries).

## vehje/DESIGN.md.tmpl

- Unbacktick `compile_language`: the per-language orchestration entry is designed but not yet shipped
  (the symbol exists only as a deferred FIXME in source), so the DESIGN names it in prose without the
  backticks that assert an existing symbol. It returns to backticked form when implemented.
- Document `BufSink`: the in-memory `ByteEmitter` buffer the debug/demo emit path writes through.
