consumer repo) and reshapes the rest.

## M0: vehje-ir (the shared representation)

Rewrite `vehje-ir` to the locked DESIGN. `#![no_std]`, no alloc. Modules:

### CHANGE: `vehje-ir/src/arena.rs` (new)
Three caller-provided bump regions and their handles: a node arena, a child-index pool, a literal byte arena.
Each is a borrowed slice with a bump cursor. No vehje-specific policy (upstream-extraction candidate for
hilavitkutin).
Verification: `grep -q 'struct.*Arena' mock/crates/vehje-ir/src/arena.rs`.

### CHANGE: `vehje-ir/src/node.rs` (new; replaces the 9-kind `AstNodeKind` + `TokenKind`)
`Node` (the eleven Core forms: `Lit`, `Var`, `Let`, `Lambda`, `Apply`, `Project`, `If`, `Match`, `Iter`,
`Interp`, `Raw`), `NodeRef` (a `Uint32`-shaped arvo newtype), `NodeList` (`{ start, len }` into the child-index
pool), `LitRef` (a handle into the literal arena).
Verification: `grep -q 'enum Node' mock/crates/vehje-ir/src/node.rs` and the eleven variants present.

### CHANGE: `vehje-ir/src/family.rs` (new)
The `Family` trait (identity is the type itself; a `core::fmt::Debug` supertrait carries the human-readable
name for diagnostics, so no bare name const is stored; family id and effect classification land later), the
`Core` reference family, the family-set typestate reusing `hilavitkutin_api` `Cons` / `Empty` with vehje family
markers.
Verification: `grep -q 'trait Family' mock/crates/vehje-ir/src/family.rs`.

### CHANGE: `vehje-ir/src/effect.rs` (new)
`Pure`, `Reads<E>`, `Writes<E>` over environment markers `BuildEnv` / `RuntimeEnv`, the effect-set typestate
(second `AccessSet` instantiation), and the classifier hook.
Verification: `grep -q 'struct Reads' mock/crates/vehje-ir/src/effect.rs`.

### CHANGE: `vehje-ir/src/builder.rs` (new)
`Builder` holding the arena regions plus an interner, with one monoid smart-constructor per Core form.
Verification: `grep -q 'struct Builder' mock/crates/vehje-ir/src/builder.rs`.

### CHANGE: `vehje-ir/src/intern.rs` (new)
Interner integration over `hilavitkutin_str::Str` + `StringInterner`.
Verification: `grep -q 'Str' mock/crates/vehje-ir/src/intern.rs`.

### CHANGE: `vehje-ir/src/span.rs`, `diagnostic.rs` (reshaped from salvage)
`Span` / `FileId` / `ByteOffset` retained; `Diagnostic` / `Severity` retained; the phase discriminator reframed
to framework phases (resolve, check, emit, runtime). Drop the old language-phase variants.
Verification: `grep -q 'struct Span' mock/crates/vehje-ir/src/span.rs`.

### CHANGE: `vehje-ir/src/lib.rs` (rewrite)
`#![no_std]`, module decls, re-exports. Remove the old `AstNodeKind` / `TokenKind` surface.
Verification: `grep -q 'no_std' mock/crates/vehje-ir/src/lib.rs`.

### CHANGE: per-node span side-table (`arena.rs`, `builder.rs`)
`Arena` carries a third caller-provided region `spans: &mut [Span]` parallel to the node arena; `push` takes a
`Span` and writes it at the node's own index; `span(NodeRef) -> Span` reads it back. Each `Builder`
smart-constructor gains a trailing `span` argument. `ResolveError::Unresolved` gains `span: Span`, recovered
from the arena at the failing `Var`. This replaces the earlier "nodes carry no span" FIXME.
Verification: `grep -q 'fn span' mock/crates/vehje-ir/src/arena.rs` and `grep -q 'span: Span' mock/crates/vehje-resolve/src/lib.rs`.

## M3-M5: runtime-abi, runtime-driver, vehje

- `vehje-runtime-abi`: the tier-tagged C ABI, tier-0 flat IR-arena serialization, the runtime-environment
  descriptor. Bare primitives only at the `#[repr(C)]` boundary.

### CHANGE: tier-0 residual serialization (`vehje-runtime-abi/src/encode.rs`, `wire.rs`)
Serialization is trait-based, not a monolith: `encode.rs` holds the format-agnostic `ResidualEncoder` trait
plus the shared `encode` walk that decomposes each Core form into primitive encoder calls once (the
eleven-form match lives here). `wire.rs` holds the tier-0 `FlatArenaEncoder` (fixed seven-word records, a flat
child-index pool, a self-contained string blob) and the `serialize` convenience over `encode`. This threads
the output format as a generic (`E: ResidualEncoder`), mapping onto the `Tier` axis: Arena today, Bytecode a
future impl. Native lowering is NOT an encoder (it abandons the IR); it rides the `Target::emit` codegen axis.
`Residual` becomes the tier crossing-descriptor. `#[repr(C)]`/FFI byte widths are confined to the wire helpers.
Verification: `grep -q 'trait ResidualEncoder' mock/crates/vehje-runtime-abi/src/encode.rs` and `grep -q 'FlatArenaEncoder' mock/crates/vehje-runtime-abi/src/wire.rs`.

- `vehje-runtime-driver`: compile-side dispatch, no `dyn`, static Zig-runtime linkage.
- `vehje`: the two contracts (`Grammar` plug-in, `Target` re-export), orchestration, compile-time distribution
  composition.
Detail refines during IMPL; these are the stretch of the night.

## Discipline

Red builds mid-implementation are expected and correct (strict-by-design). The tree is not green until the
runtime seam lands; that red is the measurement, not a problem to stopgap. Every numeric position uses arvo
types (no bare primitives); every collection crosses as a trait bound or a bounded store; no `dyn`, no alloc.
