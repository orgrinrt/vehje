# Source changelist: family operations reach their handler

**Round:** 202607251140
**Phase:** IMPL
**Scope:** the Zig runtime gains `Raw` evaluation through a host callback, and `vehje-runtime-driver` gains the matching host record and a host-carrying execute. No family is defined anywhere.

## The Zig runtime

### CHANGE: `VehjeScalar` and `VehjeHost` CREATE
File: `mock/runtime-zig/src/runtime.zig`
`VehjeScalar` is an `extern struct` of a kind tag and a payload word, covering unit, boolean, and integer. The tag values are the value image's scalar tags, so one vocabulary describes a scalar wherever it appears. `VehjeHost` is an `extern struct` of one dispatch callback plus opaque userdata, mirroring the sink's shape because the same reasoning applies: the host owns the context and the runtime retains nothing past the call.
Verification: `grep -q 'pub const VehjeHost' mock/runtime-zig/src/runtime.zig`.

### CHANGE: `vehje_runtime_execute` gains a host parameter
File: `mock/runtime-zig/src/runtime.zig`
The entry takes `host: ?*const VehjeHost` after the sink. A null host means the program is expected to need none.
Verification: `grep -q 'host: ?\*const VehjeHost' mock/runtime-zig/src/runtime.zig`.

### CHANGE: `eval` evaluates `TAG_RAW` through the host
File: `mock/runtime-zig/src/runtime.zig`
Read the family id and the payload list, evaluate each payload child left to right into a fixed-capacity operand buffer (`ARG_CAP`), convert each to a `VehjeScalar`, and call the host. A closure operand has no scalar form and is refused. Over capacity is `TooManyOperands`; a null host is `NoHost`; a non-zero host code is `HostFailed`. The returned scalar becomes the node's value.
Verification: `grep -q 'TAG_RAW =>' mock/runtime-zig/src/runtime.zig`.

### CHANGE: `EvalError` gains `NoHost`, `TooManyOperands`, `HostFailed`
File: `mock/runtime-zig/src/runtime.zig`
Each failure named, so a host that refuses is never confused with one that produced a value.
Verification: `grep -q 'HostFailed' mock/runtime-zig/src/runtime.zig`.

### CHANGE: `evalImage` takes the host
File: `mock/runtime-zig/src/runtime.zig`
Threaded from the entry through `eval`, since any node may be a family operation.
Verification: `zig build test` passes.

## The driver

### CHANGE: `HostFn`, `Host`, and `Scalar` CREATE
File: `mock/crates/vehje-runtime-driver/src/runtime.rs`
The Rust mirrors of the Zig records: `Scalar` (`#[repr(C)]`, kind tag plus payload word), `HostFn` (the dispatch callback type), and `Host` (`#[repr(C)]`, callback plus userdata).
Verification: `grep -q 'pub struct Host' mock/crates/vehje-runtime-driver/src/runtime.rs`.

### CHANGE: `ExecuteFn` gains the host parameter, `Runtime::execute_with_host` CREATE
File: `mock/crates/vehje-runtime-driver/src/runtime.rs`
`ExecuteFn` matches the runtime's new arity. `execute` keeps its signature and passes a null host, since a program needing none should not have to supply one; `execute_with_host` passes one through.
Verification: `grep -q 'pub fn execute_with_host' mock/crates/vehje-runtime-driver/src/runtime.rs`.

## Tests (fail-first, strict)

Zig, in `mock/runtime-zig/src/runtime_test.zig`:

- A family operation reaches its handler: a host that adds its two integer operands makes `Raw(family, [2, 3])` evaluate to 5. This is the test that proves a program can compute at all.
- Operands evaluate left to right, proven by a host that records the order it saw them, because a host call may have effects and the order is part of what a program means.
- A nested family operation works, so a handler's result is an ordinary value: `Raw(add, [Raw(add, [1, 2]), 3])` is 6.
- A `Raw` with no host is `NoHost`, not a crash.
- A host reporting failure surfaces as `HostFailed`.
- A closure operand is refused, since it has no scalar form.

Rust, in `mock/crates/vehje-runtime-driver/src/runtime/tests.rs`:

- The hostless `execute` still works against the stand-in, so the default path is unchanged.
- `execute_with_host` passes the host through: a stand-in runtime that calls the host and commits what it returns proves the record crosses correctly.
- The end-to-end test gains a companion that runs a real family operation against the built artifact with a Rust host closure, asserting the returned value. Ignored like its sibling, since it needs the artifact.

Verification: `zig build test` and `cargo test -p vehje-runtime-driver --features dynamic` pass, and the ignored tests pass with `--ignored`.
