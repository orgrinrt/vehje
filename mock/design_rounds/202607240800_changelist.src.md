## CHANGE: reachability binder rule in `vehje-typecheck`
File: `mock/crates/vehje-typecheck/src/lib.rs`
At `Let` and `Lambda`, after unioning the children's reach sets, drop the bound variable's own reach slot
(the binder rule: a value's reach set does not include the variable the binder introduces). This is the
degenerate depth-lease the DESIGN names, replacing the M-level "union without the drop".
Verification: a new test builds a `Lambda`/`Let` and asserts the body's reach set excludes the bound slot;
`cargo test -p vehje-typecheck` passes.

## CHANGE: `GradeTable::get`/`set` bounds-checked in `vehje-ir`
File: `mock/crates/vehje-ir/src/grade.rs`
`get` returns `Maybe<Grade>` and `set` returns `Bool` (or a `Maybe<()>`), bounds-checked against the region,
rather than indexing and panicking. Callers in `vehje-typecheck` handle the `Maybe`.
Verification: `grep -n "Maybe<Grade>" mock/crates/vehje-ir/src/grade.rs`; a test asserts an out-of-range `get`
is `Isnt`; `cargo test --workspace` passes.

## CHANGE: `Reader::validate` typed structural decode in `vehje-runtime-driver`
File: `mock/crates/vehje-runtime-driver/src/lib.rs`
`validate` walks the value arena, bounds-checking every node's child list and blob span against the arena, and
enforcing the monotone child-index invariant (a child index strictly below its parent) that the children-first
emission order guarantees, so a malformed or cyclic arena is rejected linearly rather than read. Uses
`ValueArena::try_get` and the pool-clamped `children`.
Verification: tests assert a well-formed arena validates and a forward-reference (child index >= parent) is
rejected; `cargo test -p vehje-runtime-driver` passes.

## CHANGE: `vehje-lower` cheap stratum: `Rewrite` side-table, `If`-fold, CSE
File: `mock/crates/vehje-lower/src/lib.rs`
Add `Rewrite<'a>` (a caller-lent `NodeRef`-to-`NodeRef` remap with `resolve`). `ConstFold::apply` records, for
each `If` whose condition resolves to a literal boolean, a redirect from the `If` to its taken branch.
`Cse::apply` builds a hash-cons remap (over a caller-lent table) and redirects each subtree that hashes equal
to an earlier one to that earlier node. Both populate the `Rewrite`; the lowered root is `rewrite.resolve(root)`.
`Anf` stays FIXME'd (needs the mutable-arena rewrite).
Verification: tests assert `ConstFold` folds `if true then a else b` to `a` (via the `Rewrite`), and `Cse`
redirects two structurally equal subtrees to one; `cargo test -p vehje-lower` passes.
