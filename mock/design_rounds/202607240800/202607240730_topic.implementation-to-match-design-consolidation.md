# Implementing the ecosystem to match the full-design docs

The goal is a ready-to-go crate ecosystem: every crate under `mock/crates` with 100% design-complete
documentation (done) and an implementation that matches it, so the mockspace DSL can be built on the vehje
machinery next. The docs model the final design; the first-light implementation trails it behind 46 FIXME
markers. This round moves the implementation up to the docs wherever the design is complete and a real
algorithm exists, and leaves an honest marker only where the design itself defers to a future consumer or to a
research-grade mechanism. Faking a deferred-by-design shape (inventing a family payload encoding no consumer
has asked for, stubbing a saturation e-graph to look done) would violate the strict-by-design discipline; the
line between "implement now" and "honest marker" is drawn at whether the design is settled and the mechanism
is buildable without an unbuilt prerequisite.

## The taxonomy is unchanged

The twelve-crate taxonomy settled in `202607240100` holds; the bench full run confirmed the design it rests on
and forced no restructuring. `vehje-ir` (shared IR + grade vocabulary + structural hash), `vehje-signature`
(language-level graded signature), `vehje-fixpoint` (generic relational engine), `vehje-resolve`,
`vehje-typecheck` (the graded check), `vehje-lower`, `vehje-schedule`, `vehje-codegen`, `vehje-runtime-gen`,
`vehje-runtime-abi`, `vehje-runtime-driver`, and `vehje` (orchestration). No crate is added, removed, split, or
merged this round. The two deferred renames (`vehje-typecheck` to `vehje-check`, and the architect's suggested
`vehje-codegen` to `vehje-emit`) remain owed to op, not settled here.

## Implement now (design settled, real algorithm, no unbuilt prerequisite)

These the round turns into real, tested code, each matching its DESIGN:

1. `vehje-lower` cheap stratum: `ConstFold` folds a node whose operands are all `Lit` to its literal;
   `Cse` builds the `StructuralHash`-to-`NodeRef` hash-cons table (over a caller-lent region, no alloc) and
   rewrites duplicate subtrees to the first occurrence; `Anf` hoists non-trivial subexpressions into `Let`
   bindings. These are the node-count-reduction win the bench sized (76% fewer nodes), and they are concrete
   rewrites over the existing arena.
2. `vehje-fixpoint`: the semi-naive delta evaluation (the current whole-column strategy stays the default the
   bench chose for shallow graphs, but the delta path is implemented and selectable), and `Congruence`
   re-derivation after closing the given equalities (so a closed congruence actually propagates).
3. `vehje-typecheck`: the reachability binder rule (at `Let` and `Lambda`, splice the bound expression's reach
   set where the body reaches the variable, then drop the variable's own slot), the concrete lease inference
   the design's degenerate depth-lease floor names.
4. `vehje-schedule`: the pass DAG over `arvo-bitmask`'s `BitMatrix` adjacency (reused, not reinvented), with
   the per-pass read/write sets, so `PassDag` is a real dependency graph rather than an inert placeholder.
5. `vehje-ir`: the family numeric-id assignment (the id a runtime bitmask keys on), and `GradeTable` `get`/`set`
   returning a bounds-checked `Maybe`/`Outcome` rather than panicking on an undersized region.
6. `vehje-runtime-driver`: the full typed structural decode over a value arena (bounds plus the monotone
   child-index check the children-first order makes linear), the real body of the `Reader::validate` the
   soundness review flagged, using the `try_get` accessor that round `202607240600` added.
7. `vehje-runtime-abi`: the `#[no_mangle] pub unsafe extern "C" fn` batched-column entry export (the actual
   entry the runtime calls), defined even while the cdylib build itself stays an rlib pending the no_std
   panic-runtime story.

## Honest markers kept (design defers, or research-grade)

These stay FIXME-marked; implementing them now would invent a shape no consumer has constrained, or fake a
research-grade mechanism:

- The family payload IR shapes: `Match` arm pattern-plus-body pairs, `Handle` clause operation-id + handler
  body + resumption binder, and the `Raw` family-interpreted payload encoding. The design defers each until the
  first consumer that uses it defines its shape; inventing one now is a guess, not an implementation.
- The `vehje-lower` `Saturate` stratum (the no-alloc bounded streaming e-graph). Research-grade; the design
  ships the cheap stratum and gates saturation behind the bounded window, which is a dedicated later effort.
- The `vehje-typecheck` fixpoint-routed inference (routing reach and effect through `vehje-fixpoint` as
  relational queries) and the program-derived inclusion half (deriving the used family/effect sets from the
  program rather than trusting caller-supplied sets). The direct bottom-up fold is the sanctioned M-level; the
  fixpoint routing and the runtime-bitmask inclusion are the sized-but-deferred next layer.
- Binding-time discharge and the effect-drop-on-`Handle` rule, both blocked on prerequisites not yet built
  (per-node knowledge-source annotations; the `Handle` clause representation above).
- The census-corpus harness (`vehje-runtime-gen`), `compile_language` and the grammar byte-source seam
  (`vehje`): all wait on a real consumer, which does not exist yet.

## The plan for the rest of the round

The doc changelist is light: the docs already model the design, so it records only where the new
implementation refines a documented surface (the `GradeTable` `Maybe`/`Outcome` return, the family-id API, the
`Reader::validate` body, the schedule DAG becoming real) and clears the two standing doc-wording debts (the
`hash_of` "stable across arenas" narrowing, the `ValueTag` discriminant wording). The source changelist
implements the "implement now" set above, crate by crate in dependency order, each with tests strict enough to
fail until the code matches, and larger units reviewed by a domain expert before the round locks.
