## Deliverables

### clause-syntax (new src)

1. `src/ast.rs` — AST arena types. Roughly 110–140 lines.

   - `pub const MAX_CHILDREN: usize = 8;` — const-sized child
     slot count per node this round. Larger productions either
     raise this constant in their own round or switch to a side
     table keyed by `NodeId`.
   - `pub struct AstNode { kind: AstNodeKind, span: Span,
     children: [NodeId; MAX_CHILDREN], child_count: u8 }`.
     `Copy + Clone + Eq + PartialEq + Hash + Debug + Default`.
     Methods: `new(kind, span) -> Self`, `leaf(kind, span)`
     helper, `children(&self) -> &[NodeId]` slice over
     `child_count`, `push_child(&mut self, id: NodeId) -> bool`
     (returns `false` if at capacity).
   - `pub const MAX_NODES: usize = 256;` — default arena cap
     this round. Larger programs come with a const-generic Ast
     later; skeleton stays fixed.
   - `pub struct Ast { nodes: [AstNode; MAX_NODES], len: u32,
     root: Option<NodeId> }`. `Copy` via `[AstNode; N]` being
     `Copy` (AstNode is `Copy`).
   - Methods: `Ast::empty() -> Self`, `Ast::is_empty(&self) ->
     bool`, `Ast::len(&self) -> usize`, `Ast::root(&self) ->
     Option<NodeId>`, `Ast::set_root(&mut self, id: NodeId)`,
     `Ast::push(&mut self, node: AstNode) -> Option<NodeId>`
     (returns `None` if arena full), `Ast::get(&self, id:
     NodeId) -> Option<&AstNode>`, `Ast::get_mut(&mut self, id:
     NodeId) -> Option<&mut AstNode>`.

2. `src/error.rs` — diagnostic carrier. Roughly 60–90 lines.

   - `pub enum SyntaxErrorKind { UnexpectedToken,
     UnexpectedEof, InvalidLiteral }`. `Copy + Clone + Eq +
     PartialEq + Hash + Debug`. `Default` → `UnexpectedToken`.
   - `pub struct SyntaxError { kind: SyntaxErrorKind, span:
     Span, message: &'static str }`. `Copy` etc.
   - Constructors: `SyntaxError::unexpected_token(span,
     message)`, `SyntaxError::unexpected_eof(span, message)`,
     `SyntaxError::invalid_literal(span, message)`.
   - `impl From<SyntaxError> for clause_ir::Diagnostic` —
     converts to an error-severity diagnostic carrying the
     span and message.

3. `src/parser.rs` — driver loop. Roughly 120–170 lines.

   - `pub struct Parser<'a> { tokens: &'a [Token], cursor: u32,
     ast: Ast }`.
   - `Parser::new(tokens: &'a [Token]) -> Self`.
   - Core helpers (used by follow-up rounds):
     - `peek(&self) -> Option<&Token>` — token at cursor.
     - `peek_kind(&self) -> Option<TokenKind>`.
     - `peek_at(&self, offset: usize) -> Option<&Token>`.
     - `bump(&mut self) -> Option<&Token>` — advance, return
       the consumed token.
     - `at(&self, kind: TokenKind) -> bool`.
     - `is_eof(&self) -> bool` — cursor at end OR peek kind is
       `Eof`.
     - `current_span(&self) -> Span` — span of current token,
       or a zero-span at the last token's end if past EOF.
   - `Parser::parse(mut self) -> Result<Ast, SyntaxError>` —
     the minimal skeleton grammar:
     - If `is_eof()` at entry → `Ok(self.ast)` (empty Ast).
     - If the next token is `IntLit`:
       - Push an `AstNode { kind: AstNodeKind::Expr, span: <lit
         span> }` into the arena.
       - Set that id as root.
       - Bump the literal.
       - Expect `Eof` (or end of slice); anything else →
         `UnexpectedToken` error.
       - Return `Ok(self.ast)`.
     - Anything else → `UnexpectedToken` error.

4. `src/lib.rs` — top-level entry. Roughly 40–60 lines.

   - `#![no_std]` + crate-level doc comment.
   - `#![deny(unused, unreachable_code, unused_must_use,
     unused_imports, dead_code)]` matching sibling crates.
   - `pub mod ast;`, `pub mod error;`, `pub mod parser;`.
   - Re-exports: `Ast`, `AstNode`, `MAX_CHILDREN`, `MAX_NODES`
     from `ast`; `Parser` from `parser`; `SyntaxError`,
     `SyntaxErrorKind` from `error`; `NodeId`, `AstNodeKind`,
     `Span` re-exported from `clause_ir`; `Token`, `TokenKind`
     re-exported from `clause_lex` / `clause_ir`.
   - `pub fn parse(tokens: &[Token]) -> Result<Ast,
     SyntaxError>` — constructs `Parser::new(tokens)` and
     calls `.parse()`.

### Tests (`clause-syntax/tests/`)

1. `tests/ast_types.rs` — 4 tests:
   - `ast_empty_is_empty` — `Ast::empty()` reports length 0,
     root None.
   - `ast_push_returns_monotonic_ids` — push three nodes,
     verify `NodeId` indices 0, 1, 2.
   - `ast_get_round_trip` — push a node, fetch by id, assert
     kind/span match.
   - `astnode_leaf_has_no_children` — construct a leaf, verify
     `children()` returns empty slice and `child_count == 0`.

2. `tests/empty_input.rs` — 2 tests:
   - `parse_empty_slice` — `parse(&[])` returns `Ok`, `Ast` is
     empty, root is `None`.
   - `parse_slice_with_only_eof` — `parse(&[eof_token()])`
     returns `Ok`, `Ast` is empty.

3. `tests/single_literal.rs` — 3 tests:
   - `parse_int_literal_then_eof` — `parse(&[int_tok, eof])`
     returns `Ok` with root set; root node kind is `Expr`, span
     matches the literal's span, `child_count == 0`.
   - `parse_int_literal_at_end_of_slice` — same but no explicit
     `Eof` token (parser treats end-of-slice as EOF).
   - `parse_int_literal_sets_root` — after parse, `ast.root()`
     is `Some(NodeId(0))`.

4. `tests/unexpected_token.rs` — 3 tests:
   - `parse_plus_is_unexpected_token` — `parse(&[plus, eof])`
     returns `Err` with kind `UnexpectedToken`.
   - `parse_ident_is_unexpected_token_in_skeleton` — even
     `Ident` is unexpected this round (identifier productions
     are BACKLOG).
   - `parse_literal_followed_by_non_eof_is_unexpected_token` —
     `parse(&[int_tok, plus, eof])` returns `Err` —
     `UnexpectedToken` after the literal.

Total: 12 tests.

Every test builds its token slice with a small helper
(`tok(kind, start, end)` → `Token`) so the tests read compactly
and the intent is obvious.

## Impl-time decisions (pre-committed)

1. **`Ast` is `Copy`** via fixed-size arrays. Skeleton size is
   `MAX_NODES = 256`. Any production that needs more either
   ships its own const-generic `Ast<const N: usize>` (follow-up
   round) or switches to a caller-sized arena shape once the
   real parser lands.
2. **`AstNode::children` is a `[NodeId; 8]` + `child_count:
   u8`** — no `Option` wrapping. Unused slots are `NodeId::default()`
   but `child_count` bounds the slice; callers must go through
   `children()` / `push_child`.
3. **`SyntaxError::message` is `&'static str`** to match
   `Diagnostic` and stay alloc-free.
4. **`From<SyntaxError> for Diagnostic`** emits
   `Severity::Error` with an empty `related` list.
5. **Parser treats end-of-slice and `TokenKind::Eof` the same
   way** — either terminates parse. `clause-lex` appends a
   final `Eof` token, but calling `parse(&[])` directly (useful
   in tests and for the trivial-input case) also works.
6. **`current_span` returns a zero-length span at the end of
   input when the cursor is past the last token**, using the
   last token's end offset as the point. Prevents callers from
   having to case-split on EOF.
7. **No `alloc` dependency.** Every buffer is fixed-size.
