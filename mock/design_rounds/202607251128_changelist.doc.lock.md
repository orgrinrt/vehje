# Doc changelist: the host drives the runtime

**Round:** 202607251128 (topic: `202607251128_topic.the-host-drives-the-runtime.md`)
**Phase:** DOC
**Scope:** `vehje-runtime-driver/DESIGN.md.tmpl` gains the real embedding and drops the superseded loader and `std` claims. `runtime-zig/DESIGN.md.tmpl` moves the produced-value crossing from intended to shipped.

## `mock/crates/vehje-runtime-driver/DESIGN.md.tmpl`

- Opening: keep the crate's role (the compile-side embedding and dispatch, and the in-process consumer of what crosses back). Replace the "designed to be the one framework crate with a `std` role, for the dlopen of the runtime artifact" claim and its owed-role note. Loading goes through `hilavitkutin-linking`, the workspace's pull-based explicit-symbol loader over dlopen and LoadLibrary, which is `no_std` and holds no allocator, so embedding needs no `std`. State that plainly, and state why the crate reaches for the workspace primitive rather than a third-party loader.
- Scope: add `Runtime`, the loaded artifact. It opens by path, resolves the three exported entries (`vehje_runtime_new`, `vehje_runtime_free`, `vehje_runtime_execute`) once at open so a later call cannot fail on a missing symbol, executes a serialized residual against a caller-lent output buffer, and closes explicitly with the platform result surfaced (the drop path remains the fallback). Say that the resolved symbols cannot outlive the library, which the type enforces rather than asks for.
- Scope: describe the sink the driver supplies. The runtime writes the produced value through the host's reserve-then-commit callbacks, so the driver lends one caller-provided buffer and records what was committed, the degenerate single-reserve case the transfer contract allows. A buffer too small to hold the image refuses the reservation, which the runtime reads as backpressure rather than as a failure to write.
- Scope: extend the `DriverError` entry with the failures the embedding makes reachable, naming each: the artifact could not be loaded, an expected symbol was missing, and the runtime reported an execution failure. A missing symbol and a rejected program are different problems and stay distinguishable.
- Keep `Reader` and its validation description unchanged. Add one sentence saying the untrusted decode over committed bytes is `ValueImage` in `vehje-runtime-abi`, so this crate adds no second decoder.
- Deferred: drop the dlopen-embedding line now that it ships. Keep the runtime build integration note. Keep the diagnostic mapping as owed, since mapping runtime diagnostics to `vehje-ir::Diagnostic` still has no wire diagnostics to map.
- Dependencies: add `hilavitkutin-linking`. Correct the `std` sentence to say the crate is `#![no_std]` with no alloc, and that the `std` feature no longer gates the embedding.

## `mock/runtime-zig/DESIGN.md.tmpl`

- The C ABI surface section: record that `vehje_runtime_execute` takes a sink pointer alongside the residual, and that a null sink means the host wanted only the outcome.
- Intended-not-shipped list: remove the produced-value bullet and add the shipped description in its place. The value is marshalled into the value image layout and committed through the host's reserve-then-commit sink; a closure is refused with a named reason because it has no value-arena representation; a refused reservation is backpressure. Keep every other intended item (family operations and host calls, strings and sequences and records, the remaining Core forms, the `Bytecode` tier, per-session arena state and diagnostics) exactly as it stands.
