# Topic: split vehje-lower/lib.rs to satisfy the file-size gate

**Date:** 2026-07-25
**Phase:** TOPIC
**Scope:** vehje-lower

## Current state

`mock/crates/vehje-lower/src/lib.rs` is 405 non-blank, non-comment lines,
one over the 400-line push-gate limit. The file carries the lowering pass
plus a large `#[cfg(test)] mod tests` (roughly 120 lines). The
`file-size` lint blocks push until the file is split.

## Decision

Move the test module to a sibling `src/tests.rs`, referenced from
`lib.rs` by `#[cfg(test)] mod tests;`. This is the split the file-size
rule recommends for a large test module and drops `lib.rs` well under
the limit. No design change, no public-surface change, no doc-template
change: a pure code-organization refactor.
