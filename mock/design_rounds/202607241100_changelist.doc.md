# Doc changelist: the family-extension dispatch seam

Doc-template edits for round `202607241030`. The `vehje-resolve` and `vehje-typecheck` DESIGNs already state
the passes are "generic over the family set, with family-extension hooks"; the implementation did not deliver
that, treating a `Raw` node as an inert leaf. This changelist documents the hook traits the implementation adds
so the passes match their own DESIGN, and records that all three Core passes now descend into a `Raw` node's
payload. New public surface: the family-dispatch hook traits and the Core-only default that implements them.

## vehje-resolve/DESIGN.md.tmpl

- Document `FamilyResolve`: the family-extension hook trait a consumer implements to add family-specific
  resolution (a family binding form) at a `Raw` node. Its default method is a no-op, because the base pass
  already descends into the `Raw` payload and resolves its Core children. `resolve` and `resolve_into` remain
  the Core-only entries (they use the default hook); `resolve_with` and `resolve_into_with` take a consumer
  hook. Document `CoreFamilies`, the no-op default the Core-only entries use.
- State that the resolve walk descends into a `Raw` node's payload, resolving its child handles exactly as an
  `Apply`'s arguments, rather than treating `Raw` as a leaf.

## vehje-typecheck/DESIGN.md.tmpl

- Document `FamilyCheck`: the family-extension hook trait a consumer implements to declare a family operation's
  own effect (`effect_of_raw`, defaulting to the empty effect). The check pass descends into a `Raw` node's
  payload, joins the children's grades, and joins the family operation's declared effect from the hook. `check`
  remains the Core-only entry (default hook); `check_with` takes a consumer hook.

## vehje-codegen/DESIGN.md.tmpl

- State that `fold_core` descends into a `Raw` node's payload, folding its child handles so a target's `visit`
  sees them, rather than treating `Raw` as a leaf. The target's `visit` closure is itself the family fold hook
  (it is called on every node, including a `Raw` and its now-visited payload children), so no separate codegen
  hook trait is needed.
