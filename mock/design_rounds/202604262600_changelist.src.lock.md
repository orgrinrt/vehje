## Impl-time decisions (pre-committed)

1. **Sanctioned `&'static dyn Validator`** in ValidatorRegistry —
   same exception as R3's TargetRegistry, same justification
   (static-lifetime, const-sized, registry iteration surface only).
2. **STRICT1-7 as core validators** — ported from Python era;
   shapes match that prior art.
3. **Category → default severity** mapping fixed this round:
   Strict/Type=Error, Style=Warning, Performance=Info,
   Custom=trait default.
4. **Suppression hierarchy fixed**: item > crate > workspace >
   category default.
5. **Sequential per-node validator execution** this round;
   parallelisation is a BACKLOG optimisation.
