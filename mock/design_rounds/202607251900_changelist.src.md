# Src changelist: Project evaluation over records

**Date:** 2026-07-25
**Phase:** IMPL
**Doc CL:** `202607251900_changelist.doc.lock.md`

One form gains evaluation, two refusals gain names, and the tests cover both the hit and the two ways it can
miss.

## CHANGE: `EvalError` GAINS `NotARecord` and `NoSuchField`

File: `mock/runtime-zig/src/runtime.zig`
The doc CL locked these as two distinct names rather than one, because projecting from a non-record and
projecting an absent field are different mistakes for whoever has to fix one.
Verification: `grep -n "NotARecord\|NoSuchField" mock/runtime-zig/src/runtime.zig` returns both.

## CHANGE: `eval` GAINS the `TAG_PROJECT` arm

File: `mock/runtime-zig/src/runtime.zig`, the `eval` switch
FROM falling through to `EvalError.Unsupported`
TO evaluating the base at the node's first child word, requiring a `.compound` whose arena node is a record,
reading the key as a blob span from the two words after it (the shape a string literal already uses), and
walking the record's alternating key and value children comparing the key bytes.
Verification: `grep -n "TAG_PROJECT =>" mock/runtime-zig/src/runtime.zig` returns one match, and the tests
below pass.

## CHANGE: the family test suite GAINS three `Project` tests

File: `mock/runtime-zig/src/runtime_family_test.zig`
A hit: a handler returns a record and `Project` reads a named field out of it. Two misses: projecting from an
integer is `NotARecord`, and projecting an absent field is `NoSuchField`. The two misses are separate tests
because the whole point of the two names is that they are distinguishable.
Verification: `zig test src/runtime.zig` passes with three more tests than before.

## Not in this round

The compile-resolved offset and the inline cache, both of which need a record shape the emitter does not yet
name. Sequence indexing by a computed value. `Match`, `Iter`, `Interp`, `Handle`.
