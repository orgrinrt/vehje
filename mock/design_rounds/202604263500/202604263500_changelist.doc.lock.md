## Purpose

Ship the resolver crate scaffolding for Clause: the type surface
for scopes and symbols, a stubbed `Resolver` driver, a stub
`parse_manifest`, and a top-level `resolve` entry point that walks
an empty/skeleton AST and produces an empty `Resolved`. This is
the saalis-style skeleton pattern — land the harness, defer every
resolution rule (top-level items, local bindings, use-trees, path
lookup, visibility, generics, traits, hygiene) to follow-up
micro-rounds.

Without this round, clause-resolve is an empty crate; with it,
downstream phases (clause-typecheck, clause-schedule,
clause-codegen) have a concrete `Resolved { ast, scopes, resolution
}` to key work off, and each deferred resolution rule ships as an
isolated round on top of a stable harness.

## Deliverables this round

### clause-resolve — type surface

- `SymbolKind` — enum `{ Type, Value, Module, Import, Function,
  Const }`. `Copy + Clone + Eq + PartialEq + Hash + Debug +
  Default`. Default variant `Value`.
- `Symbol` — struct carrying `name: String`, `scope: ScopeId`,
  `node: NodeId`, `kind: SymbolKind`. Owned string this round —
  interning is BACKLOG. `Clone + Eq + PartialEq + Hash + Debug`.
- `Scope` — struct carrying `parent: Option<ScopeId>` and
  `symbols: HashMap<String, Symbol>`. `Clone + Debug + Default`.
- `ScopeTree` — struct wrapping `scopes: Vec<Scope>`. Methods:
  `new() -> Self` (allocates a root scope at index 0),
  `root() -> ScopeId`, `len() -> usize`, `get(ScopeId) ->
  Option<&Scope>`, `push(parent: Option<ScopeId>) -> ScopeId`
  (creates a new scope, returns its id). `Clone + Debug + Default`.
- `Resolved` — struct wrapping `ast: Ast`, `scopes: ScopeTree`,
  `resolution: Vec<Option<Symbol>>` (indexed by `NodeId`). Methods:
  `empty() -> Self`, `is_empty() -> bool`, constructor `new(ast:
  Ast, scopes: ScopeTree, resolution: Vec<Option<Symbol>>)`.
- `Manifest` — struct carrying `crate_name: String`, `version:
  String`, `dependencies: Vec<String>`. `Clone + Debug + Default`.

### clause-resolve — driver stub

- `Resolver` — struct owning `ScopeTree` + cursor state `current:
  ScopeId`. Methods: `new() -> Self` (fresh `ScopeTree`, cursor at
  root), `resolve(&mut self, ast: &Ast) -> Result<Resolved,
  ResolveError>` (stub: opens top scope, does nothing, returns
  `Resolved { ast: *ast, scopes: self.scopes, resolution: vec![None;
  ast.len()] }`).

### clause-resolve — manifest parser stub

- `parse_manifest(bytes: &[u8]) -> Result<Manifest, ManifestError>`
  — stub rules:
  - Empty input → `Ok(Manifest::default())`.
  - Any other input → `Err(ManifestError::NotImplemented)`.

### clause-resolve — errors

- `ResolveError` — enum:
  - `UnresolvedIdentifier { name: String, span: Span }`
  - `DuplicateDefinition { name: String, span: Span, prev_span:
    Span }`
  `Clone + Eq + PartialEq + Hash + Debug`. `From<ResolveError> for
  clause_ir::Diagnostic` converts to error-severity diagnostics
  (message is a static placeholder for the skeleton).
- `ManifestError` — enum:
  - `Parse { message: &'static str }`
  - `NotImplemented`
  `Copy + Clone + Eq + PartialEq + Hash + Debug`.

### clause-resolve — entry point

- `resolve(ast: &Ast) -> Result<Resolved, ResolveError>` —
  top-level function. Constructs `Resolver::new()` and forwards
  to `.resolve(ast)`.

### Tests (`clause-resolve/tests/`)

- `tests/scope_tree.rs` — 4 tests:
  - `root_scope_has_no_parent` — `ScopeTree::new()` has a root
    scope with `parent == None`.
  - `push_returns_monotonic_ids` — push three child scopes, verify
    `ScopeId(1)`, `ScopeId(2)`, `ScopeId(3)`.
  - `nested_scope_parent_chain` — push `A` under root, `B` under
    `A`, verify `B.parent == Some(A)`.
  - `get_out_of_range_returns_none` — `tree.get(ScopeId(99))` →
    `None`.
- `tests/symbol_types.rs` — 3 tests:
  - `symbol_kind_variants_distinct` — every `SymbolKind` variant
    differs under `PartialEq`.
  - `symbol_holds_fields` — construct a `Symbol`, assert name /
    scope / node / kind round-trip.
  - `symbol_kind_default_is_value` — `SymbolKind::default() ==
    Value`.
- `tests/empty_ast.rs` — 2 tests:
  - `resolve_default_ast_ok` — `resolve(&Ast::default())` returns
    `Ok(Resolved)` whose `resolution` is an empty vec.
  - `resolved_is_empty_on_empty_ast` — same, verify
    `Resolved::is_empty()` is true.
- `tests/manifest_empty.rs` — 2 tests:
  - `parse_empty_returns_default` — `parse_manifest(b"")` returns
    `Ok(Manifest::default())`.
  - `parse_nonempty_returns_not_implemented` —
    `parse_manifest(b"not-toml")` returns
    `Err(ManifestError::NotImplemented)`.
- `tests/resolve_errors.rs` — 2 tests:
  - `unresolved_identifier_constructs` — build a
    `ResolveError::UnresolvedIdentifier` and assert its fields.
  - `duplicate_definition_constructs` — build a
    `ResolveError::DuplicateDefinition` and assert its fields.

Target ~12 tests total (13 in practice).
