# Topic: wire vehje::run end to end

**Date:** 2026-07-25
**Phase:** TOPIC
**Scope:** vehje (the run entry + a test), vehje DESIGN.md.tmpl

## Current state

`vehje::run` resolves the Core binders and stops (`vehje/src/lib.rs:72`,
a FIXME). The full per-program compile path (resolve, graded check, mint the
`Checked` witness through the target's inclusion sets, emit through the
target) is proven by `first_light_emits_the_program` but only as a manual
sequence in the test, not through the public entry.

## Decision

Wire `run` to the proven path: `run<T, Families, Effects, S>(target, arena,
root, res, grades, sink)` resolves, runs the graded `check`, mints
`check_for::<T, Families, Effects>` (the family and effect inclusion check
against the target's `Supports` / `Permits`), and emits through the target
into the sink. A stage failure returns a `Diagnostic` naming the `Phase`.
The caller lends the resolution and grade regions (no alloc) and names the
program's family and effect sets (the target proves inclusion). A test drives
a program through `run` and asserts the emitted bytes.

The cheap lowering (ANF) is not yet threaded into `run`: the check-then-lower
sequencing and which arena the `Checked` witness covers is its own design
gate, kept as a FIXME. The runtime execution hand-off (the Zig runtime that
executes the emitted residual) is the separate downstream gate, also a FIXME.
