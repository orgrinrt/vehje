# Changes proposed

## `clause-resolve` public surface

`Symbol::name: String` becomes `Symbol::name: Str`. `Symbol::new`
accepts `impl IntoStr` and stores the interned handle. `Symbol`
gains `Copy`. Usages in the accessor `Symbol::name(&self)` return
`Str` by value (since `Str: Copy`) instead of `&str`.

`ResolveError::UnresolvedIdentifier { name: String, span }` and
`ResolveError::DuplicateDefinition { name: String, span,
prev_span }` shift to `name: Str`. The variants inherit `Copy` if
the rest of the error shapes allow; `Span` and `ScopeId` already
are. `ResolveError` becomes `Copy` + `Eq` (tightening `PartialEq`
into structural equality over four `u32`s). The `From<ResolveError>
for Diagnostic` impl keeps its static-string mapping — per-variant
rendering with the interned name is BACKLOG for the diagnostic
registry (#168).

`Manifest::crate_name: String` and `Manifest::version: String`
become `Str`. The accessors return `Str` by value. `Manifest`
remains `Clone + Debug + Default`. The `parse_manifest` stub
returns `Manifest::default()` unchanged for empty input.

`Scope::insert(&mut self, name: String, symbol: Symbol)` becomes
`Scope::insert(&mut self, name: Str, symbol: Symbol)`.
`Scope::lookup(&self, name: &str)` becomes `Scope::lookup(&self,
name: Str)` (`Str` comparison is `u32` equality; no hashing of
text needed).

`ScopeTree::len(&self) -> usize` becomes `ScopeTree::len(&self)
-> USize`. `ScopeTree::is_trivial` keeps `Bool` already (it is
`arvo::Bool`).

## `clause-resolve` internal collection fields

The four deferred collection fields stay as `std::collections::HashMap`
/ `Vec` skeleton storage, carved out via `SHAME.md` + trailing
inline `lint:allow(bare_collection)` `reason:` `tracked: #131`.
The SHAME.md entries explain that the canonical home of these
storages is the `hilavitkutin` scheduler — once #131 lands
(`clause-schedule as WorkUnit home`), each field is re-expressed
as a scheduler-managed `Column<T>` or `Map<K, V, N: Cap>`
descriptor over an AccessSet-typed read/write. Today's skeleton
holds the storage inline so the resolver and the manifest parser
have somewhere to write state.

The SHAME key for each field is the struct name:

- `Scope` covers `Scope::symbols` (`HashMap<Str, Symbol>` after
  the `String` retirement).
- `ScopeTree` covers `ScopeTree::scopes` (`Vec<Scope>`).
- `Resolved` covers `Resolved::resolution` (`Vec<Maybe<Symbol>>`).
- `Manifest` covers `Manifest::dependencies` (`Vec<Str>` after
  the `String` retirement).

Each SHAME entry runs over the 50-word minimum and cites #131
and #134 (persistence spine) as the landing points.
