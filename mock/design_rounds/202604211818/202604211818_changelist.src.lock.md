## Purpose

Retire the last bare `String`s in `clause-resolve`. Replace owned
`String` with `hilavitkutin_str::Str` in the symbol, error, and
manifest surfaces. Return `arvo::USize` from `ScopeTree::len`.
The four deferred collection-field storages (`Scope::symbols`
`HashMap`, `ScopeTree::scopes` `Vec`, `Resolved::resolution`
`Vec`, `Manifest::dependencies` `Vec`) gain trailing-inline
`lint:allow(bare_collection)` `tracked: #131` markers matching
the SHAME.md keys landed in the doc CL. Ten source files change
(six crate sources, one crate Cargo.toml, one workspace
Cargo.toml, one test file, one src re-export).

No source changes outside `clause-resolve` except the workspace
`Cargo.toml` (to register `hilavitkutin-str` as a workspace
dep). The lint severity flip already landed in the doc CL;
after source execution the tree stays green at the new `error`
gates.

### Change S3 — `clause-resolve/src/symbol.rs`: `Symbol::name: Str`

Three-part rewrite:

Imports: add `hilavitkutin_str::Str` next to the existing
`clause_ir::{NodeId, ScopeId}` use.

Module-doc: retire the "owned `String`" BACKLOG note (it has
landed):

```
- //! Skeleton round: names are owned `String`. Interning is BACKLOG
- //! (string interning will also let `Symbol` become `Copy`, which
- //! the current owned-`String` design deliberately forgoes to keep
- //! the surface obvious).
+ //! Names are `hilavitkutin_str::Str` — 4-byte Copy handles keyed
+ //! by interned identity. This makes `Symbol` itself `Copy`,
+ //! which in turn makes `ResolveError` `Copy` (the error variants
+ //! carry a copied name).
```

Struct derives: drop `Clone` bound (becomes redundant under
`Copy`). Add `Copy`:

```
- #[derive(Clone, Eq, PartialEq, Hash, Debug)]
+ #[derive(Copy, Clone, Eq, PartialEq, Hash, Debug)]
  pub struct Symbol {
-     name: String,
+     name: Str,
      scope: ScopeId,
      node: NodeId,
      kind: SymbolKind,
  }
```

Constructor:

```
-     pub fn new(name: impl Into<String>, scope: ScopeId, node: NodeId, kind: SymbolKind) -> Self {
-         Self { name: name.into(), scope, node, kind }
+     pub fn new(name: Str, scope: ScopeId, node: NodeId, kind: SymbolKind) -> Self {
+         Self { name, scope, node, kind }
      }
```

Rationale: taking `Str` directly is simpler than accepting an
`impl IntoStr` (which forces passing the interner at every call
site). Call sites construct the `Str` via `str_const!("…")` at
compile time or via `StringInterner::intern` at runtime; either
is a one-line preamble.

Accessor:

```
-     /// Name text of this symbol.
-     pub fn name(&self) -> &str {
-         &self.name
+     /// Name handle of this symbol.
+     pub fn name(&self) -> Str {
+         self.name
      }
```

Accessor doc-comment updated per the value-return semantics.

### Change S8 — `clause-resolve/src/resolver.rs`: no signature change

`resolver.rs` carries no bare `String`. The `resolve` method
constructs `vec![Maybe::Isnt; ast.len()]` which is then passed
to `Resolved::new`; that Vec's lifetime is entirely inside the

does not fire on it.

## Ordering

Apply in order: S1 → S2 (deps first so compilation doesn't
break) → S3 (Symbol::name is foundation) → S4 (error uses
Symbol's name via Str directly) → S5 (scope uses Symbol +
Str) → S6 (resolved uses Symbol + ScopeTree) → S7 (manifest
uses Str, independent) → S8 (resolver glue, may no-op) → S9
(lib.rs re-export, last) → S10 (test update last).

Single commit is acceptable for this sweep — the changes are
atomic and the doc lock already pinned the contract. If the
cascade surfaces a cross-file issue, break into two commits
(dep + resolve-source vs test-update).
