## CHANGE: add an end-to-end consumer integration test
File: `mock/crates/vehje/tests/consumer_demo.rs` (new)
A minimal consumer built against `vehje` alone: a family marker `Demo` (implementing `Family`), a target
`DemoTarget` declaring `Supports = (Core, Demo)` and `Permits = ()`, a program that puts a Core sub-expression
inside a `Raw(Demo)` node, run through resolve, the graded check, `check_for` to mint the `Checked`, and emit
through the target into a byte sink. Asserts the emitted output covers the family node and its Core child, so
the descent and the full pipeline are exercised end to end from a consumer's position.
Verification: `cargo test -p vehje --test consumer_demo` passes.
