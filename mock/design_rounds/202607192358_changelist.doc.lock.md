# Doc changelist: reframe vehje as the framework

**Date:** 2026-07-19
**Phase:** DOC
**Round:** extension-point contract (topics `202607190650` through `202607192340`).
**Scope:** Rewrite the design and agent-instruction surfaces from "vehje is a general-purpose scripting
language" to "vehje is the multi-input, multi-output, embeddable IR framework; the general-purpose language is
one first-party consumer, named later". Reframe the surviving crates' design docs to the framework crate
surface. The crate deletions (`vehje-lex`, `vehje-syntax`, `vehje-runtime-tests`) and the `vehje-typecheck` to
`vehje-check` rename are source-tree operations and land in the src changelist, where each crate's source and
its doc templates move together; this doc CL does not touch those crates' templates.

## Framing decisions this CL encodes (from the locked topics)

The identity reframing (`202607192254`), the input-side contract (`202607192300`), the output-side contract
with inclusion-not-coverage exhaustiveness, compile-time dispatch, and the parametrized effect axis
(`202607192310`), the framework crate surface (`202607192320`), the 11 ratified Core forms (`202607192330`),
and the tier-tagged C ABI plus runtime execution model (`202607192340`). The doc surfaces are brought into
line with those; the topics are the authority, this CL is the mechanical propagation into the shipping-contract
docs.

  framework identity: vehje is the embeddable, multi-input, multi-output IR framework; grammars plug in on the
  input side, targets on the output side; the general-purpose language is one first-party consumer named later.
- Replace the "Status / extracted from the Python prototype / parity oracle" section: the Python prototype is
  heritage for the first-party language consumer, not the framework's oracle. The framework's design authority

- Replace "Two-language strategy" framing so "the language" reads as "a consumer language"; keep the Rust
  compiler / Zig runtime / C ABI split, restated as the framework's compile side and runtime side, and add the
  tier-tagged residual (arena baseline, bytecode, native endgame with Zig as env-plumbing).
- Rewrite "Layers" to the framework crate surface: `vehje-ir`, `vehje-codegen`, `vehje-schedule`,
  `vehje-resolve`, `vehje-check`, `vehje-runtime-abi`, `vehje-runtime-driver`, `vehje`. Note the offered
  opt-in front-end scaffolding (not shipped now) and that the front-end and family live in consumer repos.
- Rewrite "Extension pattern" to the ten-consumer census framing: grammars and targets are consumers, each a
  separate repo bringing a grammar (front-end producing IR), a family (node kinds plus a `Family` impl plus

## Per-crate design surfaces (surviving crates only)

Each surviving crate's `DESIGN.md.tmpl` and `README.md.tmpl` is rewritten to its framework role from the crate
surface topic. Type-name claims are kept minimal and prose-led where the source does not yet exist (the source
lands in the src CL); backticked type names are used only for types the src CL commits to, so the
`design-doc-source-mismatch` lint tracks real obligations. Where a design point is committed but unbuilt, it
goes in `BACKLOG.md.tmpl` (unbackticked) per the mock-workspace rule, not in `DESIGN.md.tmpl`.

- `vehje-ir`: the shared representation. Arena, `u32`-indexed Core nodes, `EntityList`/`ListPool` variable
  arity, the 11 Core forms, the `Family` extension trait plus effect classification, the family-set and
  effect-set typestate reusing `hilavitkutin-api` `AccessSet` with vehje family and `Reads<E>`/`Writes<E>`
  effect markers, the monoid builder, interner integration.
- `vehje-codegen`: the output machinery. One generic fold, the `Target` trait with `Supports` family set and
  `Permits` effect set as associated type-level sets, inclusion-check plus effect-check plus `Checked<T>`
  gating, compile-time target composition (generated match, no `dyn`). Drop the `dyn CodegenTarget` registry
  from the doc.
- `vehje-schedule`: the pass DAG over `arvo-graph`. Drop the typecheck dependency framing.
- `vehje-resolve`: the Core-level resolve pass, borrowed non-allocating scope chain over Core binders, generic
  over the family set, family-extension hooks.
- `vehje-runtime-abi`: the tier-tagged C ABI. The `Checked` residual crossing as a flat serialized IR arena
  (tier 0), tier tag reserving bytecode (tier 1) and native (tier 2), the runtime-environment interface.
- `vehje-runtime-driver`: compiler-side dispatch over the ABI, Zig runtime embedding.
- `vehje`: the two public contracts (the grammar plug-in and the target plug-in), orchestration, the
  distribution-composition entry point, a reference distribution.
