# Src changelist: runtime-ABI soundness fixes

Source execution for round `202607240530`, against the locked doc CL
`202607240600_changelist.doc.lock.md`. Gives the value-arena wire records a declared `#[repr(C)]` layout,
makes the arena accessors bounds-safe, and adds the untrusted-path accessor. `#![no_std]`, no alloc.

## CHANGE: `#[repr(C)]` on the value-arena wire records in `vehje-runtime-abi`
File: `mock/crates/vehje-runtime-abi/src/value.rs`
Add `#[repr(C)]` to `ValueList`, `BlobSpan`, `ValueNode`, `Region`, and to `ValueTag` (a stable C-ABI
discriminant). These are the records the runtime reads zero-copy; the default Rust representation gives no
stable layout. `ValueTag` uses `#[repr(C)]` rather than `#[repr(u8)]`: the compact fixed width is part of
the flagged-open wire-spec decision, and `#[repr(u8)]` also trips the no-bare-numeric lint on the `u8`
token, so the C-ABI-default discriminant is the lint-clean, honestly-deferred choice for now. `ValueRef`/`RegionId` keep their existing `#[repr(transparent)]`;
`ValueArena` (the in-process slice view, not a crossed wire type) is unchanged.
Verification: `grep -n "repr(C)\|repr(u8)" mock/crates/vehje-runtime-abi/src/value.rs` shows five new attrs
on those types; `cargo test -p vehje-runtime-abi` still passes (field access is by name, layout-independent).

## CHANGE: `ValueArena::children` clamped to the live pool in `vehje-runtime-abi`
File: `mock/crates/vehje-runtime-abi/src/value.rs`
The child slice used `pool[start .. start + len]` with no bound (the same overflow-and-OOB shape the round
`202607240400` review fixed in `Arena::list`). Clamp with a saturating add to the live pool length, so a
malformed `ValueList` yields a truncated or empty slice rather than an overflow panic or an out-of-bounds
read.
Verification: `grep -n "saturating_add" mock/crates/vehje-runtime-abi/src/value.rs` returns one match in `children`.

## CHANGE: add `ValueArena::try_get` and state `get`'s precondition in `vehje-runtime-abi`
File: `mock/crates/vehje-runtime-abi/src/value.rs`
`try_get(&self, at: ValueRef) -> Maybe<ValueNode>` bounds-checks the node index for the untrusted path.
`get` stays the trusted-path accessor, with its precondition (valid only after validation, or on a trusted
in-process arena) stated in the doc comment. The full validation pass and the unvalidated-arena typestate
stay FIXME'd (the out-of-process residual story is not yet built), tracked.
Verification: `grep -n "pub fn try_get" mock/crates/vehje-runtime-abi/src/value.rs` returns one match; a new
unit test asserts `try_get` on an out-of-range `ValueRef` returns `Isnt`.
