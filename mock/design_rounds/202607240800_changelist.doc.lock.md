# Doc changelist: implementation-to-match-design

Doc-template edits for round `202607240700`/`202607240730`. The docs already model the full design; this
changelist is light. It documents the one new public type the implementation adds (`vehje-lower`'s `Rewrite`
remap side-table), records the bounds-checked `GradeTable` accessor return, and clears the two standing
doc-wording debts (the `hash_of` "stable across arenas" narrowing and the `ValueTag` discriminant wording). The
mechanisms the implementation realizes (the reachability binder rule, const-fold, CSE, the typed decode) are
already described in their DESIGN templates; the source catches up to the docs, so the docs need no new prose
for them beyond what follows.

## vehje-lower/DESIGN.md.tmpl

- Document `Rewrite`: the caller-lent remap side-table (`NodeRef` to `NodeRef`) that the cheap stratum's
  redirecting rewrites populate, so const-fold and CSE rewrite by producing a remap rather than mutating the
  arena. `Rewrite::resolve` follows the remap to a node's current representative; the lowered root is the
  root's resolved form. No allocation: the region is caller-provided, like `Resolution` and `GradeTable`.
- State that `ConstFold` folds an `If` whose condition is a literal boolean to its taken branch (the
  Core-level constant fold that needs no family operation), recording the redirect in the `Rewrite`. Folding a
  primitive operation over literal operands waits on the family payload encoding (deferred), so the Core fold
  is the `If`/condition fold today.
- State that `Cse` shares structurally equal subtrees by hash-consing over the one structural hash, recording
  each duplicate's redirect to its first occurrence in the `Rewrite`. The benefit is node-count reduction.
- State that `Anf` stays deferred: A-normal-form hoisting creates new `Let` bindings, which needs the
  mutable-arena rewrite the redirecting passes avoid; it lands with that arena-rewrite path.

## vehje-ir/DESIGN.md.tmpl

- State that `GradeTable`'s `get`/`set` are bounds-checked against the region, returning/consuming a
  `Maybe`-guarded access rather than panicking on an index past an undersized region.
- Narrow the structural-hash claim: replace "the hash is stable across arenas, so a cache hit across artifacts
  is sound" with the accurate scope. `hash_of` folds a name's interner handle, which is stable within one
  interner, so the hash is sound for within-compilation hash-consing; cross-interner or cross-artifact identity
  is served by the byte-image hash (`vehje-fixpoint`'s `xxhash3_64`), not this word-fold.

## vehje-runtime-abi/DESIGN.md.tmpl or DEEPDIVE_VALUE_TRANSPORT.md.tmpl

- Narrow the `ValueTag` wording: it carries an explicit stable `#[repr(C)]` discriminant (the C-ABI default
  width); narrowing to a compact fixed width is part of the open wire-spec decision, so the doc says "a stable
  declared discriminant" rather than implying a specific small width.

## vehje-runtime-driver/DESIGN.md.tmpl

- State that `Reader::validate` runs the real typed structural decode over the value arena (the monotone
  child-index bounds check the children-first order makes linear), so the untrusted path is validated before
  the host reads, rather than a no-op.
