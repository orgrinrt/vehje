# Topic: flip Core binder positions to Sym, declare the binder domain

**Date:** 2026-07-24
**Phase:** TOPIC
**Scope:** vehje-ir. Flip the three binder positions in the Core node algebra (`Var`, `Let.name`, `Lambda.param`) from `Str` to the generic identity handle `Sym` from the new `hilavitkutin-sym` crate, and declare vehje's minted-binder generative domain. Update the builder and every consumer that constructs or matches those positions. The `Anf` and `MacroExpand` passes stay no-ops in this round; this is the type-level foundation the node-creating catamorphism (a following round) stands on. Everything keeps compiling.

The canon's frontier item B (the one handler discipline) and its generative-freshness property need fresh binder identities that a compiler pass can mint at the earliest binding time, and whose capture-safety is structural rather than hoped for. The upstream round factored that need into `hilavitkutin-sym`: a `Sym` is a 4-byte integer-equality handle tagged by a 3-bit domain `kind`, with two producer shapes (an `Interner` that deduplicates a value, a `Generator` that mints a fresh handle). String interning is one domain; a minted binder is another. Two handles of different kind are never equal, so a minted binder provably never captures a source name, by construction of the identity core rather than by a convention in the resolver.

This round consumes that core on vehje's side. A source binder name arriving from the lexer or the interner is a `Str`, which is now a `#[repr(transparent)]` view over a string-kind `Sym`, so it widens to `Sym` at zero cost. A minted binder is a `Sym` straight from a `Generator<BinderDomain>`. Both live in the same Core field, one `Sym` type, which is exactly what the ANF fold needs: it copies a source binder or requests a fresh one, and compares binders only by integer equality, never by text.

## Current state

The Core `Node` enum (`vehje-ir/src/node.rs`) holds `Str` at five positions: `Var(Str)` (a variable reference), `Let { name: Str, .. }` (a let binder), `Lambda { param: Str, .. }` (a lambda binder), `Literal::Str(Str)` (a string literal value), and `Project { key: Str, .. }` (a record field label). The builder (`vehje-ir/src/builder.rs`) exposes `var`/`let_`/`lambda`/`project` taking `Str` at those positions. Eight crates construct or match these fields: vehje-ir (node, builder, hash), vehje-lower, vehje-resolve, vehje-typecheck, vehje-codegen, vehje-runtime-abi (encode), and vehje. vehje-ir depends on `hilavitkutin-str` but not yet on `hilavitkutin-sym`.

## Changes proposed

Add the `hilavitkutin-sym` dependency (git, hilavitkutin `dev`, where the crate now lives) to the vehje workspace and to vehje-ir. In `node.rs`, flip the three binder positions to `Sym`: `Var(Sym)`, `Let.name: Sym`, `Lambda.param: Sym`. Keep `Literal::Str(Str)` and `Project.key: Str` as `Str`, because they are genuine string concerns (a string literal value, and a field label resolved structurally against a record), not alpha-renamable binders. Declare `BinderDomain`, a `GenerativeDomain` marker with `KIND = SymKind::from_raw(0b001)` (the value the sym-core kind table reserves for vehje's minted binder), and export it from vehje-ir so vehje-lower can hold a `Generator<BinderDomain>` in the following round.

In `builder.rs`, the `var`/`let_`/`lambda` constructors take `Sym` at their binder parameters; `project` keeps `Str`. Source-name call sites widen their `Str` via `Str::as_sym()`. Update every consumer that constructs or matches `Var`/`Let.name`/`Lambda.param`: vehje-lower's `structurally_equal` compares binders by `==` (integer equality, unchanged operation, now on `Sym`); vehje-resolve, vehje-typecheck, vehje-codegen, vehje-runtime-abi/encode, and vehje adjust their construction and matching. The structural hash (`vehje-ir/src/hash.rs`) folds the binder positions; folding a `Sym` is the same 32-bit fold as a `Str`. Keep the whole workspace compiling; the `Anf`/`MacroExpand` no-ops are untouched.

Strict fail-first tests: a minted `BinderDomain` `Sym` is never equal to a source-name `Sym` (disjointness by domain kind, the capture-safety boundary); the builder accepts both a widened source `Str` and a minted `Sym` at a binder position; the structural hash of a node is unchanged for a source-name binder (byte-compatibility of the widening).

## Not in this round

The `Anf` node-creating catamorphism itself (the fold that hoists non-trivial subexpressions into `Let` bindings whose names come from a `Generator<BinderDomain>`) is the next round. This round only makes the binder positions hold the generic identity type and gives vehje its minted-binder domain, so the fold has a type to mint into.
