## vehje-lower

### CHANGE: `Anf::apply` FROM no-op TO node-creating catamorphism
File: `mock/crates/vehje-lower/src/lib.rs`
`apply(&self, builder: &mut Builder<'_>, root: NodeRef, rw: &Rewrite<'_>, gen: &mut Generator<BinderDomain>) -> Maybe<NodeRef>`. Flat A-normal form via three internal fns: `normalize_term` (fresh bind-scratch, flatten, reverse-wrap the Lets, return root), `flatten` (append operand hoist-bindings, return the tail; flatten let-chains; branch/lambda/iter/match-arm/handle-clause bodies each get a fresh `normalize_term`), `atomize` (return an atom; mint a fresh `BinderDomain` Sym and record the binding for a non-atomic operand). Fixed-cap stack scratch (`BIND_CAP`, `ARG_CAP`); `Isnt` on arena-full or generator-exhaustion or scratch overflow.
Verification: `grep -q 'gen: &mut Generator<BinderDomain>' mock/crates/vehje-lower/src/lib.rs && cargo test -p vehje-lower`.
