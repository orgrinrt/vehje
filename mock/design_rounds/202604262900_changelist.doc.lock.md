## Purpose

Ship a skeleton lexer for the Clause language. Covers the full
token enum + trivia + byte cursor surface; implements the
tokenisation drive loop for the straightforward subset
(keywords, ASCII operators, decimal integers, line/block
comments, whitespace). Defers the more finicky parts (string
literals, char literals, float literals, unicode escapes, raw
strings, numeric suffixes) to follow-up rounds so this round
stays small and shippable.

Concurrently, populates `clause-ir` with the shared types each
phase consumes: Span / FileId / ByteOffset / NodeId / ScopeId /
Diagnostic / Severity / TokenKind / AstNodeKind. Without these,
clause-lex can't depend on clause-ir meaningfully.

## Deliverables this round

### clause-ir

- `Span { file: FileId, start: ByteOffset, end: ByteOffset }`.
- `FileId(u32)`, `ByteOffset(u32)` transparent newtypes.
- `NodeId(u32)`, `ScopeId(u32)` transparent newtypes.
- `Diagnostic { severity: Severity, span: Span, message: &'static
  str, related: &'static [Span] }`.
- `Severity { Error, Warning, Info, Help }`.
- `TokenKind` — complete enum per grammar seed.
- `AstNodeKind` — complete enum (stub shape now; refined per
  phase).
- Tests: size / layout + TokenKind completeness assertions.

### clause-lex

- `Token { kind: TokenKind, span: Span, trivia: TriviaSet }`.
- `TriviaSet` — leading/trailing whitespace + comments attached
  to each token.
- `Cursor` — byte-level source walker with UTF-8-safe peek.
- `Lexer` — stateful tokeniser driving Cursor.
- `TokenStream` — forward-only iterator from Lexer output.
- Lex diagnostics via clause-ir::Diagnostic.
- Drive-loop tokenisers for:
  - ASCII keywords (`fn`, `let`, `mut`, `const`, `struct`, `pub`,
    `if`, `else`, `match`, `for`, `while`, `return`, `use`,
    `mod`, `impl`, `trait`, `type`, `enum`, `macro`, `expect`,
    `actual`, and the full keyword list from the grammar seed).
  - ASCII identifiers (non-keyword `[A-Za-z_][A-Za-z0-9_]*`).
  - Decimal integer literals (no suffix this round).
  - ASCII punctuation / operators (all the grammar seed lists).
  - `//` line comments + `/* ... */` block comments
    (non-nested this round — nested blocks BACKLOG).
  - Whitespace runs.
- Tests covering each tokeniser.

### clause-lex deferred to follow-up rounds (BACKLOG)

- String literals (`"..."`, escape sequences).
- Char literals (`'x'`, escape sequences).
- Float literals (`1.5`, `1e10`, etc.).
- Numeric suffixes (`123u64`, `1.5f32`, etc.).
- Unicode escape sequences (`\u{...}`).
- Raw string literals (`r"..."`, `r#"..."#`).
- Byte literals (`b'x'`, `b"..."`).
- Doc comments (`///`, `//!`, `/** */`).
- Nested block comments.
- Shebang (`#!`).
- BOM handling.
