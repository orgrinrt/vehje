# Src Changelist: vehje skeleton debt sweep

**Date:** 2026-04-24
**Phase:** SRC
**Parent doc CL:** `202604300000_changelist.doc.lock.md`

## Comparison to deprecated changelist

Previous src CL `202604300100_changelist.src.md` was deprecated when
the round unlocked to fold the D5 rename cleanup (residual `clause`
and `Clause` prose references) into the doc CL. This src CL is
identical in scope to the deprecated one, plus the source-side half
of D5: apply the same word-boundary rename to every `.rs` file
outside `design_rounds/`.

## Purpose

Execute the source-level sweep that brings every skeleton crate into
compliance with the shipping doc templates. Wrap bare primitives in
arvo types, reframe compiler-phase crate module docs to state the
`no_std`-first discipline, add `#![no_std]` to every crate root that
currently lacks it, and apply the two-tier FFI-wire primitive policy
to `clause-runtime-abi`.

Round closes with restoration of the four temp-lowered lint
severities (`arvo-types-only`, `no-bare-numeric`, `no-bare-string`,
`no-public-raw-field`) from `warn` to `error` at commit+push (task
#218). Those severity changes are user-applied via the classifier;
the src CL landing is the trigger.

## Scope of source changes

Per crate, per concern. Each bullet below enumerates the expected
source edits without prescribing a per-commit split. Commits land as
logical units (usually one or two crates per commit).

### `clause` (top-level bin)

- Add `#![no_std]` at `src/main.rs` (or equivalent) top. Pair with
  `extern crate alloc` only if a `std`-feature gate is added;
  skeleton stays `no_std` + `no_alloc`.
- Replace `String` in `args.rs`, `build.rs`, `check.rs`, `lex.rs`,
  `parse.rs`, `run.rs`, and the two `main.rs` sites with
  `hilavitkutin_str::Str` or `&'static str`.

### `clause-ir`

- Wrap bare numerics flagged at `no-bare-numeric` sites. Tuple-struct
  newtypes (`FileId`, `ByteOffset`, `NodeId`, `ScopeId`, etc.) that
  currently hold `u32` or `usize` flip to hold `USize` or a domain-
  appropriate arvo type.
- Ensure all `pub struct` fields named in `no-public-raw-field`
  violations carry arvo types.

### `clause-lex`

- Largest debt (~100 violations). Per-file sweep across
  `diag.rs`, `keyword.rs`, `lex.rs`, `lexer.rs`, and the remaining
  modules. Target shapes: `USize` for byte offsets / lengths,
  `&'static str` for keyword tables, `Str` for dynamic strings,
  `Bool` for flags.

### `clause-syntax`

- ~55 violations. Token-adjacent numerics flip to arvo newtypes;
  parser state numerics flip to `USize`; any bare `&str` in AST
  node payloads flips to `Str`.

### `clause-resolve`

- Module doc `//!` at `src/lib.rs` replaced with the no_std-first
  framing (per D2 of the doc CL).
- `#![no_std]` at crate root.
- Remaining 3 violations wrapped.

### `clause-typecheck`

- Same pattern: `#![no_std]` at root, module doc updated if it
  carried the "host-side, std is fine" framing, 3 violations
  wrapped.

### `clause-schedule`

- Currently empty (`no-empty-crate` fires). Populate with the
  skeleton WorkUnit-home surface (minimum: one `PlanStage` re-
  export from hilavitkutin-api and a `vehje_schedule` mod).
- `#![no_std]` at root.
- 3 additional violations wrapped.

### `clause-codegen`

- `#![no_std]` at root.
- 4 violations: `artifact.rs` bare `u8` wraps; three `&str` sites
  in `registry.rs` flip to `&'static str` or `Str`.

### `clause-runtime-abi`

- Apply two-tier FFI policy per the DESIGN.md.tmpl subsection added
  in the doc CL:
  - `USize` where a wire `usize` is needed (struct fields: `name_len`
    etc. if any, `capabilities_len` if any).
  - `u64`-wide types wrap to arvo newtype analogous to
    `CapabilityId` where a semantic name exists.
  - Bare `i32` / `u32` at `extern "C"` fn signatures and `#[repr(i32)]`
    enum discriminants stay bare with
    `// lint:allow(arvo-types-only) tracked: #207`
    annotations (single-token form).

### `clause-runtime-driver`

- `#![no_std]` at root.
- 7 violations wrapped; driver runs compiler-host-side so `Str`
  applies for filesystem-passed path strings once a real dylib-load
  surface exists (current skeleton uses minimal bare primitives that
  wrap cleanly).

### `clause-runtime-tests`

- 3 violations wrapped.

## Per-crate doc-comment sweep

Every crate's `src/lib.rs` `//!` module comment is audited for the
"host-side, std is fine" framing. Where present, it is replaced with
the no_std-first framing per the doc CL (D2).

## Round-close trigger for #218

The SRC CL's final commit is the trigger for the lint severity
restore in `mock/mockspace.toml`:

- `arvo-types-only`: commit+push `warn` → `error`
