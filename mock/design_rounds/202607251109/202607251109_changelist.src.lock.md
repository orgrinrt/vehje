# Source changelist: the value image writer and reader

**Round:** 202607251109
**Phase:** IMPL
**Scope:** `vehje-runtime-abi` only. Add the pinned value-image byte layout, the writer that serialises a `ValueArena` into it, and the bounds-checked reader over an untrusted image. Correct two stale `ValueTag` doc comments. No other crate changes; the Zig writer and the driver embedding are their own rounds.

The layout follows the locked doc CL: a seven-word little-endian header (magic, version, node count, pool count, region count, blob length, root), then fixed six-word value-node records, then the flat child-index pool, then the region table, then the byte blob.

A record's six words are `tag`, `region`, `children.start`, `children.len`, `blob.offset`, `blob.len`, which is exactly `ValueNode`'s logical shape, so a decode is a direct field read with no reinterpretation. Scalars span the blob (a boolean is one byte, an integer eight little-endian bytes) because `ValueNode` carries a `BlobSpan` and no inline payload. Whether a scalar should instead sit inline in the record, as the residual's operands do, is a measured decision and not a guess: it is recorded in BACKLOG against the record-width question rather than settled here.

## CHANGE: fn `write_value` CREATE
File: `mock/crates/vehje-runtime-abi/src/value_image.rs`
`pub fn write_value(arena: &ValueArena<'_>, out: &mut [u8]) -> Maybe<USize>`. Serialises the arena into `out` in the pinned layout, returning the bytes written, or `Isnt` when `out` cannot hold the whole image. Writes the header, then every node record, then the pool, then the region table, then the blob. It never writes a partial image: the size is computed first and the buffer checked before any byte is written.
Verification: `grep -q 'pub fn write_value' mock/crates/vehje-runtime-abi/src/value_image.rs`.

## CHANGE: struct `ValueImage` CREATE
File: `mock/crates/vehje-runtime-abi/src/value_image.rs`
`pub struct ValueImage<'img>` wrapping untrusted bytes, with `parse` validating the header (magic, version, and that every declared section fits inside the byte slice) and returning `Maybe<Self>`. Accessors: `root`, `node_count`, `try_node` (bounds-checked record read), `child` (bounds-checked pool read), `blob` (bounds-checked span read), and the scalar readers `as_bool` and `as_int` which check the span width before decoding. Every accessor returns `Maybe`, so a malformed image is a refusal and never a read past the end or a panic.
Verification: `grep -q 'pub struct ValueImage' mock/crates/vehje-runtime-abi/src/value_image.rs`.

## CHANGE: fn `ValueImage::validate` CREATE
File: `mock/crates/vehje-runtime-abi/src/value_image.rs`
The linear structural check over an untrusted image: for every node, its child span lies inside the pool, its blob span inside the blob, its region inside the region table, and every child index is strictly below the node's own index. That last check is the whole acyclicity argument, because the writer emits children before parents, so a single monotone comparison rules out cycles without a search. Returns `Bool`.
Verification: `grep -q 'fn validate' mock/crates/vehje-runtime-abi/src/value_image.rs`.

## Tests (fail-first, strict)

File: `mock/crates/vehje-runtime-abi/src/value_image.rs` (module tests)

- A value round-trips: build an arena holding a record whose children are a unit, a boolean, and an integer, write it, parse it, and read every leaf back with the same tag and the same scalar value. This is the contract the Zig writer will be held to.
- The writer refuses a buffer one byte too small, returning `Isnt` and leaving the caller nothing to misread.
- A wrong magic is refused by `parse`.
- A truncated image (a header declaring more nodes than the bytes hold) is refused by `parse`.
- A child index pointing at or above its parent is refused by `validate`, which is the cycle that the children-before-parents ordering forbids.
- A blob span reaching past the blob is refused by `blob`, and an integer whose span is not eight bytes is refused by `as_int`.

Verification: `cargo test -p vehje-runtime-abi` passes with these cases present.
