## CHANGE: wire emit() callers to pass byte + diagnostic sinks

Files: `mock/crates/vehje-codegen/tests/{target_trait,end_to_end,registry}.rs`

Each test file gains an inline `ByteCounter` (impls `Push<u8> + BulkPush<u8>`, satisfying `ByteEmitter` via blanket impl) and `DiagCounter` (impls `Push<Diagnostic> + Len`, satisfying `DiagnosticSink<Diagnostic>` via blanket impl). Both are counter-only structs: they discard the pushed value and tally a `usize` count. Tests assert `count == 0` after the skeleton-target `emit()` returns, preserving the original "skeleton emits nothing" intent.
