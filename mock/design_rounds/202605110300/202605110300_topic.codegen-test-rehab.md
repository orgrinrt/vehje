# Topic: rehab vehje-codegen tests past Round-5d emit() reshape

## Scope

Test-side mechanical migration of the four `vehje-codegen` test files.
The codegen API changed shape during a prior round (the Round-5d
codegen redesign): `CodegenTarget::emit` and `TargetRegistry::emit_for`
gained two extra arguments (caller-provided `&mut dyn ByteEmitter` and
`&mut dyn DiagnosticSink<Diagnostic>`), and `CodegenArtifact` lost its
`bytes` and `diagnostics` fields (those flows now go through the
sinks). The tests still used the older 1-arg or 2-arg call sites and
asserted on the lost artifact fields.

This round is the test-side adoption of that redesign. Library source
already reflects the post-Round-5d shape.

## Files in scope

Test files only. Plus one `Cargo.toml` dev-dep addition.

- `crates/vehje-codegen/tests/artifact_types.rs` — drop assertions on
  the lost `bytes` / `diagnostics` fields, keep the `kind` check.
- `crates/vehje-codegen/tests/target_trait.rs` — wire `emit(&ctx,
  &mut bytes, &mut diags)` plus inline `ByteCounter` + `DiagCounter`
  test sinks, assert sinks stay empty for skeleton targets.
- `crates/vehje-codegen/tests/end_to_end.rs` — same pattern for the
  top-level `emit(resolved, name, bytes, diags)` driver fn.
- `crates/vehje-codegen/tests/registry.rs` — `lookup` returns `Maybe`
  (not `Option`); `is_none()` → `isnt()`. `emit_for` takes the same
  4 args; same sink wiring.
- `crates/vehje-codegen/Cargo.toml` — add `arvo` as
  `[dev-dependencies]` for `arvo::USize` at test time only.

## Decisions

1. **Two inline test sinks per file: `ByteCounter` + `DiagCounter`.**
   Both implement the trait pair the source-side bound requires
   (`Push<u8> + BulkPush<u8>` for `ByteEmitter`; `Push<Diagnostic> +
   Len` for `DiagnosticSink<Diagnostic>`). Both stay counter-only,
   discarding the pushed value. Tests assert `count == 0` after the
   skeleton-target `emit()` returns, which preserves the original
   "the artifact is empty" intent.

2. **`assert!(target.lookup("bogus").is_none())` → `.isnt()`.** Notko
   `Maybe`'s predicate name is `is()` / `isnt()`; the older `is_none()`
   was an `Option` carry-over. Mechanical fix.

3. **No deeper `bytes`/`diagnostics` field tests.** The original
   `assert!(artifact.bytes.is_empty())` / `assert!(artifact.diagnostics.is_empty())`
   were verifying the old artifact-carries-payload shape. The new
   shape has caller-owned sinks, so the equivalent assertion is
   `assert_eq!(my_byte_sink.count, 0)`. The migration moves that
   assertion to where the data lives now.
