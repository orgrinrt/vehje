# Prior-art synthesis: index

**Date:** 2026-07-20
**What this is:** a categorised synthesis of two prior-art corpora into standalone required-reading domain
docs. Each doc below pulls the load-bearing mechanisms, exact API shapes, measured numbers, and stated
tradeoffs from the sources it names, so a future round can read one domain doc instead of re-reading the raw
corpus. Sources overlap across docs by design; the same prior art usually serves several domains.

**Synthesised from:**

- `202607190650_mockspace-procedural-docs-arc/prior_art/` (8 docs): LMS/Delite (`01`), Jsonnet/Dhall (`02`),
  Pandoc/Djot (`03`), Racket/Scribble (`04`), Typst (`05`), MLIR-ODS/nanopass (`06`), Rust
  final-encoding+arenas (`07`), Terra/proc-macro/comptime (`08`).
- `202607201227_runtime-value-transfer-study/` (5 runtime docs, synthesis excluded): .NET CLR
  (`dotnet_clr`), Lua/LuaJIT (`lua_luajit`), V8/Deno (`v8_deno`), WebAssembly Canonical ABI
  (`wasm_canonical_abi`), zero-copy formats (`zerocopy_formats`).

The original docs remain the primary citations; each synthesis doc points back to them plus the underlying
papers and repos.

## The five domains

1. **`202607201618_synth_staged-metaprogramming-and-codegen.md`** — generating an interpreter, a backend, or
   a whole runtime from a definition. Multi-stage programming, typed generation, what crosses the generation
   boundary, when unrepresentable-value failures surface, and making illegal states unrepresentable in the
   generated output. Sources: `01`, `06`, `07`, `08`, `02`.

2. **`202607201618_synth_output-spectrum-interpret-transpile-multitarget.md`** — one term or tree, many
   outputs. Tagless-final and polymorphic embedding, the interpret-to-transpile spectrum, writer and renderer
   contracts, coverage versus inclusion, trait/interface dispatch over an open operation set, per-target cost.
   Sources: `07`, `04`, `03`, `02`, `06`, `05`, `01`.

3. **`202607201618_synth_ir-representation-and-no-alloc-arenas.md`** — what the IR actually is and how it is
   held with no heap. Core-form vocabularies, per-node extensibility, flat-array-plus-index versus
   child-list-by-handle versus red/green, interning, `EntityList`/`ListPool`, `heapless`/`bump-into`,
   hash-consing/CSE, the confirmed no-alloc toolkit. Sources: `07`, `06`, `05`, `01`, `03`, `04`, `02`,
   `zerocopy_formats`, `wasm_canonical_abi`.

4. **`202607201618_synth_embeddable-runtime-value-model-and-host-boundary.md`** — how a produced value lives
   and crosses to an embedding host. Moving-GC handle tables versus never-moving arenas, marshalling and
   blittability, streaming with backpressure, ownership and lease contracts, zero-copy flat buffers, the
   scalar/bulk/graph channel split. Sources: `dotnet_clr`, `lua_luajit`, `v8_deno`, `wasm_canonical_abi`,
   `zerocopy_formats`, `05`, `08`.

5. **`202607201618_synth_purity-totality-effects-and-the-compile-runtime-split.md`** — what reduces when, and
   what guarantees a language can carry. Totality and termination as type properties, content-addressed
   determinism, laziness and thunks, effect classification as read/write edges, binding-time and the
   compile/runtime split, lifetime and lease contracts. Sources: `02`, `01`, `08`, `04`, `dotnet_clr`.

## Cross-cutting threads that recur in every domain

- **Make illegal states unrepresentable, and push the check into generated structure.** Recurs in staged
  generation (`01`/`08`), in exhaustive writers that fail to compile on an unhandled case (`03`/`04`), and in
  typed generation certified once (`07`/`08`).
- **Everything the corpus surveys is heap-and-GC-shaped; the no-alloc port is the standing tax.** Every prior
  art has a "what would not transfer to no_std, no-alloc Rust" section; those sections, read together, are the
  real constraint map, and they converge on a small confirmed toolkit (`07` §9).
- **A handle is an index, never a pointer, whenever memory can move or must be shared.** Recurs in arenas
  (`07`), in the moving-GC runtimes (`dotnet_clr`/`v8_deno`/`lua_luajit`), and in zero-copy formats
  (`zerocopy_formats`).
- **One truth, many projections, kept consistent by a generator or a total traversal.** The tagless-final
  interface (`07`), the nanopass grammar-driven default clause (`06`), the ODS record (`06`), and the typed
  metaprogram (`08`) are all this pattern.
