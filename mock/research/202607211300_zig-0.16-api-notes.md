# Zig 0.16.0 std/builtin API notes (from the overnight run)

Consolidated API changes hit while building the overnight sketches/benches on the pinned Zig 0.16.0, so the
implementation work does not re-discover them. These are 0.16-specific; several design docs and older code assume
pre-0.16 shapes.

## Builtins

- **`@Type` is REMOVED.** Reification from `std.builtin.Type` is now a family of specialised builtins:
  `@Enum`, `@Union`, `@Struct`, `@Int`, `@Fn`, `@Pointer`, `@Frame`, `@Tuple`, `@Vector`, `@EnumLiteral`. This is
  load-bearing for certified generation (SK1). Observed signatures from std:
  - `@Enum(tag_type, mode, names, values)` where `mode` is `.exhaustive`/`.nonexhaustive`, `names` is
    `[]const [:0]const u8`, `values` is `[]const tag_type` (slices work). `EnumField.name` is `[:0]const u8`.
  - `@Union(layout, tag_type, field_names, field_types, field_attrs)`.
  - `@Struct(layout, backing, field_names, field_types, field_attrs)`.
  - Design docs referencing "`@Type`" (1627/1845) are stale; update to the `@Enum`/`@Union`/`@Struct` family.
- `@typeInfo`, `@TypeOf`, `@FieldType`, `@typeName` remain. `@typeInfo(T).@"enum"` / `.@"union"` (snake-case,
  quoted) for the info fields.

## std reorganisation (many modules moved)

- **`std.time.Timer` and `std.time.Instant` are GONE.** Only the `ns_per_*` constants remain in `std.time`.
  Timing moved to the `std.Io` interface (`Io.now(clock)`), which needs an Io instance. For a simple monotonic
  clock, use the libc binding: `std.c.clock_gettime(std.c.CLOCK.MONOTONIC, &ts)` with `-lc`, `ts: std.c.timespec`
  (fields `.sec` / `.nsec`). This is what every overnight bench used for timing.
- **`std.posix.clock_gettime` is GONE** (posix layer reorganised). Use `std.c.clock_gettime` (link libc).
- **`std.io.fixedBufferStream` is GONE** (`std.io` reorganised). For building strings, use a manual cursor with
  `std.fmt.bufPrint(buf[n..], fmt, args)` and advance `n`, or `std.ArrayListUnmanaged(u8)`.
- **`std.fs.cwd()` is GONE / changed** (fs reorganised; likely needs an Io/Dir handle now). The overnight
  sketches avoided Zig file I/O and printed to stderr, capturing/writing files from the shell instead.
- **`std.os.argv` is GONE.** Use `std.process` for args, or avoid CLI args (loop internally).

## Container / init changes

- **`std.ArrayListUnmanaged(T){}` empty-init is REMOVED.** Use `std.ArrayListUnmanaged(T).empty` (or
  `.{ .items = &.{}, .capacity = 0 }`). Managed `ArrayList` similarly; append takes the allocator:
  `list.append(al, x)`.

## Syntax / strictness

- **`catch` requires whitespace on both sides.** `x() catch y`, NOT `x()catch y` (0.16 is strict here). Same
  general strictness bit consumers of compressed code hit.
- Comments are `//` only; no `/* */` C-style comments.
- `@intCast` in an arithmetic context needs a known result type: `@as(u64, @intCast(i)) + k`, not
  `@intCast(i) + k`.
- Shift LHS must be a fixed-width int: `@as(u64, 1) << shift`, not `1 << shift`, when the result feeds a runtime
  fixed-width slot.

## Calling conventions (SK3)

- **No `preserve_none` / `ghccc` convention** in 0.16's 102-entry `std.builtin.CallingConvention` (union). Use
  `callconv(.c)` + `@call(.always_tail)` + explicit-argument passing to keep state in argument registers. See SK3.

## What still works as expected

- `@call(.always_tail, fn, args)` (guaranteed TCO; compile error if not guaranteeable).
- `@Vector(N, T)` + `@reduce(.Or, ...)` for SIMD (BN4).
- `@setEvalBranchQuota` for comptime (but it does NOT rescue deep comptime recursion, which SIGSEGVs the
  compiler, SK5, use an explicit work-stack).
- `export fn ... callconv(.c)` + `zig build-lib` + link into C/Rust hosts (SK25, dual-locus).
- macOS JIT: `mmap(MAP_JIT)`, `pthread_jit_write_protect_np`, `sys_icache_invalidate` all work via `zig cc` from C
  (copy-and-patch probe).

## Recommendation
Pin these in the implementation crates' notes. Where a design doc names a pre-0.16 API (`@Type`, `std.time.Timer`),
update it to the 0.16 shape. The `@Type` -> `@Enum`/`@Union`/`@Struct` change is the one that touches the
certified-generation design directly.
