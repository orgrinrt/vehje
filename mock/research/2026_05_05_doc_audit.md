# Vehje per-crate documentation audit, 2026-05-05

**Date:** 2026-05-05.
**Scope:** `mock/crates/*/{README,DESIGN,BACKLOG,SHAME}.md.tmpl` across 11 crates plus `mock/runtime-zig/{README,DESIGN}.md.tmpl`. No DEEPDIVE_*.md.tmpl files exist in the tree.
**Method:** Manual read pass against `documentation-writing.md` (surface taxonomy + Tier-1 leakage), `writing-style.md` (em-dash, marketing words, label-form bullets, ASCII diagrams), `vocabulary.md` (banned + watch-list words), and `ai-agent-framing.md` (AI tool naming).

## Summary

The dominant finding is Tier-1 leakage of mockspace machinery. Every single `DESIGN.md.tmpl` ends with a `## Sources` section that lists timestamped changelist filenames (`202604191500_changelist.doc.md`, `202604264100_changelist.doc.md` etc.). Multiple `SHAME.md.tmpl` files refer to "mockspace task" / "mockspace lint" by name. Both `runtime-zig` templates name "Mockspace" as the build orchestrator. Per `documentation-writing.md` Tier-1 rules these surfaces forbid mockspace vocabulary, `.tmpl` references, `cargo mock` commands, and changelist filenames; the rendered output of these templates becomes the public per-crate `docs/<crate>/` view.

A second cross-cutting pattern is the `- **Bold label**. description` and `- \`Type\`. description` bullet form, which is banned by `writing-style.md`'s "label-plus-colon" rule — the colon-replacement-with-period reads as the same cheat-sheet shape with the same TLDR-flavour. Pervasive across DESIGN and BACKLOG templates.

Em-dashes are clean (zero hits, hard ban observed). Banned vocabulary from `vocabulary.md` (substrate, HList, holistic, paradigm, leverage, utilize, seamless, robust, scalable, powerful, blazing, amazing, incredible, elegant, principled) is clean. Marketing tone is generally absent. Stale `clause` references (the language was renamed to vehje) are clean inside templates; the only `Clausewitz` mentions are legitimate domain references to Paradox engine output, which the audit instructions explicitly carve out. The single concerning sibling-repo leak is two `stellar-heritage` mentions in `vehje/BACKLOG.md.tmpl` and `vehje-codegen/BACKLOG.md.tmpl`. AI tool names (Claude Code / Copilot / Codex / Cursor) appear zero times outside legitimate uses (`cursor` as parser-cursor concept in `vehje-syntax`, `vehje-lex`, `vehje-resolve`).

Stale type/trait references are minor: `vehje-schedule/DESIGN.md.tmpl` claims `PassDag`, `PassRegistry`, `Scheduler`, `Artifact` as in-scope types, but `src/lib.rs` only exports `CompilerSchedule` + `ScheduleError`. The crate's `SHAME.md.tmpl` acknowledges this gap, so this is a doc-vs-source claim mismatch that the existing skeleton-status framing partly mitigates but does not resolve at the Tier-1 surface.

Total finding count: ~75 distinct line-level findings across 11 crates plus runtime-zig. Severity skew: 1 cross-cutting Tier-1 leakage class (every DESIGN template), 1 cross-cutting bullet-form class (most DESIGN/BACKLOG templates), then a long tail of minor item-level findings.

## Cross-cutting patterns

### CC1: `## Sources` section in every DESIGN.md.tmpl is Tier-1 leakage

Every DESIGN.md.tmpl audited (vehje, vehje-codegen, vehje-ir, vehje-lex, vehje-resolve, vehje-runtime-abi, vehje-runtime-driver, vehje-runtime-tests, vehje-schedule, vehje-syntax, vehje-typecheck, runtime-zig) ends with a `## Sources` section listing changelist filenames (`202604191500_changelist.doc.md`, `202604262500/202604262500_changelist.doc.lock.md`, etc.) and topic-seed filenames (`202604191300_topic.vehje-design-seed.md`). These names mean nothing to a stranger landing on `docs/<crate>/`; they are pure mockspace-machinery cross-references. Per `documentation-writing.md` Tier-3 guidance, this section either (a) gets stripped from the rendered Tier-1 output by the doc-generation pipeline, or (b) gets moved to a sibling Tier-2 file (`mock/research/<crate>-history.md`). Verify the strip works; if not, move.

### CC2: `## Round-skeleton scope` / `Phase N skeleton round` Tier-1 leakage

Every Phase 6 / R1 / R2 / R3 / R4 reference in body prose is workspace-internal vocabulary that means nothing to a Tier-1 reader. Affected files: vehje-codegen, vehje-runtime-abi, vehje-runtime-driver, vehje-runtime-tests, vehje-schedule, vehje-syntax, vehje-typecheck, runtime-zig.
