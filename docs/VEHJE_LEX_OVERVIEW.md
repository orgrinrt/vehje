# vehje-lex. Design

Tokenisation phase. Consumes source text, produces a token stream
with trivia attached. Emits lex-level diagnostics (malformed
numeric literals, unclosed strings, invalid characters).

## Scope

- `Token`. `{ kind: TokenKind, span: Span, trivia: Trivia }`.
- `TokenStream`. forward-only iterator + `peek` + rewind on demand.
- `Lexer`. orchestrates tokenisation. Stateful (position + trivia
  buffer).
- `Trivia`. leading/trailing whitespace + comments attached to each
  token. Required for round-trip source preservation (needed by
  refactoring tooling and formatter later).
- Lex diagnostics via `vehje-ir::Diagnostic`.

## Non-scope

- AST construction (vehje-syntax).
- Grammar framework (vehje-syntax or vehje-ir. R1 TBD).
- Incremental relex across edits (future round; day-one is full relex).

## Dependencies

- `vehje-ir` for Span / TokenKind / Diagnostic.
- arvo for USize / Cap / newtype discipline.
- `#![no_std]`, no alloc. Lexer state uses const-generic token
  buffer; consumer sizes it.

## Provisional module layout

- `lexer.rs`. top-level Lexer struct + drive loop.
- `cursor.rs`. byte cursor with Unicode-aware peek.
- `tokens.rs`. Token struct (composes vehje-ir::TokenKind).
- `trivia.rs`. whitespace + comment handling.
- `stream.rs`. TokenStream iterator adapter.
- `diagnostics.rs`. lex error construction helpers.
