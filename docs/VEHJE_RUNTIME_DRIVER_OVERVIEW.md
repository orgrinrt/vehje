# vehje-runtime-driver. Design

The compiler-side embedding and dispatch over the wire ABI, and the in-process
consumer of what crosses back. It serializes a `Checked` residual through
`vehje-runtime-abi`, hands it to the embedded Zig runtime, and maps the
runtime's result and diagnostics back to `vehje-ir` diagnostics; it also holds
the safe reader over the value-arena a produced value crosses back in. It is the
one framework crate with a `std` role, for the dlopen of the Zig runtime
artifact. `#![no_std]` on the core paths, `std` behind the embedding feature.

## Scope

- `dispatch`. Hand a `Checked` residual to the runtime through the wire ABI and
  read back its outcome, mapping the wire diagnostics to `vehje-ir::Diagnostic`.
- `Reader`. The safe value-arena reader. The runtime output is a
  `vehje-runtime-abi` value-arena; the driver is the in-process consumer, so
  `Reader` is the safe, bounds-checked view over that arena, and it carries the
  validation pass that a produced value must pass before the host reads it (the
  typed structural decode, which the in-process path may skip and the untrusted
  path must run).
- `DriverError`. Dispatch diagnostics (the runtime rejected the residual, the
  residual could not be serialized).
- The embedding of the Zig runtime artifact: a separate build artifact the
  driver links (statically for the compiler layer) or dlopens (behind the `std`
  embedding feature). Multiple runtime backends, if they ever exist, compose at
  compile time, never through `dyn` or a shared-object registry at the compiler
  layer.

## Non-scope

- The wire format and the entry (`vehje-runtime-abi`).
- Runtime execution semantics (the Zig runtime).
- The residual's construction (`vehje-codegen`) and the language package
  (`vehje-runtime-gen`).

## Dependencies

`vehje-runtime-abi` for the wire form and the value-arena; `vehje-ir` for the
diagnostic type; `vehje-schedule` for the pass order; `hilavitkutin-api` and
`notko` for the primitives. `#![no_std]` on the core paths; `std` behind the
embedding feature for the dlopen.
