# clause-runtime-abi — Design

C ABI contract between the Rust compiler and any runtime
backend (Zig today; possibly others tomorrow). Pure type
surface + `extern "C"` entry points. No runtime logic.

## Scope

- `#[repr(C)]` struct mirrors of clause-ir types: `AbiSpan`,
  `AbiToken`, `AbiNode`, `AbiDiagnostic`.
- `extern "C"` entry points: init / shutdown / invoke_macro /
  eval_scratch / expand_generative / last_error.
- `abi_version: u32` as the first field on every public struct.
- `From` impls between `clause-ir` types and their Abi mirrors.

## Round-skeleton scope

Phase 6 skeleton round (2026-04-20) ships a narrower instance
of the above:

- `ClauseResult` `#[repr(i32)]` — result code carrier.
- `ClauseRuntime` `#[repr(C)]` opaque handle (`[u8; 0]`
  private field).
- `ClauseDiagnostic` `#[repr(C)]` carrier: flat `AbiSpan`
  (`{ file, start, end }`), pointer + length message, kind
  enum.
- `ClauseDiagnosticKind` `#[repr(i32)]` — `Error`, `Warning`,
  `Info`.
- Three `extern "C"` entries: `clause_runtime_new`,
  `clause_runtime_free`, `clause_runtime_execute`.
  All stubbed: `new` returns null, `free` is a no-op, `execute`
  returns `ClauseResult::Err`.

Full `AbiToken` / `AbiNode` / richer `AbiSpan` wrapping around
`FileId` / `ByteOffset`, `From` conversion impls, and the
init / shutdown / invoke_macro / eval_scratch /
expand_generative / last_error entry points are BACKLOG.

## Non-scope

- Actual runtime logic (`mock/runtime-zig/`).
- Driver dispatch + dylib loading (`clause-runtime-driver`).
- Soundness tests (`clause-runtime-tests`).

## Dependencies

- `clause-ir` for the mirrored types.
- `#![no_std]`, no alloc. FFI stays bare-types.

## Rules

- No `Option`, `Vec`, `String`, `Box` in ABI types.
- No enum discriminants > u64.
- Little-endian fixed; big-endian refuses load (BACKLOG).
- Every struct has `abi_version: u32` first (BACKLOG —
  skeleton types omit the version prefix until the first
  real-backend round surfaces the bump-compatibility need).
