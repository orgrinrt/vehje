# Workflow

How a consumer builds on the vehje framework, what shape the
dependency takes, and how the framework evolves.

## Building a consumer on vehje

A consumer brings a grammar (a front-end producing IR), a family (node
kinds plus a `Family` impl plus effect classification), and one or more
targets (a `Target` impl declaring `Supports` and `Permits` plus its
lowering). It depends on the framework crates and composes its targets
into a distribution.

Vehje is in pre-implementation phase. The framework crates are not yet
shipping; pin to a specific git rev or wait for the first crates.io
release.

```toml
[dependencies]
# Future shape (not yet published):
# vehje = "0.0"
```

## Status

Pre-implementation. The framework is in design phase; the crate surface
is settled (extension-point round) and the source is being authored to
it. Expect red builds mid-implementation by design, until the runtime
seam lands.
