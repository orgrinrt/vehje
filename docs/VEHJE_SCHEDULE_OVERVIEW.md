# vehje-schedule. Design

Compiler pass DAG construction + scheduling. Consumes a typed
program graph from vehje-typecheck. Uses arvo-graph for
topological analysis + critical-path discovery. Produces a
codegen-ready IR hand-off for vehje-codegen.

## Scope

- `PassDag`. directed acyclic graph of compiler passes, built
 from pass-registration + dependency declaration.
- `PassRegistry`. registered passes (core + plugin). Each pass
 declares: name, read set, write set, dependencies.
- `Scheduler`. orders passes via arvo-graph topological sort +
 optional critical-path analysis.
- `Artifact`. cache key + artifact blob for incremental builds.
- Schedule diagnostics (cycle detection, missing dependencies).

## Non-scope

- Concrete pass implementations (each phase owns its own).
- Codegen (vehje-codegen).
- Runtime execution of Vehje programs (Zig runtime, R2).

## Dependencies

- `vehje-ir`, `vehje-typecheck`.
- arvo (numeric + newtype).
- arvo-bitmask (Mask64 for pass read / write sets).
- arvo-graph (topological sort, critical path, rank).
- `#![no_std]`, no alloc.

## Provisional module layout

- `dag.rs`. PassDag construction + integrity invariants.
- `registry.rs`. PassRegistry + pass metadata.
- `scheduler.rs`. Scheduler drive loop.
- `artifact.rs`. Artifact + cache key derivation.
- `diagnostics.rs`. schedule error construction.
